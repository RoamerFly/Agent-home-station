大肥鱼使用手册

第一次使用，先完成一次授权私聊的文字回复，再安装需要的插件。这样遇到问题时，可以判断故障发生在微信连接、模型、加工工具还是投递阶段。

我想做什么 从哪里开始 怎样算成功
在 Windows 开起来，或部署到 Linux 安装与启动 管理页打开，微信后台可以连接
扫码、选择模型、收到第一条回复 首次配置 指定会话产生执行记录，回复取得微信回执
让不同群遵循各自的偏好 群聊与记忆 新回合采用该群规则，回复依据能追到原消息
把图片做成 PDF，或用自己的声音说话 附件与声线 能核对源附件、实际成品和投递目标
挑选、安装或编写插件 插件指南 宿主能发现授权工具，插件返回可核验的结果
查看失败原因、处理未知回执和安全更新 排障与维护 定位失败阶段，恢复时避免重复发送

适用版本

本手册以 Windows 原生开发分支的 89b0bfa 为功能基准。使用较早版本时，可能看不到文档工坊或私人声线入口。源码、便携程序、已安装插件和本机模型分别更新；查看仓库中的功能说明后，还要在自己的管理页检查安装状态。对应源码
