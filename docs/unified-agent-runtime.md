## 执行方式

会话规则准入 → 近期上下文与本会话文档摘要 → 主模型 function calling → 读取真实工具结果 → 继续执行、等待、保存文档或回复 → 既有随机发送间隔与微信回执。

已删除独立的歌曲类型分类、歌曲承诺分类、角色歌声分类和资源复用分类，以及仅凭新资源关键词阻止主模型读取旧素材的分支。没有再用一层模型去决定另一层模型是否可以选择业务工具。格式、真实素材身份、权限、有效下载来源、未知副作用不重放和实际交付证据继续由程序约束。默认 YuE 女声、仅明确要求时才使用 RVC 的业务约定由主模型与工具说明解释，后端仍以 native 作为缺省值；这不是对模型理解永不出错的保证。

## 工作区

私有管理目录下 `agent-workspace/shared/` 存放管理员维护的 `AGENTS.md`、`TOOLS.md` 和项目指南。各会话使用 `agent-workspace/<scope-hash>/`，模型无法通过工作区工具指定其他群的范围。共享文件只允许可信主人或网页登录管理员修改；普通会话只能修改自己的笔记，且受原有记忆权限约束。

`workspace_list/read/search/write` 提供 Markdown 文档读写。现有文档必须先读取 revision，再据此保存；并发冲突拒绝覆盖，临时文件原子替换保留旧内容。每份64KiB、每个范围256份。文件不代替聊天原始记录、任务数据库、权限或发送回执。启动仅创建缺少的默认指南，不覆盖已编辑内容。每轮只加载小型指南索引和不超过6KiB的本会话 MEMORY.md，其余按需读，不扫描整个项目或加载所有群聊。

管理端 Agent 页可选择共享指南或会话，查看、编辑、新建文档；轮询不覆盖编辑内容，冲突保留草稿。私有工作区、真实程序输出和会话笔记不进入 Git。

## 项目和程序工具

- `server_read` 返回完整文件哈希和分页偏移；单个文本文件上限1MiB。
- `server_search` 在授权目录内检索代码与说明，限制文件数、结果和输出。
- `server_edit` 要求完整 sha256 和唯一旧文本，发生变化或匹配不唯一时拒绝修改。文件工具内部串行；外部 Shell 写入仍需 Git 与实际验证协调。
- `server_exec` 继续用于短命令。
- `server_process` 提供 start/status/list/cancel，长命令立即返回编号、输出可查询，默认为30分钟、最长2小时。同一会话与可信用户的相同 request_key 不重复运行；同键不同命令拒绝。

完整命令以管理服务的系统用户运行，起始工作目录不是 Shell 沙箱；进程不隐式继承模型密钥环境变量。配置的可信身份、授权会话和 full 权限仍是执行条件；本次没有自动把项目或服务器权限授予群友。权限撤销时终止仍在运行的受管命令，关闭管理服务时取消其受管进程。异常重启将原记录标为 interrupted，先核对，不凭旧 PID 杀进程或盲目重放。

后台程序会自动建立原会话结果续行任务。程序运行时只查状态，不重复调用模型；完成后把实际输出交给同一主模型。用户主动请求的程序结果不依赖主动问候权限。主模型可以继续检查文件、修复、测试、保存文档或解释失败，结果处理与微信交付分别记录。
