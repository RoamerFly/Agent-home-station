# 更新等待与自动恢复

2026-10-25本机升级过程中，等待在途语音收尾会暂停机器人开始新的处理；当更新程序退出后，旧实现可能留下drained状态。微信账号仍在线，但新的消息要等解除等待后才会继续。已手动解除该实例的遗留等待，确认原收件游标继续推进、普通回复重新取得回执。

更新等待现采用30秒续租机制。只有持票据的更新程序持续查询准备状态才延长等待；程序退出、断连或被终止后不再续租，定时器解除等待，已停止的工作循环按原配置恢复。错误票据不能解除别的等待，旧定时器不能撤销已续期等待。停止机器人会清除定时器，避免用户手动停止后被旧任务重新启动。

本机更新脚本只等待15秒收尾；仍有长语音或其他活动时推迟本次升级并恢复处理，不再让所有会话为更新等待几分钟。不会取消正在发送的媒体，不重置登录，不从头重放已经接受的发送。总览显示“更新前收尾/等待更新完成”，避免微信在线与自动回复暂停混淆。

测试覆盖失去续租后的解除、合法续租与旧定时器、错误票据、管理员鉴权与CSRF。并发测试通过。首次实际恢复后已验证后台继续收到新消息和取得回复接受回执；不通过故意中断真实群发送来做测试。
