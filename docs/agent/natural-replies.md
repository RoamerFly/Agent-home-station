# 自然回复

普通对话、旧发言复核和执行结果回复共用自然表达规范。优先说明当前结果、具体问题和真实安排；核验与工具协议留在内部。采用状态句表达已知与未知，简短收尾，减少自我辩护、免责声明与反复解释。

媒体观察反馈使用实际读取范围和继续读取方法，保留采样帧数、音轨范围、错误代码与来源身份。读取失败仍交给模型结合上下文判断回应；不把失败写成已观看，也不把接收回执推导成试听结论。

共享工作规范合并“自然表达，直接回应”，保留主人原有备注，重复启动不重复添加。最终消息由模型生成；没有关键词删除、输出替换或固定兜底回复。用户主动询问技术区别时仍可具体解释。

验证包括规范传入普通/失败路径、保留模型原始输出、规范记忆幂等更新、媒体读取成功与失败范围，以及需要显式启用的真实模型表达评估。真实模型测试使用合成情境，不接触真实会话，也不发送微信消息；样本结果用于检查表达趋势与发现问题。
