# 任务、工具会话与上下文优化检查点

## 统一任务结果入口（0.31.7）

音乐、异步HTTP工具、后台程序和手机任务保留各自的实际状态读取器，但共用`task_result.go`的结果领取、结构化上下文、模型回送与收尾逻辑。原账号、会话、发送者、原始请求、引用和副作用编号持续绑定。旧任务字段和磁盘数据保持兼容，不迁移或删除已有记录。

这取代了四份不同的结果提示和音乐/工具重复的三次结果处理上限。尚未取得输出时采用动态退避，核对同一任务，不重建远端任务；输出已暂存/进入微信交付时交由原回执状态推进。程序和手机任务产生附件时，也可以记录相同的分段及交付证据。各提供商的轮询期限、真实取消和权限检查仍由适配器执行。

后台快照写入统一检查版本，迟到结果不能覆盖取消或其他更新。任务列表返回完整深拷贝，工具行动证据不会被旧轮询快照抹掉。合成回归覆盖四类任务40次之后的继续处理、重复领取、取消竞争、原会话引用及部分/完整交付；不能据此称所有外部服务都经过实机测试。

程序更新成功并确认健康后，只清理校验通过的旧ELF回滚文件：每个程序保留最近三个及当前/正在运行版本的副本，保留刚创建的回滚文件。独立`binary_retention.py`默认仅预览，显式执行须匹配完整计划哈希；目录、文件身份或内容变化会拒绝旧计划。配置、会话、模型、素材和生成物均不在候选范围。

维护脚本集中在`scripts/update_local_web.py`与`scripts/binary_retention.py`，原研究路径只保留兼容入口。新代码复用一份计划、校验、保留逻辑；不在每个启动脚本中复制清理命令。

## 任务与交付

生成完成后进入交付中，而不是直接标记整个请求完成。附件排队、语音分段回执、部分接受、全部接受、失败、未知结果分别保留；只有预期附件和后置文字全部取得所需证据才完成。交付对象绑定原请求、任务、账号和会话，重启读取原状态。已经产生交付记录的任务不能通过“恢复执行”再生成一遍；需要核对或恢复原发送记录。

用户的时长、交付格式、标题由模型作为工具参数给出；程序验证范围、权限、实际生成时长和文件可用性。默认完整分段语音，每条不超过60秒；需要文件时复用原音频，明确双格式则串行交付。仍有旧的音乐承诺检查器用于发现纯文本承诺代替工具执行，后续继续缩减此处语义启发式；不能宣称整个系统已没有关键词判断。

## MCP 生命周期

桌面微信连接和消息接收器随应用运行。供任务调用的本地工具可在工具中心选择“按需启用”。首次调用时，宿主按已授予的权限启动工具及依赖；后续请求共用该进程。任务、素材、配置和回执仍由各自的持久存储保存。

在“设置 → 权限与行为 → 账号与服务器授权”可以分别设置轻量工具和 Windows 音乐服务的空闲保留分钟数，默认分别为 10 和 15。时间从实际使用结束后计算。相邻请求可以复用已经就绪的服务，间隔较长时释放进程和它占用的资源。填 0 会保留已启动的服务。工具中心的“启动工具”用于本次常驻，“恢复按需”会恢复自动释放；“停止工具”会同时停用工具。

正常聊天按平台/账号/会话保持独立MCP连接。stdio进程初始化一次，同会话后续工具调用复用；HTTP保留会话头。工具发现缓存30秒，单Hub最多32个会话，5分钟空闲关闭。一次连接串行RPC，等待锁时可以取消，活动请求超时或传输失败会废弃连接，不自动重播副作用不确定的工具调用。后续新发现/调用可以初始化新连接。运行重载/退出会关闭所属连接。

stdio只继承基础运行环境和管理员明确配置的env，不继承其他服务商的任意环境密钥。Linux取消进程组；Windows取消进程树；其他平台只能保证结束直接子进程。预演和手动检查继续使用短会话，不能用预演结果证明常驻运行时的全部状态。

## 上下文

新的压缩结果必须是version=1的对象，具有有界的人物、话题、当前焦点、媒体、待办、偏好、更正字段。JSON标量、字段类型错误、未知字段和超量结果不会提交，也不会推进压缩覆盖位置；原始消息保留。旧版本已保存的同名字段摘要兼容保留，在下次成功压缩时升级。

所有模型接入方式都对近期历史和摘要执行同一字节预算，优先近期消息；摘要与原始消息分别标为资料，覆盖的旧原文不会再加载。预算是历史上下文UTF-8字节数，不是模型精确Token数，也不包含系统指令、当前请求和后续工具结果。真实模型使用合成记忆验证：20条压缩、25条原始记录保留、schema校验通过，没有读取真实聊天或发送微信。

## 仍需继续推进

声明式HTTP工具现支持可恢复后台任务：创建前领取、编号持久化、配置指纹固定、同编号轮询、按原会话领取结果与取消，配置见 `PLUGINS.md`。迟到的查询和模型结果不能复活已取消任务；已准备结果或进入交付的任务不能通过恢复按钮重复发送。取消接口只调用一次，区分本地停止、远端接受请求和远端未确认。自动化覆盖创建回执丢失、改参数重试、重启恢复、取消与查询竞态、改址、期限和交付状态；真实模型已在合成异步HTTP服务上完成创建与结果读取，不涉及真实创作服务或微信发送。

记忆与活动日志已增加先归档再缩减、只读恢复阅读/导出和容量展示，见 `history-archive.md`；清除活跃记忆也清除压缩摘要。0.13.1增加网页发送记录的已确认回执磁盘归档，保留原编号查重和查询，不再因为累计1000条已成功发送而永久阻止新请求。持续任务、特权操作和附件索引尚未压缩，也未实现归档自动过期和媒体清理，不能把容量展示当作已经解决所有硬上限。

普通MCP服务的异步任务互操作仍在持续目标内。素材链和多人引用已有场景回归，仍需扩充真实使用覆盖。服务器完整命令仍以管理端系统用户权限执行，授权目录是文件工具边界和Shell起始目录，不是系统隔离沙箱。视频号实际理解受授权播放信息限制，详见 `channels-content-understanding.md`。
