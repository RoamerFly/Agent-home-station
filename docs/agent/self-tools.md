# Agent自行编写工具与恢复服务

Agent可以通过基础文件与执行能力实现未封装的业务：读取项目和运行环境，编写程序，执行，读取退出结果，修复，复跑，再保存使用说明。新脚本本身不需要更改Go工具列表或重新构建镜像；模型通过`server_exec`或`server_process`调用它。公共项目可由真实管理员维护，普通会话只能在自己的目录编写程序。

复用方法保存在Markdown中；公共工具在公共项目及注册清单中登记，`project_list/project_read`每次读取真实清单。新的脚本不会自动变成独立的function-call或自动取得宿主权限。需要远程API的程序可沿用已经配置的服务工具，密钥仍由控制面保管。

宿主systemd与隔离工作区是不同执行节点。音乐服务停止时，隔离Shell无法通过本地回环访问宿主来启动服务；需要已提供的`music_service_start`。这个入口只启动已安装的本机音乐单元，之后查询健康状态，再继续原任务。受管执行边界、账号与会话隔离不因修复而撤销。

## 本次真实模型验收

可显式运行`TestLiveAgentWritesOwnToolRepairsAndRuns`，环境变量`WECHAT_SELF_TOOL_LIVE=1`、`WECHAT_LIVE_MEDIA_ROOT=<运行数据根>`，可用`WECHAT_SELF_TOOL_REPORT`指定本机报告。常规CI默认跳过实模型请求。

测试使用隔离管理器、临时真实文件和真实隔离进程，只向模型提供文件读写与执行基础工具，无预写业务包装器。模型复现错误，修改`duration.py`，自行创建带参数和JSON输出的`audio_duration.py`，运行并写入`TOOL.md`。独立执行`check.py`和工具，48000采样/24000采样率返回2秒，退出码0。成功记录含1次编辑、2次创建及多次真实执行。它验证了编写与运行程序的能力，不证明模型会在所有生产对话中自动选择正确行动。

测试没有真实微信发送能力，不修改生产源码、权限、聊天或登录态。测试中模型输出不作为唯一成功依据，断言还核对磁盘文件、真实报错和独立运行结果。
