# YuE参考翻唱、种子与歌曲来源

2026-10-25，0.12.0-reference-cover-local。

## 本次原因

资料群的原曲音轨已缓存，引用也带有精确素材编号；当时两次生成请求却都未传 `reference_asset_id`，歌词是新编内容，桥接记录均为 `reference_used=false`。这属于工具说明和模型选参偏向原创，不是找不到原音频。旧工具描述要求“原创歌词”，承诺修复提示也偏向写新词；桥接还无条件随机种子、追加短歌风格，无法精确复用指定种子或原始风格。

## 已接入的功能

`music_local_start` 明确区分 `mode=original` 和 `mode=cover`。后者必须提供同平台/账号/会话缓存原音频的 `reference_asset_id`，后台校验内容哈希及25MiB限制，不接受任意主机文件路径。模型应优先采用微信引用中的精确素材，不能以较新改编版替代原曲。缺少原词时先读取/转写/确认，不用原创词冒充原词。

支持传递 `style`、`lyrics`、`seed`（0–2147483647，含0）、`reference_mode`（melody/full）和 `duration_seconds`（10–600秒的生成上限）。同一请求省略种子时生成一个稳定种子，重试和JSON格式变化不重新抽取；新请求省略种子会选择另一种子。指定种子保留其值，但跨硬件/模型版本不保证逐样本相同。桥接将种子写入任务后再执行，不在执行阶段随机覆盖；风格和歌词原样进入节点，不追加“短歌”指令。

`music_reference_inspect` 读取精确素材的原始来源、已提交的生成参数。可选 `transcribe=true` 使用已启用百炼ASR转写指定片段（单次最多60秒，支持offset），结果明确标为候选歌词，不能当作无误的歌词库。网络/识别失败不会生成虚构歌词。长曲可分段读取，不用每次再下载同一原曲。

新任务和媒体素材保存风格、歌词、参考编号、模式和种子；管理端“行动与任务”可展开提交参数。模型的任务列表省略完整风格/歌词，用检查工具按需读取，避免把全部歌词反复放进上下文。原录音重发仍使用 `media_reuse`；换种子抽卡才重新生成。翻唱文件以“大肥鱼翻唱-歌曲名”命名，原创继续使用“大肥鱼原创歌曲-歌曲名”。

桥接健康接口提供版本和能力，管理端拒绝把新参数提交到无法确认其生效的旧桥接。等待中的旧任务仍可按原编号读取，不自动重新生成；没有给旧产物猜测或补造种子和参考参数。

## 本地项目能力与边界

| 本地应用功能 | 微信Agent接入 |
|---|---|
| 文字生成歌曲、风格、分段歌词 | 已接入，模型选择参数 |
| 上传参考音频、参考旋律翻唱 | 已接入，使用同会话下载/缓存音频；本次补齐明确模式与原词检查 |
| 种子、重新抽取版本 | 已接入并持久保存；精确重发应复用原文件 |
| 纯音乐双阶段生成/音源分离工作流 | 本地应用存在，当前Agent尚未接入该独立工作流 |
| Gradio本地队列与历史 | Agent使用独立持久任务与回执，不把本地UI队列等同微信交付 |

本地ComfyUI的 `SheetSage2AudioToABC` 从参考音频提取旋律（melody）或旋律和和弦（full），再由 `YuE2GenerateMusic` 与采样器重新合成音频。它不是将原曲伴奏原样保留、只转换人声的RVC/SVC链路，也不是特定鲸鱼娘声线的克隆模型。女声风格是生成条件，具体声线和忠实度需要试听；不能保证翻唱任何歌曲或完全还原原伴奏。严格要求伴奏不变时应说明能力不足，不能换成原创歌来冒充。

## 验证范围

- 合成测试：精确参考字节、歌词/风格、种子0、同请求重复/格式变化、跨会话拒绝、参数恢复和文件命名。Python节点测试覆盖melody/full、固定种子、原样歌词及错误模式拒绝，纳入CI。
- 真实模型、合成工具/素材：引用原曲而非后来改编版；保留参数只换种子；先请求ASR候选原词；严格原伴奏要求不擅自生成替代品。微信发送为0。
- 真实缓存原音轨分段和全曲ASR读取；30秒实际YuE参考生成完成，ComfyUI记录核实参考WAV、种子、旋律模式及30秒上限，输出ASR包含原曲开头词句。ASR不是旋律、人声性别或听感质量的验收。
- 用户后续要求完整女声版本，使用约182秒原音轨与全曲ASR候选词（36行、6个段落）实际生成184.84秒音频；完整解码通过，MP3试听文件约4.4MB。输出ASR中6次副歌题句与结尾词句均存在，未按试听时长裁剪。生成节点指定女声风格，但音色与旋律忠实度仍需用户试听，不把ASR当作性别或艺术质量鉴定。未向资料群发送，按用户试听意见决定。
