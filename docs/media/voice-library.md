# 角色语音库

管理后台「服务商 → 语音、识别与歌曲服务 → 打开角色语音库」，或登录后访问`/voice-library`。可按角色名及引擎筛选，试听已有参考和样本，展开查看全部权重版本。页面只做归档与试听，不自动修改当前声音、不生成、不发送微信。

## 本地数据分层

- 管理服务的`<admin>/voice-library/catalog.json`保存聚合索引；`files/`按SHA-256与扩展名去重保存个人模型、参考及文本。该目录不挂载给Agent普通Shell，也不进入Git。
- 第三方公开的曼波模型保存在`public_workspace/models/voice-library/manbo-tlme`，与个人模型分开。页面列出位置、固定来源修订、大小、哈希和授权说明。
- 百炼原有私有登记仍位于`secrets`，库中只记录登记位置、候选代号与表达指令，不复制API Key。A/C/D表达可能共用同一个复刻音色，不误标为四套独立权重。

## 收集已有GPT-SoVITS模型

```text
python scripts/voice_library.py --workspace <项目根> --history <GPT-SoVITS历史目录> --library <admin>/voice-library
```

只读取指定目录的`GPT_weights_v2`、`SoVITS_weights_v2`、`SoVITS_weights`和明确配对的`A_Example`。全部已导出的训练轮次保留；同名角色按原名称归组，不猜测真实身份。GPT与SoVITS分别保留其版本，v1孤立权重不能自动与v2组合。最高轮次作为可检查候选，不宣称最佳质量。缺参考或权重的条目需补配后运行；历史`weight.json`引用的预训练模型不是角色训练成果，不因此导入整套运行环境。

## 曼波公开模型

使用[TLME/RVC-Umamusume](https://huggingface.co/TLME/RVC-Umamusume)的待兼诗歌剧（マチカネタンホイザ）权重与索引，固定修订`49cc012b5ad11274a33d61affb11723ec854f944`。仓库标注MIT，角色与原始声音权利不因此转移；不把仓库许可推断为角色商业授权。上游声明未逐个验证全部模型，日语角色模型的中文表现需实际试听。

导入命令加`--download-manbo`获取公开权重。每个下载块校验HTTP206、Content-Range和大小，最终核对上游LFS SHA-256；失败保留可续接块，不覆盖已有不同内容。模型是`.pth`，不在收集阶段反序列化执行，不自动加载第三方pickle。它需要输入语音/歌曲人声做RVC转换，不能当作直接输入文字即可发声的GPT-SoVITS或百炼模型。当前默认大肥鱼音色保持不变。

## 管理接口

`GET /api/voice-library`返回当前账号管理目录的库；`GET /api/voice-library/files/<sha256.ext>`只服务私有库内的哈希文件，支持音频Range；`/voice-library`为页面。三者均要求管理登录，不能通过文件路径参数访问工作区外文件。未登录返回401；不向普通微信会话暴露语音库中的个人录音或模型。

## Agent使用

Agent可调用`voice_library_list`（搜索、引擎筛选及分页）、`voice_library_read`（精确权重、参考、状态和使用说明）、`voice_library_prepare`（将选定文件校验复制到受管工作区）。默认准备登记的推荐检查点与参考；传入`file_ids`可选其他轮次。准备文件不会训练、运行权重或发送微信。

管理员可检索当前账号的私人归档；私人模型和参考准备到本账号`global/voice-library`，后续`server_*`使用`global=true`。普通成员只发现公共库，公共条目准备到当前会话。不会把整个管理目录或凭据挂载给Shell。私人库仍由管理服务保存，工作区只取得明确选中的文件。

曼波公共条目由`voice_library_read`返回`music_rvc_start.voice_profile_id="voice-manbo"`。调用换声时显式传此值；任务配方、幂等身份及重启续办都保留声线选择，不改默认大肥鱼C配置。旧桥接缺少选音色能力时不提交到默认声线。桥接v12支持按任务选择公共清单内的音色配置，配置与权重哈希仍在转换前核验。

本机音乐服务停止时，可信管理员可调用`music_service_start`启动已安装的`wechat-agent-music.service`，再用`music_service_status`核查桥接和后端状态。该操作只适用于已配置的Linux本机127.0.0.1:6188；其他部署由其自身服务管理器启动。它不开放任意宿主Shell、不提交歌曲、不发送微信。服务就绪、任务提交、音频生成及手机播放分别核验。
