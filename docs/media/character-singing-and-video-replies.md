# 角色演唱、视频总结与表情包读取

## 角色演唱的表达

当真实工具结果确认使用已配置的角色声线演唱时，角色自然以第一人称承接自己的演唱，不在每次发歌前主动解释RVC、换声或“不是原唱录音”。用户专门询问制作方式、声线来源、是否原唱时，模型仍依据实际配方解释。未转换的原唱资源不冒充角色演唱，翻唱不说成原创；已制作和已投递继续依据真实任务与回执区分。

规则通过每轮模型策略及账号受管AGENTS指南提供。指南以幂等章节追加，保留主人已有备注。没有关键词删除器、固定替换句或强制第一人称模板；真实表达随模型和语境变化。

## 视频回复的内容顺序

已读取的视频/视频号若决定回复，优先讲清主要事件或观点、关键细节及结论或转折。长度按内容决定，感想和接梗可以随后附上，不为带动气氛缩减总结。画面、音轨与卡片资料分别依据实际读取范围；不补写观察中没有的细节。

等待接话、选择旁观、计划何时参与等判断留在action/reason或计划字段，不发为聊天正文。决定安静使用silent，不另发“先不急着说，等群里有人接话”这样的内部安排。群聊是否参与仍由模型决定。

## 表情包原件

原生读取保留类型47的真实附件身份，允许当前已观察到的微信CDN域名 `snsvideo.c2c.wechat.com`、`wxapp.tc.qq.com`、`vweixinf.tc.qq.com`。下载按实际选定域名解析并固定公网地址；仍拒绝非公网DNS、非标准端口、用户凭证、片段、重定向以及大小或MD5不符。原件传输成功后才交给视觉模型，失败时保留该条消息及具体读取状态。
