# 节点工作台与管理后台优化路径

版本：`0.28.0-node-workbench-local`。

## 当前交付

默认首页是节点画布。12 个节点把微信接入、会话规则、媒体观察、模型、角色、记忆、Agent、工具、发送、补发和安静的关系放在同一视野。节点可拖动，空白处可平移，按钮或 Ctrl＋滚轮可缩放；“适应画布”与“重置布局”便于恢复。布局只保存在当前浏览器，不包含配置、密钥或聊天正文。

点击节点在右侧打开真实配置，保存沿用现有 API，不复制第二套配置状态。切换节点保留同一页面中的草稿；离开画布后原表单回到原页面。手机窄屏使用可滚动的单列节点，避免把整个图缩成不可读的缩略图；不改写桌面节点位置。右侧面板铺满画布宽度，复杂表单改为单列。节点选择菜单与移动菜单提供不依赖拖动的操作方式。

回合下拉叠加已有日志中的证据，例如接收数、工具数、发送回执和安静状态。“回合详情”打开该回合的大弹窗。选中节点时突出相连的边，其他连线减淡。画布不是模型思维链，也不推断缺失的历史步骤。

主导航保留工作台、会话、执行回合、角色、能力、系统。会话只管消息与记忆；执行回合只管处理过程和投递证据。原有详细设置与地址保留，默认的工作台减少常用配置之间的跳转。

## 为什么采用这一条路线

[ComfyUI 的界面设计](https://docs.comfy.org/interface/overview) 将节点画布与右侧属性/信息面板结合，适合在一个视野中理解关系、修改局部参数。对本项目，先把现有运行链路和真实表单放入这一结构，比先更换整个前端技术栈更容易验证交互价值。

| 方案 | 适合的阶段 | 本项目的取舍 |
| --- | --- | --- |
| 当前原生 DOM＋SVG | 管理入口、状态投影、少量节点 | 已实现；沿用 Go 内嵌静态资源，无额外部署依赖 |
| [Drawflow](https://github.com/jerosoler/Drawflow) | 可连接节点、导入导出图、原生 JavaScript | 后续确需用户编排流程时可做小范围原型 |
| [LiteGraph.js](https://github.com/jagenjo/litegraph.js) | 大型 Canvas 图、可执行节点网络 | 会带来执行语义和插件节点生命周期的额外设计工作 |
| [React Flow](https://reactflow.dev/learn/concepts/the-viewport) | React 应用中的复杂节点编辑器 | 当前没有 React 组件体系，不为画布单独迁移全部页面 |

当前连线表达已有依赖；拖动节点不会改写 Agent 的执行逻辑，也没有任意重连、节点执行引擎或自定义流程导入能力。Agent 仍根据对话、上下文和真实工具结果自主行动。

## 后续优化顺序

1. 先稳定现在的入口、侧栏表单和证据定位，优先处理重复标题、溢出、滚动丢失和无反馈操作。
2. 整理配置字段的归属与依赖，将低频诊断项收进高级分组。统一保存、错误定位和字段校验，避免同一个设置在不同页面有多个名称。
3. 若确实需要可编辑执行图，先定义节点输入输出、异步任务、取消、恢复和权限继承，再选择图编辑器。不能让图形连线直接替代已有权限检查或把一条 UI 连线当作任务成功的证据。

以上第二、三阶段是候选路径，不是本版已经实现的能力。

## UI 冗余与审美审查

本轮使用两个任务内审查 Agent，只读检查界面代码和合成截图；不接触私有对话、不修改配置、不发送微信。

- 修正会话弹窗仍声称包含执行过程的旧文案。
- 为回合叠加状态增加直接打开对应回合的入口。
- 修正小屏“适应画布”固定缩放导致无法看到全部节点列的问题。
- 提高节点辅助文字的字号，完整状态可通过悬停提示查看；突出选中节点相连的边。
- 属性面板标题与移动/关闭操作分行，密钥输入行和规则卡片改为单列。
- 保留画布内编辑真实设置，避免为了减少表单数量又增加往返跳转。保留节点选择及移动菜单，支持键盘和不拖动操作。

## 验证与证据边界

- `scripts/test_node_workbench.cjs`：合成日志、拦截配置写入；验证拖动、平移缩放、仅布局本地保存、草稿保留、模拟保存、原表单恢复、回合详情、连接突出、明暗主题与小屏/横屏适应。
- `scripts/test_conversations_ui.cjs`：消息新到旧、历史按需读取、压缩后收起原文、不同会话并行压缩不串状态、大弹窗与焦点恢复。
- `scripts/test_admin_console.cjs`：18 页、两种主题、375/768/1440 宽度；执行回合筛选、分组、滚动保留与弹窗。
- `scripts/test_catalog_ui.cjs`：目录查询超时、空结果、换群取消和分页失败保留已取得结果。
- Go 测试覆盖独立压缩预算、JSON 模式兼容回退、摘要格式修复、快照变更恢复、昵称更新不误冲突、HTTP 错误分类和静态资源类型。

合成浏览器测试不构成真实微信投递或手机播放证据。实际模型压缩诊断使用私有副本，不修改活跃记忆。更新只替换本机管理端程序，保留原生微信登录和私有配置；不生成或导出 Docker 镜像。
