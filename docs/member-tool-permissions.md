# 微信普通成员与管理员权限

已授权会话中的普通成员可使用文件处理、文档预览、脚本工作区、学习笔记，以及已启用的公共工具状态查询和启动。

- 同群成员共享会话工作区、学习笔记和已保存的素材。可以继续加工其他成员上传的文件，无需先引用上传消息。
- 不同群、私聊和账号保持独立。素材访问仍核对账号、会话和实际文件来源。
- 原件保留在素材库；处理时复制到任务工作区。成员可以创建文件夹、脚本、笔记和新产物，工作区内的临时文件可整理。
- 正式素材库删除、跨会话访问、全局配置与工具安装等管理能力继续由管理员掌管。
- 普通成员可启动已启用工具；停止或重启使用 idle_only，由宿主检查未完成任务和在途调用。工具忙碌时等待完成，不强制打断。
- 群共享不等于开放所有会话：会话启用范围、发送权限、任务取消与发送确认沿用现有设置。

验证采用合成会话和素材，不发送真实微信消息。原有会话目录无需迁移。
