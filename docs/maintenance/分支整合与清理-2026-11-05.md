## 验证与执行顺序

独立 worktree 中解决合并冲突 → 格式/静态检查、完整 Go 测试与 vet → Windows 生命周期及必要 CI 检查 → 整合 PR 普通 merge（不 squash，以保留祖先证明）→ 回读 main SHA → 仅删除已确认祖先的分支 → 核对剩余分支和主工作区改动。

安装教程和成长计划链接同步指向 main，避免删除开发分支后失效。整合同时修正原有四个 Go 文件格式。GitHub hosted runner 的 WebView2 曾在私有桌面初始化时报 0x80070578，因此仅在 GITHUB_ACTIONS=true 且 CI=true 时继承 runner 桌面，保持实际页面、生命周期和单例断言；其他环境仍在私有桌面并检查窗口泄漏。本机桌面控制器 60 项、窗口生命周期 88 项断言通过；全库 vet、25 项 JS 模型测试、JS 语法与项目结构检查通过。全量 Go 回归与远端 CI 仍需核对最终结果，不通过跳过断言或管理员绕过检查完成合并。完整执行结果以 PR、测试输出和远端实际分支为准。
