# 工具健壮性与隐藏执行

本次覆盖已配置工具的公共参数入口、文件与进程执行、任务回执、插件/MCP 降级和 Windows 控制台启动方式。独立服务是否在线、账号授权、内容是否可下载和服务商限流仍需依据每次真实返回判断。

## 公共参数与错误反馈

- 内置工具先依据自己的 schema 校验 JSON 对象、必填字段、类型、枚举和范围。校验失败明确标记 `tool_arguments_invalid` 和“未执行”，不把缺参数伪装成网络连接失败。
- 接受无歧义的 camelCase、snake_case、连字符字段别名；明确的数字/布尔字符串可转为对应类型，整数不经浮点数中转。重复或冲突字段拒绝，不能悄悄选择其中一个。未知参数不会被静默忽略。
- 外部 MCP 的字段拼写和类型保持原样，其完整 schema 仍由对应服务负责。错误信息不回显未知参数值或上游认证响应。
- 本地校验、权限和操作拒绝返回具体原因；第三方原始错误正文不直接写入通用日志。读取、编解码、提交和接受回执仍是不同阶段，不能混为成功。
- 程序创建前被拒绝明确记录 `rejected`，说明没有启动，可在修复环境后再次尝试；已经领取执行、可能产生影响或结果未知的操作继续检查原记录，不能盲目重放。
- 一项外部 MCP 不可用时，能力目录返回剩余本地工具及 `partial` 标记，不把整个目录报成不可用。
- YuE 的 schema 与后端兼容行为对齐：旧调用可省略 mode，后端按已有参考资料推断；明确的翻唱仍需正确参考素材与歌词。移除会因为其他历史任务累积达到 500 条而拒绝插件任务的隐藏门槛。

## 文件和程序

WSL 文件工具在真实盘符挂载存在时接受 `E:\...` 等 Windows 路径，映射到 `/mnt/e/...` 后仍检查原有授权根目录。无挂载时明确提示当前节点差异。读取返回规范路径与真实解析路径；创建时区分“文件已存在”“父目录缺失”和其他失败，修改仍保留哈希冲突校验。

进程记录保留实际输出与非零退出码；启动器本身失败也会写入本地诊断，避免只有空输出和 `-1`。Windows 原生 Go 子进程和 MCP 子进程使用 `CREATE_NO_WINDOW`。

## WSL 到 Windows 的隐藏通道

在可信主人原有 full 权限和授权根目录下，可配置 `host.windows`：

- `pythonw`：服务节点可访问的 GUI 子系统 `pythonw.exe` 绝对路径。
- `helper`：`scripts/windows_agent_host.pyw` 的服务节点绝对路径。
- `spool`：同一 Windows 盘映射中的私有暂存目录，不能加入 Git。
- `shell`：实际 Windows PowerShell 可执行文件路径，可使用已安装的 PowerShell 7。

配置后提供 `server_windows_process`。它复用现有进程身份校验、幂等请求、取消与持久后续任务；`path` 可写盘符路径，`command` 直接写 PowerShell，无须额外套 bash 或转义 `$`。使用 pythonw 启动隐藏 PowerShell，通过私有文件传输输出与状态，不开放网络端口。取消仅停止本次受管进程树。

已有的特定 Codex PowerShell 标题窗口可用 `scripts/Hide-AgentConsole.ps1` 隐藏，`-ListOnly` 检查，`-Restore` 恢复。脚本只匹配当前桌面该准确标题的 Windows Terminal 窗口，不关闭终端、微信或 YuE，也不修改全局终端设置。外部程序主动打开的图形界面不在隐藏控制台的保证范围内。

## 验证边界

测试矩阵覆盖 42 项内置工具 schema，包含当前生产目录的 40 项及额外可选工具；验证错误 JSON、缺参、类型、枚举、重复字段和兼容别名，不触发真实发送或付费生成。另验证外部 MCP 故障不阻断本地工具、明确拒绝的程序可在环境修复后再试，以及原有完整测试套件。

本机 Windows 实测验证 Unicode、引号与美元符、真实退出码、取消与窗口不可见。WSL 实测运行生产 Go 工具适配器调用真实 Windows 程序，验证退出码和相同请求不重复执行。Linux CI 对 Windows 专用实测会跳过，检查其源代码；本机实测和 CI 结果分别报告。未将全部第三方服务逐个发送、生成或执行一遍，也不把参数验收等同于第三方服务在线。
