# 官方媒体与云端语音包就绪验收

2026-11-01。就绪仅指下面列明的已实现能力可被安装、配置及调用，不代表全部服务迁出主体。

## 本轮就绪范围

- `media-understanding` 0.1.2：`media.observe` 与 `media.transcribe`。配置按能力独立，只有 ASR 配置时不必填写视觉凭据，只有视觉配置时也不必填写 ASR。Agent 发现的是宿主参数 `source_message_id`，内部图片/音频引用不暴露为可伪造的工具参数。
- `speech` 0.1.3：默认云端 `speech.synthesize`。包权限仅为当前实现所需的 `model.invoke`。命名/本地声线、克隆和训练仍是旧实现或不可发现的待迁移占位，不预申请 GPU，也未放宽执行器权限。
- `web-search` 仍保留既有就绪范围。分享及其他服务继续迁移。

## 证据

官方包的安装/调用测试直接使用仓库内清单，不复制后改状态、删权限或重写能力。实际 Windows LPAC 合成响应测试通过媒体模型代理、图片/语音来源恢复及默认 TTS 契约。待迁移的 `speech.voices/train` 不可发现且调用被拒绝。没有真实模型或微信发送。

通用 Store 和后台生命周期测试使用明确固定的合成权限与配置，不再继承真实 speech 包逐步收敛的权限。放行契约检查精确列举三个就绪包及可发现能力，仍拒绝其他未实现能力伪报就绪。

新增只读迁移预演器，覆盖逐账号旧配置映射、缺项、源字段、摘要与未来应用前提。本机预演仅读取管理配置，未导出密钥或复制模型/聊天，计划留在忽略的 temp 目录。无法映射的付费搜索后端和混合 ASR 后端明确阻断。Windows 私密导出未实现经验证的 DACL，因此主动拒绝该选项，不以 0600 模式伪称已安全导出。
