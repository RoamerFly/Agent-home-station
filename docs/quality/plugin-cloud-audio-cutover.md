# 默认云端语音与云音乐插件切换

日期：2026-11-01。Windows amd64、Go 1.25.3、项目内 Python、Edge headless。仅使用合成配置、来源、音频及假提供商；本轮付费调用与真实微信发送为零。生产登录、配置、模型、声线、素材和 EXE 未修改；未创建旧备份或访问待删除目录。

## 实际改动

- 默认云端 TTS 和云音乐只经已安装、已配置、已授权插件执行。删除 `bailian.Client.Synthesize`、`Client.Music` 及不再使用的解析 helper；未安装、停用、配置缺失或撤权时不会退回旧 provider/key。
- speech 0.1.4 使用独立 Python MCP stdio；只开放 `speech.synthesize`。管理页测试有独立的登录会话身份，不伪造微信来源、不授予发送权限；实际音频始终解码验证，可选识别不代替音频验证。
- music 0.2.0 仅开放 `music.generate`，独立运行时只处理固定宿主请求与提供商结果，无密钥、直连网络、文件、GPU 或微信能力。翻唱、RVC、训练仍不可发现。请求或任务含命名声线、参考翻唱等约束时拒绝云端替代。
- 两类策略固定账号、目的、来源版本、配置、包版本/摘要、工具参数与单次提供商尝试。实际用量由宿主记录，未知用量保持未知。提供商 URL 只在私有结果存储，公开结果不当作交付回执。
- 修复合成后的撤权窗口：下载前后、转换后、每段上传前后及素材登记前继续核验。管理页退出/会话过期、停包、配置变化、取消或遗忘会阻止后续步骤；不会把已经发生的上传描述为已撤回。
- Go 应用器及 Python 只读预演新增独立 music 映射，路径为 `/api/v1/services/audio/music/generation`；密钥留宿主，迁入先保持停用。旧配置哈希、包摘要、权限及修订变动使旧批准失效。
- 删除旧页面中不再生效的默认 TTS 和云音乐表单，转为真实插件详情入口；未安装时打开只读迁移预览。保留 ASR、本地 YuE、声线库和不发微信的默认合成测试。修复隐藏子页导航、重复弃稿确认、GET/POST 交错、等待期间编辑导致按钮锁定与草稿覆盖。
- 可选旧 Live 测试的默认 TTS 部分改用临时安装插件与真实隔离执行器，先检查运行环境，未显式选择即跳过。本轮没有运行付费 Live 场景。

本轮只在合成临时目录中预演及实际应用。后续本机更新前排空在途任务，重新计算每个账号的迁移计划，核对旧开关、端点、模型、默认声线、权限、来源摘要及私密配置是否一致。迁移事务保留记录，可安全重试；不复制大模型、不清空记忆、不删除旧兼容文件。
