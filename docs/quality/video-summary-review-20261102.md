# 视频工具、复核与总结表达修复（2026-11-02）

## 只读核对结论

本轮对既有私有诊断资料进行只读核对，没有重放任务、调用真实模型或发送微信消息。真实资料及消息标识不进入仓库。

- 活动日志通过 `logText(..., 4096)` 生成预览并追加 `…[截断]`。这不是模型输入的截断标记。本次实际生成、初次复核和最终复核的快照均包含音轨后段及最后一个枚举项。
- 原始候选已经概括了多个口述要点；初次复核把具有实际音轨正文的当前来源误解成读取失败/只有标题。修稿随后退化成读取范围说明。不能把这一事故归因于没有音轨，也不能把“服务器接受”当作总结质量通过。
- 同一复核输入内存在其他消息的历史失败观察，当前成功观察具有不同消息/事件身份。没有证据表明这些记录应合并；保留各自身份，不清空记忆或修改真实来源。
- 通用观察把画面采样和音轨读取统称为采样概览，即使音轨已经覆盖整个短视频，也提示从结束位置续读。这使复核易误解覆盖范围。

## 实现

### 工具调用

`video_inspect.action` 省略时默认为 `info`，在声明和执行端保持一致。默认调用仅取得真实元信息，随后仍需选择 `frames` 或 `audio` 读取内容；不能把元信息查询记为内容理解成功。显式非法 action 仍拒绝，且在解析/下载来源之前检查。返回 `effective_options.action`。

### 复核协议

新请求使用句段协议 v2：

```json
{"units":[{"unit_id":"U1","status":"supported","source_refs":["E1"],"reason":"该来源支持整段事实"}]}
```

宿主划定全部句段并检查完整编号覆盖、唯一性、状态及来源存在性。模型判断整段全部事实和问句前提是否有支持；部分支持不能标成整段支持。不再要求复制每个原子命题、逐字符覆盖、确切引文以及相互冗余的 mode/category 字段。

来源编号存在不构成语义证明，语义正确性仍依赖模型判断。保留来源版本、授权、人物、遗忘与发送约束；复核不得执行工具。协议错误仅允许既有一次格式恢复；语义拒绝走一次编辑与独立终审，不重新抽样到通过。严格旧协议解析仅作为兼容入口，不是宽松兜底。

视频复核表将当前观察中的画面、音轨和发布者描述分别呈现，不重复抄录整段过程说明。完整音轨不会因画面采样而被标成读取失败。历史失败不能替代当前成功来源的状态。此拆分只是已授权观察的呈现，不新增人物或权限证明。

### 总结表达

生成和编辑共同要求直接表达已取得的主题、观点与细节，关键内容不足时先补读，不能把采样/核验过程说明冒充总结。有用内容足够时无需为没有逐帧读完附加免责声明。

增加针对已知媒体过程式回复的本地质量检查，复用既有一次编辑与终审，不新增独立模型步骤。编辑后仍有相同问题则保留具体失败原因，不发送该草稿。明确询问读取进度、范围或故障时允许回答实际情况。该检查针对已知表达，不宣称能够穷尽开放式自然语言的所有变体。

### 音轨可读性

`internal/transcript.Readable` 对长段中文转写本地补充枚举段落、连接词前的标点；无法判断句法时只换行，不硬造句号。不改识别词、不纠正错字、不增补观点，不推断说话者或词级时间戳；原始识别结果仍在经过校验的插件私有任务结果中。

自动视频观察与显式音轨精读共用该格式器。模型收到一份可读文本，不重复注入原始版和排版版，也不增加标点模型调用。该改动改善阅读，不能宣称提高了 ASR 字词识别率。

## 离线验收与边界

新增/扩展合成回归覆盖：省略 action 的实际调度、非法 action、完整短音轨与长视频部分音轨、无可识别语音、复核编号/来源/状态错误、语义拒绝、旧协议严格校验、过程式回复修稿及终审、成功音轨与历史失败隔离、长音轨末尾保留、断句不改字及幂等。

真实模型和微信发送验收本轮均为零。既有模型的这次误判已从快照核实；新版协议改善真实语义准确率的幅度尚未付费测量。实际 Token 和费用节约不从提示字节数直接推断。
