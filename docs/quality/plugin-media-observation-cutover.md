# 媒体观察插件切换与验证

日期：2026-11-01。Windows amd64、Go 1.25.3、项目内 Python、FFmpeg/FFprobe 与 Edge headless。所有输入均为合成来源、任务、音频和提供商回调。本轮付费模型调用和真实微信发送均为零；生产 EXE、账号登录、配置、记忆、模型和声线未修改。没有创建旧备份或访问待删除目录。

## 具体切换

- media-understanding 0.2.0 提供 `media.observe`、`media.transcribe`、`media.listen` 三项已实现能力。未配置某种模型只影响对应能力；缺少插件时不回退聊天模型观察图片，也不先下载入站媒体。
- 图片/表情、视频视觉、手机录屏分析使用安装插件。录屏来源绑定捕获后的实际任务、文件哈希、设备及来源版本，分析前后和素材登记前均复核。规划所需的宿主当前模型代理仍保留在 `mobile_plan_plugin.go`，它属于已安装设备插件的受控模型通道，不是旧媒体回退。
- 删除 `bailian.Client.ReviewAudio` 及裸 JSON 听感缓存读写；原私有缓存文件不删除。歌曲观察绑定真实 MusicJob、原任务、请求者、原音频与选定声线约束；观察结果只是模型意见，不作为声线身份认证。上游任务及已完成观察的校验持续到成品暂存/上传。
- `media.listen` 的公开参数只允许实际入站语音或当前授权素材，以及区间、提示、输出额度和超时。插件只收到短期 WAV 引用，不能选择原路径、账号、凭据或伪造消息。
- 压缩素材保留原有 25 MiB 源大小要求，按文件协议探测实际时长，每个最多 90 秒的窗口独立解码为不超过 3 MiB 的 WAV，不先展开整个音频。451 秒合成 MP3 验证短范围读取、五段以上覆盖及尾部说明；失败返回真实进度和续读位置。异常大时长不按完整范围预分配内存。
- 独立音频观察配置为 `audio_review_endpoint/model/key`；密钥仅由宿主固定 HTTPS 通道使用，不发给插件进程。旧配置只在迁移时映射，preview 不返回真实值，apply 后保持停用。空旧密钥不影响独立视觉/转写迁移。
- SSE 通道单次 POST，不自动重放；有界解析实际文本、结束状态及提供商用量，不记录隐藏推理。插件返回必须与宿主实收内容一致。权限、配置、包、素材或任务变化后不能读取此前完成文本，分批撤权也不能泄露前段结果。
