# 分享读取与调用者来源验收

2026-11-01。没有生产安装、外网桥接、模型调用或微信发送；回环桥接使用 httptest，插件运行使用项目内 Windows Python/LPAC。

## 开放范围

share-reader 0.1.6 已就绪的能力只有 `share.resolve_public` 和 `share.resolve_channels`，权限仅 network，不依赖媒体理解插件。未来 `share.read` 仍不可发现。Agent 参数采用宿主 schema：原消息编号加实际可用的分页/超时；不接受可伪造的 URL、object/export ID、Cookie、文件路径或不透明媒体引用。视频号单对象不假装支持不存在的分页。

本机对象桥接通过固定宿主回调执行：地址只读已安装插件配置，限制环回 IP、显式端口和固定 GET 路径，无代理或重定向；超时必须匹配任务请求。回调在 HTTP 前预留状态，重复调用不能重放，失败保持不可重试；成功才完成来源证明。一次性 Transport 不保留闲置连接池。

旧短链绑定只在精确账号/会话/消息或明确对象别名范围内只读复用。旧桥接和 Cookie 并存的失败回退策略不自动迁移，预演会明确阻断。旧配置和绑定仍有兼容引用，因此不宣称整个解析体系已从主体删除。清理仅删除了零引用的 `DecryptData`，保留实际使用的 DecodePrefix 和宿主来源验证。

## 当前请求者与上传者

显式媒体/分享读取和视频音轨精读现在保留当前 actor、请求会话、任务、外层请求键，以及单独的 origin_source_sender。后续回调重新检查当前权限、Agent 状态、任务、trace 和跨会话授权；错误显式证明不能回落为自动上传者身份。授权 Surf 使用规范 host:surf。自动原生处理保持原有身份和幂等键，未改写真实历史。
