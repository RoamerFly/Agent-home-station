# 附件加工与私人声线验证（2026-11-03）

| 环节 | 验证方法与范围 |
|---|---|
| 微信文件收发 | 模拟微信端分别检查输入身份、会话、原件哈希、成品暂存和取消；微信文件收发随核心提供。 |
| 文档加工 | 本机 Windows 打包 Python、Tesseract 中文模型、ReportLab、PyMuPDF 和项目内 Noto 中文字体。测试 PNG 经文字及单元格识别生成可编辑 Word，随后从该 DOCX 导出 PDF，并渲染实际页面。 |
| OCR 质量 | 一张合成图片得到 2 列 3 行。正文“段落”误识为“段沙”，单元格“表格”误识为“表枪”。可查看识别框与置信度。对需精确匹配的字段应先核对。 |
| 声线试听与训练 | 本机 RTX 3060、受管 Python、公开 v2 基座和 15 段合成中文录音。原始时长 78.390 秒，估算有效人声 47.200 秒。SoVITS 与 GPT 各训练 1 epoch，分别得到新权重。使用训练后权重合成了新的 7.340 秒音频。该短训练验证执行链路，音色相似度未做人耳评分。 |
| 私人投递 | 群内发起的试听只进入原主人的私人投递队列。用模拟微信后端核对重复领取、取消未提交部分和接受回执。 |

验收没有调用付费聊天模型，也没有发送真实微信测试消息。生产收件方播放与模型是否会在任意措辞下主动选对工具需要分别观察。复杂 Office 版式按解析器实际支持范围处理。运行依赖与训练权重保存在项目本机目录，不进入 Git。
