# 本地 ASR 与云端 TTS 接入记录

2026-10-31；五个子任务并行，主任务负责协议统一和集成复核。没有真实模型/提供商调用、真实音频下载、微信发送或生产数据迁移。

## 实际接入

- 媒体插件可以选择 remote/local ASR。本地模式只传宿主登记的 profile 和资源版本；宿主绑定原消息、音频摘要和任务，使用固定插件推理源码及登记解释器，在强制隔离环境执行。工具参数不能选择路径或任意命令。原生模型推理质量本轮未验证。
- 资源解析器连接现有登记格式，提供受信初始化元数据；拒绝跨账号、目录越界、VAD/SDK 篡改及清单变化。精确只读文件挂载避免为了 VAD 暴露父目录。通用资源清单摘要不等于模型权重文件完整性的全面校验。
- 本地调用只有一次尝试，失败不重提，结果标记 local_runtime，不虚构提供商用量或计费。本地 ASR 纯推理代码归插件，宿主仍有登记、授权与隔离启动适配；不能声称 Manager 已清除所有具体服务依赖。
- 显式视频音轨读取通过规范入站消息回查并复核来源。每个分段绑定 start/duration，保留继续读取位置；缺少明确原始来源的缓存不会编造身份。
- 默认云端 TTS 接入 speech 包协议及宿主策略，指定命名声线仍走已有身份约束路径。模型、默认声线和指令绑定配置，URL 只进私有结果；核心负责下载、处理和素材登记。合成接口正文按 Unicode 字符限制，超时沿用可表示的真实传输边界。

## 验证边界

媒体协议 Python 20 项、speech 协议 4 项、本地 ASR 兼容 4 项通过。定向 Go 测试覆盖本地 profile、错误音频/版本、单次尝试、不依赖远程密钥、资源篡改及规范视频来源。真实 Windows LPAC 使用项目内 Python 验证资源只读/越权拒绝及云端 TTS stdio 协议；提供商响应为合成回调，没有实际合成或听感验收。

首次全库命令在并行写入未结束时遇到暂时编译错误及生成的 Python 缓存导致包校验失败。编译已修复，缓存已移至忽略的 temp 目录，正式包摘要复验通过，随后启动最终全库回归。临时证据位于 `temp/plugin-tts-local-validation`，不提交。

speech 和媒体包均继续 migration-pending。speech 的包级 GPU 权限目前会被通用执行器拒绝；云端契约实测仅在裁剪后的临时测试副本中执行。必须完成本地声线/GPU、配置迁移及其余入口适配后再正式开放，不能将测试副本启用等同正式可用。云端成品下载/登记路径本轮只完成源码接线，未做完整成品与播放验收。

最终复核修复远程失败包二次解码、本地未知执行误判终态、重复默认语气指令和声线证据等级。配置声线只记为 requested_voice；提供商没有独立回显时，不把配置名写成已验证的素材 VoiceID。提供商回显冲突则拒绝结果。通用插件测试改为固定合成配置，不再依赖生产 TTS 的必填字段。

最后一次 `go test ./... -count=1 -timeout 600s` 通过，证据为 `go-test-verified.log`；vet、Windows/Linux 构建与仓库检查通过。后续已获管理员授权只使用 Flash 非思考进行少量真实模型验收，真实微信测试仅限指定两群；本轮仍未消耗该额度或发送测试消息。
