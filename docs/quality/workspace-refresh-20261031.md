## 准确率与上下文

近期历史原先遇到一条放不进预算的记录便停止选取，会连带丢失更早的短消息。现在跳过超预算记录后继续选取，其省略数量仍明确返回；当前请求不经过这条历史裁剪路径。新增超长视频观察加亲属原话的合成回归。

原生函数接口的历史行不再重复外层 scope，不再携带空 source、引用、回复上下文、受话者数组与观察数组。保留说话者、消息 ID、正文来源状态、来源版本、未知媒体人物和删减标记。单条合成样本由 479 字节/252 估算 Token 降到 361 字节/194 估算 Token（约 23%）；不是整轮账单降幅。训练/GPU 的详细执行说明不再在每轮工作区上下文重复注入，按需读取 self-tools.md，仍保留执行以实际结果为准的短规则。

本轮没有新的真实模型准确率百分比。静态和离线回归只能证明这些已知逻辑及来源约束，不证明开放式聊天不会犯错。

## 工作区自主能力

新增 project_create(name, shared?)，直接建立或重新打开当前会话 projects 下的项目目录；共享项目仅可信主人可创建。已有文件不覆盖。后续沿用 server_read/write/edit、隔离进程和共享开发指南，能在已有文件权限内写工具与维护项目，无需每种任务新增业务封装。

入口遵守现有 Host.Mode、真实请求者、会话和账号授权；只读/禁用模式不能通过它写文件。目录使用原有逐级固定句柄、拒绝符号链接的实现。名字限制为安全的单个目录名，并拒绝 Windows 保留设备名。它不把部署源码、认证资料或其他账号自动变成可写工作区，也不自动安装外部依赖或发送文件。
