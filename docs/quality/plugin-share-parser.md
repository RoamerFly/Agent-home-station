# 分享解析进程迁移验收

## 本轮实际改动

公开分享与快手解析进入 `plugins/share-reader/runtime/public_share.py`；`main.py` 是 MCP stdio 进程入口，仅使用 Python 标准库和调用期间的宿主 HTTP 读取代理。没有生成固定结果的模拟业务代码，也没有直接网络套接字或微信接口。

已移植原公开页、快手解析的核心规则：只解析精确作品；允许同作品主/备播放地址和规范页重试；拒绝作品编号冲突及不受信任 CDN；脚本不执行；标题、播放地址、应用落地页不能代表视频已被观察。实际网页正文与候选地址各有分页位置，内容变化时拒绝旧哈希续读。

生产入口仍使用旧实现，整个包保持 migration-pending，未开放发现或安装。视频号的凭据与原生桥接、B 站等其余平台、媒体下载/素材登记及媒体理解协作尚未迁完。因此本轮是实现迁移进展，不是完成第二个可用业务插件。

- `TestLiveShareParserIsolatedExactWorkAndRevocation`：实际 Windows LPAC 子进程运行新 Python 代码，HTTP 回应为安全合成 JSON，不访问真实网络。返回精确作品和播放地址，未错误声明视频已下载/已观看；同键恢复不再次读取；代理读取过程中撤权后不保存/暴露结果。
- 隔离测试只将临时副本中已实现的公开解析能力置为可执行，删除该副本的媒体理解依赖。原包仍为 migration-pending；测试先确认原包安装被拒绝。不得以临时测试副本冒充正式完整能力。
- 插件清单摘要检查通过，12 个受检文件；pluginhost/pluginruntime/mcptools 全包离线测试通过。未运行真实模型或微信发送。

真实 LPAC 测试使用项目内 `dist/windows-native/runtimes/windows-python-cli/python.exe`，通过 `WECHAT_PLUGIN_TEST_PYTHON` 显式启用。Linux 隔离没有在本轮实机验证，Windows 进程通过不能替代 Linux 验收。

## 视频号固定接口增量

`runtime/channels.py` 已加入独立解析进程，处理视频号短链接或 export/nonce 对象，通过元宝解析接口获取预览位置，再通过预览接口获取精确作品媒体位置；解码键和对象编号使用无精度损失的十进制 uint64 校验。返回值明确 media_locator_only，并不生成视频总结。

宿主新增清单固定接口、x-host-only 配置隔离和 JSON POST 代理。元宝 Cookie 不发送给视频号预览/助手接口，助手 Cookie 不发送给元宝接口。返回的预览页 Referer 保留给对应接口，但限制同源路径。重定向不跟随；连接失败和 HTTP 失败不自动重试，不回显原始网络错误或私有响应正文。

`test_channels.py` 5 项加公开解析 7 项，共 12 项 Python 合成测试通过。真实 Windows LPAC 测试现在同时覆盖短链 → 宿主固定接口 → 预览作品流程，网络回调全为合成响应，并检查 Cookie 范围与 Referer。测试副本仍与正式 pending 包分离；没有测试真实登录或服务器接口可用率。

本轮 `go test ./... -count=1 -timeout 300s` 通过；其后为保持旧预览接口行为增加 Referer 约束，已重新执行 pluginhost/pluginruntime/mcptools 和 LPAC 测试。`go vet ./...`、Windows/Linux 全部 cmd 构建、JS 语法和仓库检查通过。安装确认页面展示凭据目的接口，合成浏览器浅深色与 375/1440 宽度通过，并查看了窄窗口截图。

固定接口代理要求业务来源绑定回调，但生产会话中的具体绑定适配器仍未接入。仅验证测试回调不能证明生产来源约束已完成；本地对象桥接、媒体解码和素材校验也仍待迁移。

## 宿主结果核验增量

`internal/admin/share_plugin_binding.go` 保存宿主实际收到的作品、作者、标题、播放位置及无精度损失的解码键；`ValidateResult` 要求插件结果与这份响应逐项一致。核验前后都重新调用授权与来源版本检查。模型可见检查点不含私有播放位置或解码键，私有交接值由宿主响应生成，插件不能替换该值。解析成功仅表示取得媒体位置，不表示已下载、已观察或已发送。

`TestShareBinding*` 覆盖结果替换、缺失状态、重复 JSON 字段、额外字段、未知结果、跨账号/会话、来源版本变化、核验过程中撤权、无效 uint64、错误作品以及不完整解析链。来源检查失败时没有可用媒体交接值。

`TestLiveShareBindingPythonResultMatchesHostProof` 已在 Windows LPAC 中执行真实 Python 解析进程，并经过插件 Controller、宿主固定接口代理及上述实际结果核验器；网络响应全部是合成数据。检查点完成后，同幂等键不会再次提交解析 POST；持久公开结果不包含合成私有播放令牌或解码键。本测试仅将临时包副本提升为测试可执行状态，正式包仍为 migration-pending。

生产接入仍未完成：需要在媒体预处理发生前取得稳定的原生来源版本，接入当前权限检查，并完成私有媒体交接的持久恢复与下载/解码/素材登记。现有本机分享入口尚未切换，不能把上述合成进程验收等同于生产视频号全链路可用。

## 私有媒体交接恢复增量

宿主数据库新增 `job_private_results`，与公开任务完成状态在同一 SQLite 事务中提交。`VerifiedResult.Private` 仅由宿主验证器生成，不参与 JSON 序列化，不进入 `Job`、任务分页或插件初始化配置。它保存在宿主账号数据库中，不放进插件可写数据目录；这属于宿主访问隔离，并非新增磁盘加密承诺。

`PrivateJobResult` 恢复读取核对完整任务快照、当前插件版本/摘要/授权、配置版本、取消状态，并要求调用方在读取前后检查来源版本、遗忘与会话权限。公开任务完成但没有私有交接的旧记录不会凭空补齐，也不会自动重新解析。

新增离线测试验证关闭/重开数据库后恢复、公开列表无私有信息、调用者修改返回值不改变存储、配置/权限/账号/会话/来源变化后拒绝读取。SQLite 触发器注入写失败，验证公开状态和私有记录一起回滚，原任务仍为 submitting；解除故障后可以仅重试本地检查点。该故障注入不是实机断电或物理磁盘故障验收。

实际 LPAC 解析测试进一步通过 Controller 写入私有检查点，再从原任务读取并与宿主核验信息比对，同键调用没有新增解析请求。pluginhost/pluginruntime 全包离线测试、相关 admin 测试和三包 vet 通过。生产媒体入口及兼容迁移仍未接入，本轮未改真实库或本机程序。

## 接收入口接线与授权策略验收

后续增量已将安装后的分流接入 `resolveReceivedChannels`，由 `receivedSharePolicy.resolve` 完成原生短链、插件执行、私有结果恢复，再交给原媒体下载/解码/观察流程。该路径使用当前权限与原生消息指纹核对，开启记忆时增加事件版本检查；未安装账号仍兼容旧实现，已安装但停用的账号不能走旧实现。

真实 Windows LPAC 测试运行上述生产策略与真实 Python 解析器，合成原生消息和网络响应覆盖开启/关闭记忆两种模式；首次调用与重用原任务均成功恢复同一媒体信息。另覆盖跨会话、原生正文修订、读取权限撤销、遗忘、停用不回退。完整 `go test ./internal/admin -count=1 -timeout 300s` 通过（196.657 秒），pluginhost/pluginruntime 全包测试通过，三包 vet、日志 JS 语法与仓库检查通过。随后错误原因映射改动又执行相关 admin 测试通过。

这替代了前文“生产入口尚未接线”的阶段状态，但未完成正式包启用、旧配置迁移、其他平台/桥接兼容、媒体理解插件协作与旧代码删除。本机 EXE、真实配置和记忆数据库均未更新；本轮没有真实网络平台解析、付费模型或微信发送验收。

## 后续必要条件（保持原目标）

1. 视频号凭据仅提供给确切平台端点，原生登录与来源核验留在核心；不能使用任意 Cookie/任意目标代理。
2. 私有播放地址仅交给宿主媒体读取与素材校验，不写入模型输入或公开日志。当前合成验证器移除该字段；生产验证器仍需实现。
3. 媒体理解记录实际读取范围，失败不返回仅凭标题的总结；群偏好和发送对象继续由核心校验。
4. 完整契约验证和隔离副本迁移通过后，才切换原入口并删除主体中的替代实现。本轮未修改真实配置、来源隔离状态或历史消息。
