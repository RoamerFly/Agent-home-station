# 媒体插件来源适配与费用入账增量

日期：2026-10-31。此记录为轻主体重构中的一个增量，不是整体交付报告。

## 已接入

收到的图片、表情采样图、分享链接图片及自动视频采样帧统一调用来源适配器。账号未安装媒体插件时保留原兼容入口；存在安装登记后，停用、移除、运行环境或校验失败均不回退旧视觉服务。已安装视觉插件不会偷偷调用旧 ASR 配置；当前明确返回尚未读取声音内容。

每次调用绑定实际原生消息、账号、会话、发送者、事件版本、遗忘边界、附件元数据和配置版本。图片字节复制后计算摘要，只有本次图片引用可被宿主展开为请求数据；插件不能传入任意本机路径、远程图片地址、其他模型或思考参数。当前图片校验覆盖格式头、字节大小、摘要和来源，不能据此宣称完整图片解码通过。

模型密钥仅由宿主代理添加。返回观察必须与实际接口返回的文字、终止原因和图片引用逐项一致，模型隐藏推理不写入结果。公开任务只有状态和来源，观察正文存入私有检查点。同一已完成任务在控制器重启后恢复结果，不重复请求模型；不确定结果保留待核对状态。

费用使用宿主实际 HTTP 响应中的用量，忽略插件自行报告的统计。缓存命中与未知用量沿用现有账本语义；失败的 HTTP 尝试也记录请求数，未知不能写成实际零消费。一次任务只允许提交一次模型请求，参数或引用核验失败不会发起请求。若实际调用后费用落盘失败，任务不返回观察成品，也不自动重新调用。
