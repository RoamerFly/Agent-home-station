## 配置、任务和权限

- 已安装能力读取插件配置；旧 speech/channels 设置无第二写入口，只用于显式迁移。坏旧语音文件不阻断主体启动，预览失败不使用默认值冒充迁移成功。
- `Manager` 不再持有闲置的 TTS 配置或默认值。旧 RAM 测试替换为真实临时 JSON/插件配置来源，179 个受影响用例定向通过（154.905 秒），保留原有安全与行为断言。
- 外部连接首次明确迁移后以 SQLite 为唯一权威，GET 不激活、不创建第二配置源。
- 同 ID 升级先验证新 schema。兼容时保留原配置行、密钥、修订及历史；不兼容或密钥可见性变弱时事务拒绝，API 明确返回 `configuration_migration_required`。本次权限确认不会继承新增权限。
- 旧未知任务保留原 digest、版本、配置和幂等键，不自动重绑或重提。取消和迟到结果不能复活任务，生成完成不能替代微信回执。
- 命名声线、源 hash、范围、任务与目标约束由宿主复核；替换为默认 profile、修改音频引用或 hash 均在实际 Controller 回归中被拒绝。

## 轻量与上下文观察

- 固定合成输入的原生模型调用捕获：system 由 10,016 字符、9,318 保守估算 Token，变为 9,136 字符、8,623 估算 Token，少 695（7.46%）。这是项目估算法，不是模型 tokenizer 或提供商账单；不能外推所有对话。
- 未安装插件、或已安装但话题无关时，不再每轮插入 RVC/YuE/命名语音操作教程。`discover_tools` 返回对应包的完整说明，保留 `mom` 原请求、不可替代声线、来源和微信分段/回执约束；`SystemSongPolicy` 没有删除。
- 新合成空目录、无插件/无可选 Python、GPU、设备或 broker 配置时，管理主体独立到达 healthz。五次启动观察与构建体积记录在本机 `temp/plugin-completion-benchmark.json`；参照为上一轮 b9bacd8，不是最早单体。样本量小、缓存不同，不据此宣称整体性能提升或百分比达标。

## 本机迁移和恢复

交付程序位于 `dist/windows-native`。程序、验证过的源码 catalog、helper、controls 清单和训练入口登记按来源 SHA 更新；微信原生二进制保持不变。管理维护过程暂停原配置、通过认证接口操作，退出后逐字节恢复原配置。

本机升级以插件原有授权和启用意图为准；对照升级前后的配置/密钥行指纹、插件任务和原生登录库。实际结果保存在本机私有 `temp/plugin-final-local-migration-result.json`，不在 Git 中复制真实数据。最终交付答复记录源码提交与远端核对值。

失败时保留新 SQLite、已安装版本、原任务及实际回执，暂停处理并由兼容版本修复；不自动回切旧 JSON 或重放未知任务。catalog 更新只操作经核验的源文件，不递归清理数据目录。用户要求本轮不生成备份，未创建旧数据备份，也未触碰待删除目录。
