# 手机插件管理入口与旧检索实现精简

日期：2026-11-01。环境：Windows amd64、Go 1.25.3、PowerShell、Edge headless。全部验证使用合成账号、任务、配置与资源；未使用付费模型、真实设备或微信发送。

## 已删除和迁入

- 删除独立手机 HTML 页面、`mobile.js`、静态资源映射和旧导航；来源详情中的设备任务链接改为打开插件详情的任务区。
- mobile-control 0.4.0 声明设置、任务、素材、状态四个宿主组件。服务端拒绝脚本、URL、未知绑定/操作和不相干的组件操作组合；页面实际按声明顺序、标题及省略状态渲染，不只是读取后忽略。
- 设置通过固定插件 action 写原 `mobile.Repository`，没有第二套通用插件配置。API DTO 只包含设置版本、设备/动作范围、预算和连接登记状态；不返回或接受旧命令、参数、环境、请求头、路径和凭据。旧连接档案登记仍待迁移，新页面保留已有登记，不提供任意命令编辑器。
- 保留包启动/停止，设备执行开关不能代替插件启用。未安装且无历史时不显示空设置；移除/未安装但有真实历史时提供归档任务、截图/录屏和停止能力，不提供配置或新建。
- 删除 `internal/plugincompat/websearch` 及主体的旧付费搜索调用。已安装 Web 插件停用或失败时不能回退。未迁移的旧官方付费配置返回 `web_plugin_migration_required`，不偷偷改成公共搜索或其他音频目录。迁移后的音频检索别名返回候选页面，不证明已下载、播放或发送。
- 修复迁移预演将 `legacy_web_search_enabled`、`legacy_web_fetch_enabled` 误传入闭合 schema 的问题。它们只作来源审查；实际配置只写声明字段，保留原 public/deepseek 后端及宿主私密密钥映射。

## 状态和操作保护

插件 action 与兼容 URL 共享同一任务/设置实现。认证、CSRF、账号选择、配置修订及排空检查仍在宿主；取消和停止在排空期间保持可用。归档不是另一套数据导入，不复制媒体或旧账本。

异步动作固定账号、插件、页面版本；迟到响应不能覆盖新页面或清掉新草稿。保存过程中继续编辑仍保留未提交内容。任务创建返回未知结果时，用户手动重试复用原请求编号；只在目标/设备变化或确认成功后更换编号，不自动重发。

浏览器测试使用真实 index DOM、CSS、console 初始化与顶部保存脚本，阻断一切外部请求，以合成 API 响应驱动。覆盖真实后端使用的嵌套 diagnostics、归档字段和初始停用→启用流程。已查看宽屏浅色、窄屏深色和归档截图；紧凑布局中刷新合入标题，保存固定右上，内部表单无独占保存行。

## 声明边界

UI v1 每种组件最多一次，绑定和动作是宿主固定协议，不允许插件定义 JavaScript 或任意 URL。目前 `host_data` 的业务管理动作仅为 mobile-control 接通；其他插件仍使用既有配置/任务界面，不能据此声称所有插件 UI 和服务实现已经迁出。安装或声明存在也不代表启用、可执行或具备发送权限。

手机具体队列与录屏分析仍在主体；旧连接档案登记和兼容 API、其他可选服务、公共内容发现与部分网页读取实现仍待迁出。真实账号配置迁移、生产 EXE 更新与全项目逐页验收尚未完成；没有创建新备份或触碰待删除目录。功能保留的最终验收以完成正式迁移后的状态为准。
