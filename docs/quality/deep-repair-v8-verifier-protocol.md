# v8 结构化审核验收协议

本轮延续原 240 个安全合成场景、37 个固定审核候选及其原有放行阈值。新增独立的 7 个回归候选，直接来自 v7 已确认错误的安全合成输出；保留完整多气泡候选、原输入、人物及引用关系、媒体观察、来源版本和原报告摘要。没有真实聊天或生产资料。

## 与 v7 的可比较范围

原 37 和 240 的问题、候选及预期未变；生产审核路径已改变，因此 v7 与 v8 不能混合计算同源通过率。v8 使用当前配置的同一模型，通过独立 `ChatGrounding` 接口开启 JSON 审核与推理。初值为 8,192 输出 Token（含提供商推理用量）、120 秒、高推理强度；普通生成仍为 1,024 Token。审核不执行工具，不保存模型隐藏推理。

包装器显式透传该接口。有效审核模型、JSON、thinking、推理强度、输出预算及超时进入配置指纹；每次审核另保存实际传入的已规范化选项。兼容接口不发送 DeepSeek 专有参数的情况明确标为 `not_sent`，不会宣称已经启用推理。单审核测试调用者的外层截止时间为 130 秒，完整生成回合为 480 秒，使生产审核的 120 秒预算不被旧测试的 60/90 秒提前截断。

本固定协议只接受默认审核设置；私有配置显式写入其他审核预算、强度或未知审核字段时直接报错，不能静默忽略并声称生效。外层截止时间由实际审核超时加宽限推导，单审核为 `timeout+10秒`，完整回合为 `3×timeout+120秒`；离线验证确认 180 秒设置可推导为 190/660 秒，不被固定数值截短。生产应用仍可配置其他预算，采用其他设置进行质量验收时必须声明新的实验配置。

模型仅返回逐气泡的判定与违规项，由宿主关联完整候选摘要并聚合。固定测试继续要求坏稿全部明确拒绝、正确控制至少 95% 接受；错误、超时、无效协议和不确定不计作成功。原始报告逐例保存，禁止同源重复抽样挑选最佳结果。

## 七个完整候选重放

夹具位于 `internal/companion/testdata/deep_repair/v7_confirmed_candidates.json`。每例包含原生产摘要、原合成报告摘要和实际候选。重放统一平移当前消息、全部来源、历史及引用中的绝对时间到当前执行时刻，保留原始相对时差；通过真实 Store 生成来源证明，再映射原候选中的来源编号。正文、人物、素材、所有气泡和预期均保持原样。报告同时保留原件、时间平移量、新旧来源映射及实际审核依据。

时间平移可能使原候选中“这会儿都两点了”等绝对时钟措辞与重放时钟不同；必须人工查看实际违规项是否也覆盖原先确认的错误，不能仅凭一个新的时钟错误宣称“没吃饭→正在饥饿”等原问题已修复。

运行入口为 `scripts/deep_repair_v7_regression_evaluate.py --config <私有配置> --report <新的本地报告>`。显式 `--resume` 仅继续相同源码、协议、夹具、配置和驱动指纹下缺失的用例，不重跑已完成用例。所有报告均在本地临时目录保存，包含真实提供商用量、逐例耗时、实际最终 JSON、错误阶段及未修改候选验证。

## 已完成的离线验证

包装器假模型验证已实际经过生产审核入口，验证普通包装器与嵌套来源包装器均调用结构化接口，完整宿主摘要为 64 个十六进制字符，实际预算为 8,192 Token / 120 秒 / high。7 个完整候选重放、来源哈希、逐气泡来源证明及候选原文不变检查已通过。此记录不代表真实模型 44 例或 240 例已通过；实际结果以新同源报告及人工来源审核为准。
