# 项目开发与服务托管整合验收

日期：2026-11-01。仅安全合成数据、临时工作区、合成子进程及本地传输；没有新增付费模型调用、真实微信消息、真实训练或生产配置改写。

## 已接通的实际路径

- `project-development` 0.2.0 通过隔离 stdio 解析项目登记与工具协议，提供独立读、写、执行能力。12 项既有工具别名统一进入安装控制器；缺包、停用或来源变化不走旧实现。主体继续执行受限文件与进程操作，插件不能改写原命令、工作区或授权。
- 项目请求绑定账号、请求者、来源、包和配置版本。宿主实际失败保留类型与“尚未启动”语义；明确未启动允许修复后重试，未知操作不会重放。长任务继续使用原请求键、进程编号和可调后台超时。
- `music` 0.4.0 新增服务控制能力。通用 `ManagedServices` 托管精确自有进程、日志和停止信号；不接管端口上的陌生进程。停止插件先检查其全部服务任务，忙时拒绝；成功停止只回收该插件服务。退出宿主回收全部自有服务，保留管理员启用意图。
- 项目迁移只把旧 full 模式视为完整能力意图，空配置实际应用后保持 disabled。read/files 等状态必须重新审查权限；roots、隔离和执行档案仍由宿主管理，不复制为插件配置。原配置变化使旧审批哈希失效。
