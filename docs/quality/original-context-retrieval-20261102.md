## 改动

- 原始记录查询增加会话内消息锚点、媒体类别、时间倒序和轻量目录；条件在 SQLite 查询内执行，分页前不加载全部正文。相同时间按接收序列区分。锚点、过滤条件、授权范围和版本均参与分页约束。
- 目录只返回来源编号、时间、人物和可读长度等元数据，不附带完整音轨或画面观察。旧记录的原生媒体类型也可作为候选；分享候选不等于已经确认的视频。
- 原始记录读取增加 `part=observation/transcript` 与 `media_index`，按 UTF-8 字节分页，返回有效长度、版本、可读部分及续读位置。音轨读取复用保存的识别内容，不额外调用 ASR 或模型。默认原文读取保持兼容。
- 对明确带数量的“之前视频”请求，先只读查询当前会话、引用锚点之前的来源目录。首批八条是预取批量，不是请求总量上限；更大范围仍可分页。资料不足时可继续调用 `wechat_read` 或 `video_inspect`。
- 区分“当前上下文没有附带”与“历史不存在”。已有来源目录却未尝试阅读时，允许一次补读规划；仍跳过则标为 `history_materials_not_inspected`，不能记成普通的模型安静。真正执行读取后报错，仍允许说明具体失败和续读位置，不由未读检查吞掉错误回复。
- 锚点无法核验、记忆修订/分页快照变化增加独立诊断，不解释成网络错误。
- 工具发现目录缩短摘要，完整协议仍按需加载。原生函数模式不再沿用旧协议的 128 工具/64 KiB 截止，避免已登记插件工具被静默丢弃；旧协议仍明确报告容量边界。
