# 同步外部 HTTP 与音乐声明迁移

日期：2026-11-01。本轮只使用合成账号、HTTP 回环、WAV/二进制文件及隔离进程；付费模型、真实平台接口、真实微信发送、生产配置写入均为零。

## 实际改动

`external-tools` 0.3.0 的 `external.http_request` 现已接入同步工具发现、安装控制器、单次宿主代理与响应解释。无包、停用、篡改或来源变化时不回退旧同步实现。仅无 Job/Poll 的声明进入新路径，其他异步及 MCP 能力仍在兼容路径，不能视作整个插件完成。

端点、请求头、请求模板及凭据留在宿主；插件只接收当前工具的无凭据声明。宿主持有精确原始参数，Python 只回传其不透明摘要，不重新序列化请求数字。每次调用只携带所选声明，不复制完整工具目录。实际来源、账号、请求者、遗忘 epoch、包/配置/旧声明及凭据版本在调用和恢复时重新核验。

同步响应由 Python 解释，宿主按实际响应字段和字节核对。25MiB 二进制不进入 stdio；实际正文及已核验结果保存于账号私有目录，小检查点绑定文件哈希、大小和请求身份。恢复重新校验文件，未知提交不换键重发；生成结果仍须经过核心素材与投递流程。

管理页手工测试使用绑定登录会话、所选工具和参数的 `host:external-test` 管理身份，不伪造微信发言者或群目标。注销、撤权或停用插件会阻止执行与结果暂存；两项受保护路由回归验证登录/CSRF、注销取消在途请求及零微信发送。

兼容回归覆盖 130 字符旧工具名、空描述、布尔与空值、JSON 标量、对象/数组文本、超精度整数及 JSON 媒体地址。旧请求传输的 JSON/二进制资源边界保持；本轮未新增 provider 能力。超过真实 stdio 帧大小的非标准大 JSON 响应仍会明确失败，不能按已验证的二进制引用路径宣称所有大 JSON 均可处理。

音乐的八项详细工具说明、schema 与原生采样目录移入 `music` 的两个校验资源。缺失、停用或修改安装包不使用核心声明回退。核心只保留包声明驱动的通用类型检查和原请求/声线/任务约束；实际原生参数范围由后端核验。本切片核心净移出 4,970 字节源码，不代表整体程序体积或 Token 已下降。

## 验证

- 音乐、RVC、外部 HTTP、插件及旧异步任务的组合定向回归通过：78.624 秒。旧语音测试局部安装官方能力，保持凭据、一次 HTTP、素材暂存和权限断言。
- 宿主/运行时/旧声明模块完整包测试通过：pluginhost 11.611 秒、pluginruntime 8.493 秒、plugins 4.367 秒；相关 vet 通过。
- 真正的 Windows LPAC 与项目内 Python 跑通同步文本和 25MiB 合成二进制；两项各只有一次 HTTP。其余合成测试覆盖来源遗忘、撤权、取消、伪造输出、文件篡改、未知不重发及大结果恢复。
- Python 外部协议 10 项、音乐协议 20 项及迁移预演 26 项通过。迁移浏览器 375/1440、浅深色和 JS 语法检查通过。
- 第七项迁移步骤已可实际应用空配置并保持禁用，随后可显式启用；MCP/async-only 阻塞，旧账本变化使原审批失效。端点与密钥不出现在公开预演。
- Windows/Linux amd64、CGO_ENABLED=0 的全部七个 cmd 构建通过。没有重复此前约 400 秒的整库测试；最终全项目交付前仍需统一完整回归。
