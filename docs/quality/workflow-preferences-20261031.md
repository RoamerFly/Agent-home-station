# 会话偏好与操作分组调整（2026-10-31）

## 使用方式

进入「会话」选择群聊，打开「备注与管理」，在「会话偏好」填写自由文本并保存。例如：

> 本群收到视频号、快手等分享时，默认总结主要内容并发送；回复简短，避免重复标题。

偏好仅作用于当前账号的当前会话，与「事实与关系备注」分开保存。没有设置偏好的会话不会增加该段提示。清除 AI 记忆保留管理员偏好；清空偏好文本并保存可以取消。保存采用版本校验，修改偏好会使旧上下文依据失效。

分享卡片沿用现有内容读取和群聊判断流程，包括原生视频号卡片和链接分享。自动考虑分享仍需要已有的群观察、自主参与、文字回复及视频读取权限。偏好不提升权限、不伪造 @，不增加单独的模型分类调用。快手短链接跳转到视频页后使用视频读取，读取失败不把应用宣传页面当作视频内容。此轮没有增加普通纯文本 URL 的自动检测。
