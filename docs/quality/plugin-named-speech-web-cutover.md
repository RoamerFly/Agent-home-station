## 已完成的实际链路

- speech 0.2.0 新增 `speech.synthesize_named`。旧 `synthesizeLibraryVoice` 不再执行 `project.Entry`，而是调用安装包、固定宿主 `wechat/local_speech` 和已校验包内 runner。完整推理代码已从通用 scripts 移入插件；旧源码 CLI 只作开发兼容，登记到工作区的旧入口仅提供明确诊断，不携带业务副本或源码仓库路径。
- 所选 GPT/SoVITS、参考录音及转录仅按四个精确原始文件只读挂载，不逐任务复制权重，不授予整个私有库。继续要求原 owner 和 CrossConversation 权限；撤权、素材变化、任务取消及配置/包变化使完成结果不可读和不可暂存。
- 宿主校验实际 WAV 的字节、SHA、采样率和时长，并核对 runner 报告的原文、权重和参考摘要。参数可调整真实推理设置，不能替换文本、资源、路径或流模式。长原文及浮点超时保持原值；本地没有新增 2000 字提供商上限。
- 持久化意图、单次 broker 和私有 checkpoint 负责恢复；结果未知不重提。成品目录在较短的账号私有 speech-jobs 下，修复真实 Windows 文件授权的路径过长问题；临时 scratch 回收，成品不删除。短音频验证不能当作真实声线听感通过。
- 本地 profile 与云端配置独立。Go 迁移只读核验登记和解释器证明后映射本地 profile，公开预览无私有路径/声线；资源变化使旧批准失效，应用保持停用。Python 预演只标待宿主验证，不假装资源已可执行。该证明覆盖登记/解释器及所选声线文件，不新增对全部第三方 SDK/基础模型的质量认证。
- web-search 0.3.0 新增 `web.discover`，实际解析 RSS/Atom、B站列表与关联、图片和器乐目录。修复公共搜索的 GET 代理被拒问题，查询、后端、确切 URL、大小和超时均绑定当前任务；历史、去重和分享仍由宿主验证。
- 删除 Hub 旧三个 web 执行分支、旧搜索/抓页/音频目录/订阅发现联网实现及失效测试。保留 DNS/IP/TLS、公有媒体下载和通用素材解析。缺包/停用/无隔离执行器均不回退旧实现，也不消费冲浪预算。
