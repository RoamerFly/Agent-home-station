# 手机规划迁入独立插件进程

日期：2026-11-01。运行环境：Windows amd64、PowerShell、Go 1.25.3；浏览器为本机 Edge。

## 已实现的迁移

`mobile-control` 0.2.0 的唯一就绪能力为同步 `device.plan`。详细设备提示、工具 schema、格式修复与下一步规划已迁入 Python MCP 进程，删除原 `backend/*.go`、主体静态引用与旧规划器回退。主体只保留来源、授权、当前模型代理和独立动作校验。

插件只获 `model.invoke`。原始 PNG 和模型密钥留在宿主，插件取得绑定任务与观察的摘要，并通过当前聊天模型的原调用路径请求屏幕描述和决策，继续沿用模型名称、思考模式、强度与费用统计。逻辑账号/会话身份按协议进入审计元数据，不含登录资料。

宿主校验任务/原请求者/目标/步数/事件/录屏/观察、设备设置 revision、插件版本和配置、当前模型配置指纹及取消状态。返回动作必须和最近一次实际模型工具回复相同，再通过独立的动作参数和允许范围检查；插件不能伪造模型决定或执行设备动作。

未知模型结果立即锁定本次调用；只有模型实际返回但格式或动作无效才允许一次修复。成功结果不允许再次采样改变。复用已完成请求读取原宿主核验结果，不重复调用模型。JSON 来源比较复用既有有界解析器，拒绝字段重复及尾随数据，不再增加第二套递归 scanner。

缺失、停用或异常的规划插件会阻止排新任务，并给出插件中心提示。查看、取消和停止旧任务不依赖规划插件。管理页同时校验账号与异步响应版本，旧账号的加载/保存/取消响应不能覆盖新账号页面；插件状态刷新不会覆盖未保存草稿。

## 边界与后续

`device.observe`、`device.act`、`device.record` 仍未作为独立插件能力开放。包中的 `runtime/bridge.py` 是旧兼容入口引用的后端源码；独立 `main.py` 不导入或启动它，没有 ADB/网络/设备资源授权。设备 broker、持久队列、旧配置、管理路由和录屏分析仍需迁出，不能将规划器就绪等同手机功能已全部插件化。

审计当前为 9 类插件、5 类提供受限就绪能力、112 个可选源码命中（按归属统计，可重复命中），4 个内部可选依赖；静态插件实现依赖已从 1 降为 0。`--require-light` 仍应失败，整体目标继续进行。

本轮付费模型调用与真实微信发送均为 0；未操作真实设备，未更新生产 EXE 或账号配置，未复制模型、重建记忆、创建备份或触碰待删除目录。
