# 2026-11-01 插件收尾验证记录

本批继续既有迁移，不新增付费模型测试，不发送真实微信消息，不运行真实训练、GPU 或物理设备操作。

## 实际变化

- 手机队列状态转换进入 mobile-control 0.6.0；宿主保存授权、执行声明和核实过的效果，未知执行在重启后进入待核对，禁止自动重放。
- 外部 HTTP/MCP 配置首次明确迁移后以 SQLite 为唯一权威，支持 CAS、分片、大配置和失败恢复；GET 不触发迁移，凭据不回显，成功迁移重放不重复导入。
- RVC 训练实现与依赖进入音乐包。旧 CLI 只转发到登记且校验过的安装包。Windows 通用执行入口仅在明确、已授权的训练请求中增加该代码目录只读挂载。
- 不在生产调用链内的旧云端声线 SDK 移入语音插件开发目录；核心使用不含服务客户端的配置及错误类型。
- 分享读取移除未安装时的旧解析回退；视频精读帧分析改经 media-understanding，缺插件不会借聊天密钥直接调用视觉模型。
- Windows 源码快照构建补入声明式插件 catalog，桌面构建不再引用已迁走的旧 RVC requirements。

## 验证与限制

- Windows/Linux amd64、CGO=0 的七个 Go 命令均构建通过；Linux 结果属于交叉编译，不表示 Linux 进程和设备实测。
- `go vet ./...`、静态前端 JS、PowerShell 构建脚本语法检查通过。
- 桌面控制器 55 项、窗口生命周期 86 项通过，包括私有桌面上的 8 次退出周期与 12 个并发重复启动探针。
- 合成迁移浏览器检查覆盖浅深色、375/1440 宽度、确认失效、阻塞原因和不自动启用；已人工查看桌面浅色和窄窗深色迁移弹窗截图。这不是所有产品页面的本轮视觉重验。
- 实际 Windows LPAC 使用项目内 Python 和合成服务验证工作流、语音、分享、外部任务及训练代码只读路径；没有付费提供商调用。
- 首次 `go test ./... -count=1 -timeout 600s` 失败：旧能力状态断言、Job 协议多投影调度字段，以及管理员组达到总超时（当时停在 SQLite 清理）。断言和协议字段已修复并定向复验；清理超时没有可确认的生产死锁根因，不保留未经证实的夹具改动。
- 管理员 816 项随后分为三个不重叠分组。第 1、2 组分别通过，耗时约 264、254 秒；第 0 组约 221 秒后仅一个实际 LPAC 分享初始化失败，该用例串行复验通过（2.726 秒）。另有两次直接受限 launch/分享 MCP 初始化成功。保留这次间歇性断连为未解释的稳定性限制，不把串行复验当作已消除间歇故障；不宣称原全量命令或三个分组一次全绿。
- `audit_plugin_boundaries.py --require-light` 仍返回失败：名称扫描同时列出宿主授权、素材适配、测试兼容实现及尚未实现模板。其结果保留，不宣称已经满足该粗粒度检查；生产命令依赖闭包没有旧 mobile 控制器、旧 bailian 客户端或插件开发 SDK。
- visual-generation、speech.train 等未实现能力继续隐藏。RVC 已有 CLI 的迁移不代表新建通用训练 API。
- 本批没有新的 Token/启动性能对照测量，不据源码体积变化声称达到新的百分比指标。没有真实 Embeddings、模型质量、听感、手机播放或新微信服务器接收证据。

## 本机更新边界

实际部署为 `dist/windows-native`，保留现有微信原生二进制和私有数据。程序、验证过的 catalog、隔离 helper 和 controls 摘要可以更新；声线、模型、历史与生成媒体不搬动。配置迁移经现有认证管理接口执行，不直接拼写 SQLite。首次安装迁移保持禁用，随后只恢复原有启用意图及权限。未知任务不重提，缺失资源明确保留阻塞原因。

不生成旧数据备份，不触碰待删除目录，不构建镜像、不发布 Release、不运行 CI。
