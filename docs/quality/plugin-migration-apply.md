# 插件设置迁移与官方检索后端验收

2026-11-01。本轮未应用生产迁移，未替换生产 EXE，未使用真实模型额度或微信发送。迁移和浏览器验收只使用合成账号与配置。

## 应用链路

管理 API 可只读预演并逐插件确认应用。确认绑定账号、来源摘要、准确官方包摘要与所选权限；请求不接受配置正文、密钥或任意文件路径。服务端再次读取权威旧配置与受信包目录；未声明的服务商、混合后端、来源变更、摘要变更、已启用实例或过期修订均拒绝。

迁移先持久绑定来源、包、权限、配置私有哈希和安装实例，安装始终 disabled。配置写入与完成标记同一 SQLite 事务提交；崩溃后只有同一条绑定记录可恢复。重复确认不重复安装；并发配置或秘密值变化不被误认为完成。旧配置保留，不复制模型、素材、记忆或历史；启用插件是独立操作。

桌面部署提供 `catalog_directory`，官方包源位于可独立分发的 plugins 目录；主程序仅嵌入声明元数据。构建脚本按清单校验并暂存官方包源码，拒绝链接、未知文件、哈希不符及不一致旧输出，不删除或备份旧目录。

## 检索兼容

web-search 0.2.1 提供显式 public/deepseek 后端及单独宿主持有的 search_key。DeepSeek 只通过固定声明路由调用，query/count/max_bytes/timeout 绑定原请求；count=6 是默认值，旧的 128 字符偏好不再冒充提供商限制。实际响应形成来源证据，没有静默公共搜索回退。旧官方检索配置只在声明完整时映射，仍需管理员确认。

## 验收

- 认证/CSRF、旧来源哈希拒绝、官方源缺失只读阻断、合成旧 Speech 配置到 disabled 插件应用 API 通过。
- 核心首次应用、幂等、安装中断恢复、并发配置拒绝、权限/秘密输入绑定、原子完成回归通过。
- Playwright + 本机 Edge 的合成界面确认与失效测试通过；浅深色 1440/375 截图已查看。每插件紧凑卡片，未渲染配置或密钥，窄窗口无横向溢出。
- 完整 Go 测试通过（admin 约 245 秒）。后续查询上限修复执行相关 Go/Python 与 catalog 契约复验；静态 JS、vet、Windows/Linux 构建和仓库检查通过。
- 隔离桌面构建与测试：55 个控制器断言、86 个窗口生命周期断言、8 次真实窗口退出、12 个单例并发探针通过；服务均为合成。官方目录按 9 包、108 个源码文件暂存，未包含运行环境或模型。

临时日志、合成截图和构建位于 `temp/plugin-migration-validation`，不进入 Git。跨平台语法/构建不等于 Linux 实机隔离。整体轻主体、剩余服务迁出、旧路径清理及最终生产更新仍未完成。
