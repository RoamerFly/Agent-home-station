# 刷新群聊与好友

入口在“账号管理 → 群聊规则”和“会话中心”，都有“刷新群聊”“刷新好友”。刷新只更新微信目录资料；不会添加回复白名单、开启某个群的回复或覆盖页面内未保存的规则。完成后按原搜索条件刷新可选项，再选择“添加”，最后保存配置。

新加入的群不一定会立即出现在批量群目录中。本次实际遇到：群目录读取返回完成、更新0条；好友目录更新26条，仍未包含新群名。但账号已经收到了新群消息。按该消息对应的真实群标识单独读取资料后，群名进入目录。

“刷新群聊”因此分两步：先运行原生群目录同步，再读取本账号会话列表，为尚无群资料的真实群会话补取群名等信息。每次最多补取5个新群、最多扫描10页会话，达到限制或部分读取失败会显示“部分更新”，可再次刷新。若刚入群、账号尚未收到任何消息且微信批量目录也没有返回它，需要先在该群产生一条正常消息。

同步任务在后台运行，页面轮询进度；重复点击会复用当前进行中的同步，避免并行堆积账号请求。页面刷新后可恢复查看当前管理进程内的任务状态。管理进程重启不保留此页面任务标识；原生微信的目录操作有自己的状态，页面不会因此自动重提。原始群列表查询已补齐游标分页，避免只显示第一页。

原生目录操作始终绑定当前账号并校验metadata类型；管理员登录、来源与CSRF校验保护启动接口。接口不返回原生凭据或任意错误正文。日志记录同步类型和结果，不包含好友名单或群聊正文。
