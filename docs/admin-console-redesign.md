# 管理端重做：Ocean Glass

2026-10-29。已确认设计稿：`design/console-20261029/approved-concept.png`。设计稿是视觉参考；实际状态、余额和内容来自接口，不使用图中的示例数字。

## 设计系统

- 夜蓝 `#03091D` / 雾蓝 `#F3F7FC` 背景，半透明一级面板，蓝色强调、青色少量点缀。玻璃仅用于应用框架，正文使用更实的底色。
- 保留本机中文字体，14px 基础字号、15px 正文和1.75倍阅读行高；按钮通过层级和位置区分，不依赖缩小字体。
- 140px 紧凑侧栏，鲸鱼娘头像与两行品牌，悬浮状态胶囊。常驻框架受视口约束，工作内容在组件内滚动。
- 主题、控件、弹窗和内容区由重建后的 `console.css` 统一定义；`app.css` 仍提供既有业务组件的基础结构，画布几何由 `workbench.css` 管理。

## 功能迁移对照

| 旧位置 | 新位置 | 保留的操作 |
| --- | --- | --- |
| 工作台默认画布 | 总览 → 流程画布 | 添加、删除、复制、拖动、箭头连线、排版、导入导出、真实配置及回合证据 |
| 状态与费用 | 总览 → 状态 | 在线状态、运行暂停、待办、最近活动、Token、费用及余额 |
| 角色 → 任务与文档 | 总览 → 工作区 | 任务／文档／进程分别切换；任务历史、版本保存、进程停止保留 |
| 独立语音库 | 角色 → 声线库 | 公共／私有模型、版本、参考、试听、下载；旧地址跳转并保留账号参数 |
| 会话记忆弹窗 | 会话 → 内联消息面板 | 长正文点击大弹窗阅读、时间、压缩、原始历史、备注、清理及附件投递记录 |
| 成员与目录 | 会话 → 通讯录 | 好友、群与群成员查询、刷新；可从当前会话定位 |
| 回复规则 | 会话 → 批量规则 | 规则管理保留；从当前会话定位相应规则 |
| 手动发送 | 会话 → 发送消息 | 由会话选择接收方，保留类型选择、上传、确认、回执和素材库 |
| 执行回合 | 活动 → 执行回合 | 短预览列表，点击后大弹窗阅读完整回合、筛选、增量提示、归档 |
| AI 网上冲浪 | 活动 → 网上冲浪 | 保留独立监控、来源、设置、收藏与记录 |
| 模型与语音 | 设置 → 模型与语音 | 原有模型、语音识别、合成与歌曲服务配置 |
| 插件／联网与MCP／手机探索 | 设置 → 扩展与连接 | 三类入口共享分组；配置、导入导出、手动诊断与高级声明保留 |
| 权限 | 设置 → 权限与行为 | 媒体、管理员、执行器、主动行为、安静时段与视频授权 |
| 账号管理／账号操作 | 设置 → 微信账号 | 账号列表、添加、重新扫码；操作复核从账号页进入 |
| 后台设置 | 设置 → 系统 | 管理密码、存储与归档 |

低频入口收纳：文档页的项目、全局检索、附件投递进入“工作区工具”；人设预演、插件用法折叠；原始JSON置于技术详情的最后一级。入口迁移不改变业务权限。

## 文本、状态和接口

- 列表正文保留完整数据，长内容只显示三行预览；点击后在大弹窗阅读完整原文。长名称、连续URL与路径可换行；选择菜单完整显示选项，并支持键盘选择。
- 文档、消息、回合、声线及任务采用有界内容区。长消息、任务检查点和执行步骤提供完整阅读弹窗。代码可换行、滚动与复制，原始数据不抢占业务阅读层级。
- 自动刷新保留列表、消息阅读面板和文档草稿的位置。历史按需读取；压缩状态按会话独立维护。
- 保留旧hash路由。账号切换仍由现有账号上下文处理；文档CAS、配置版本和CSRF原有语义不变。
- 新前端资源 `console.js` 不新增业务API；`/voice-library` 改为带账号参数跳转 `/#voices`。公共素材和私人数据的访问仍由服务端校验。

## 验收

`scripts/test_console_ui.cjs` 使用合成消息、长名称、完整文档及模拟写入验证19个页面、两种主题、五种视口、文档修订、草稿、弹窗阅读与技术数据分层。它只允许本地管理端并阻止真实业务写入。原有会话、通讯录及账号浏览器用例继续独立验证。

运行方式：设置本机 `WECHAT_ADMIN_TEST_PASSWORD`，按需要配置 `PLAYWRIGHT_MODULE`、`PLAYWRIGHT_CHANNEL=msedge`，然后 `node scripts/test_console_ui.cjs`。截图仅在显式设置 `WECHAT_ADMIN_UI_SCREENSHOTS` 时输出；请写入被Git忽略的验收目录。

真实余额刷新会调用服务商；合成验收不会验证提供商余额有效性，也不会发送微信或调用模型。微信原生登录服务不属于本次更新范围。

执行日志按工具作用、成功或失败、失败原因和已确认影响分层显示。已创建或修改的文件仅显示会话／账号／公共授权根目录下的相对路径；命令本身的副作用无法由成功退出码推定，未记录影响时不会编造产物。附件准备与微信接受分别显示。
