# 工具依赖版本

工具依赖使用固定的本地声明，不会解析远程仓库、下载安装包或自动启用服务：

```json
{
  "dependencies": [
    {"id": "media-understanding", "version": ">=0.1.1 <0.2.0"}
  ]
}
```

`id` 必须是工具标识。`version` 可省略以兼容旧描述；新包应使用三段语义版本的精确值，或用空格连接的比较条件：`=`, `>`, `>=`, `<`, `<=`, `^`, `~`。`^1.2.0` 限制同一主版本；预发布前版本按更严格范围处理，`^0.1.1` 限制同一主次版本，`^0.0.1` 只匹配该补丁版本。`~1.2.0` 限制同一主次版本。

启动会先遍历全部已安装依赖，再启动任意进程。缺失、停用、移除、未授权、配置缺失、循环或版本不兼容都会停止整个启动计划；宿主不会安装、启用、升级或用其他工具代替依赖。

运行中的调用仍检查依赖的登记版本。依赖升级后若超出声明范围，依赖方不会继续分派工具调用，必须由管理员停止、审核并以兼容版本重新启动。任务恢复也继续使用自身包摘要、配置版本和来源校验，不因为依赖升级而重放。
