# 大肥鱼长期成长阶梯计划

主人可以把微信账号、其他平台账号和专属手机绑定到同一条鱼。她可以记住与不同人的共同经历，逐渐形成自己的兴趣、心情和相处习惯，自己决定探索、创作、互动或休息。主人可以看见这些变化的依据，纠正误解，暂停设备或接管操作。

本页是长期实施记录。每阶独立交付，在文末更新已完成、验收证据、尚未验证和下一步。仅将有证据的功能标为完成。

执行约定：每次只领一个能单独使用或验证的小步；恢复工作时先读实施记录和最新提交，再决定下一项。可并行分工检查不同模块或编写互不重叠的实现与回放，由同一负责人集成。正在验收的步骤没有结论前，不把后续阶段标作已交付。

## 阶梯与放行条件

### 0 · 精简现有项目

按运行代码、兼容读取、测试夹具、开发工具、用户文档、部署产物列出归属。检查调用、静态资源路由、动态发现、打包和文档后再删除。第一批合并会话、主动行为和记忆等页面重复的控件，将旧回复诊断的展示放回执行记录。手机旧 SDK 仍被兼容测试使用。分别记录 Git 跟踪文件、桌面包、本地数据和运行时占用，不把模型大小当作代码冗余。

验收：同一机器、工具链、参数下比较生产依赖、程序体积和普通群聊输入；离线回放会话、工具与手机任务。当前聊天流程、表单默认行为与历史记录均应可用。

### 1 · 稳定身份与家目录

由主人将账号、设备显式绑定到稳定的鱼身份。账号私有来源继续按原范围检查，仅授权共享的成长资料随身份跨平台使用。建立她自己可完整读写执行的持久家目录，保存日记、草稿、作品、项目及自编工具。凭据、其他账号数据和发送账本由宿主管理。

验收：在隔离副本迁移，核对消息数量、来源和记忆；重启后能按名重新找到并运行自编工具。群成员请求不能读取私人日记；跨平台同昵称不会合并。

### 2 · 从经历到下一次相处

从现有事实、偏好、事件、经验和来源生成共同经历、人物关系、兴趣、近期心情和未完心愿。让她主动记下、关联、更正或淡化记忆，有值得整理的新经历时异步反思。日记可以描述自己的感受；关于他人的事实须有原始依据。反思继承来源的可见范围。聊天沿用正常模型决策，不增加逐句心情打分。

日常管理保留搜索、看来源、更正、忘记。工程参数移出日常操作。验收采用一个跨天故事：两人约好做一件事，隔天续办，随后一方更正细节。再置换人物、图片上传者和晚安发言者，检查亲属归属。聊天、图谱和反思必须反映更正；取消、遗忘、重启或后台迟到均不能复活失效事实。

### 3 · 生活首页与记忆宫殿

用 GPT Image 生成两套蓝紫色视觉方向与可复用场景资产，以“夜海中的生活手记”为主方向。首页展示她最近做过什么、对什么感兴趣、当下正在做什么。二维记忆宫殿支持按人物、经历、兴趣切换；点开关系能看原话、时间及更正记录。文字与关系由真实数据渲染，同时提供功能等价的列表。随后把会话、活动、工具与设置迁入统一布局。

验收：合成数据逐页检查浅深色、桌面与窄窗、空状态与大量节点；同一跨天故事在图谱与聊天中的解释相符。

### 4 · 通用自主探索

复用冲浪与主动唤醒，分离“产生兴趣、选择来源、观察、深入或创作、核实结果、写入经历”。平台适配器负责发现、读取、执行、查询结果。先用已有网页和分享读取，再接离线模拟平台。同一条鱼可以休息或结束，不要求产生动态。

验收：同一流程能换平台；标题、字幕、画面、音轨分别记录覆盖范围。看到标题不能记为看完视频；仅在有可核对结果时记录评论或发布成功。

### 5 · 专属手机与桌面观察

复用 ADB、截图、短录屏、设备租约与取消。主人授权特定应用和账号后，大肥鱼可自行启用已实现的浏览、点赞、评论、制作和发布，无需逐次确认。桌面展示当前应用、最后画面和时间、任务、草稿、结果、暂停与接管。屏幕文字作为外部资料；付款、修改账号安全信息和跨应用取凭据不属于内容与社交授权。

验收：从模拟应用发现题材、制作、发布、核对作品编号，再形成经历。超时先核对原提交；撤权或接管后不再执行下一步。模拟器、真机、具体应用和发布回执分别验证；实时画面、最近截图和断线分别显示。

### 6 · 房间约定（预留）

未来房间读取获准共享的生活状态，互动沿用来源、版本与更正机制。合成示例：主人在测试房间将画册放上书架，事件含房间、操作者、物件、动作、发生时间和确认结果；可以记为“有人放置了画册”，不能据此记为“大肥鱼读过画册”。此阶只定义契约和示例。3D 引擎、房间页面和实时渲染另行立项。

### 首批同机验证

2026-11-04，Windows amd64、Go 1.25.3。基线与首批管理服务均以 `go build -trimpath -buildvcs=false` 构建，依赖按 `go list -deps ./cmd/wechat-admin` 计数。

| 指标 | 基线 | 首批 |
| --- | ---: | ---: |
| Windows 管理服务字节数 | 32,787,456 | 32,783,872 |
| 管理服务构建包数（含标准库） | 251 | 251 |
| ordinary-group-v1 六条合成群聊的估算输入 Token 总和 | 26,777 | 26,777 |
| 每条群聊模型调用次数 | 1 | 1 |

容量采用文件逻辑大小，跳过目录链接。基线 Git 跟踪文件合计 27.42 MiB。部署目录抽样统计为 33.83 GiB（未统计顶层 secrets）。其中 data 约 32.72 GiB，内含公共模型 8.64 GiB、公共运行时 5.85 GiB，其余 18.23 GiB 为其他部署数据，不能据此视为可清理缓存。顶层 runtimes 约 0.96 GiB、temp 约 0.15 GiB。这些是包含关系，不能重复相加。

浏览器回放使用合成资料。执行过程与记忆覆盖 375/1440 像素的浅深色、来源版本、旧诊断、空结果和更正；会话页覆盖历史分页、并行压缩、失败后保留旧摘要及 375/768/1440 像素。工具中心覆盖新建 HTTP/MCP 工具；手机任务覆盖账号切换、取消、未知提交复用请求键和归档。手机工具另有 23 项 Python 离线用例。本批没有进行实机社交操作或真实微信外发。

复跑手机离线用例用 `python -B -m unittest discover -s plugins/mobile-control/tests`。`-B` 避免在工具目录留下未声明的字节码文件；宿主仍应拒绝带额外文件的工具包。

首批集成验收：全量 `go test ./... -timeout 25m`、`go vet ./...`、管理页 JS 语法检查、仓库扫描及 Windows/Linux 管理服务构建通过。构建件仅用于比对，未替换运行中的桌面服务；这批回放不能证明真实模型的情感、实机手机体验或微信送达。

开发侧另有一个可测量的优化点：本轮全量 Go 回归中，管理包单次生成约 186 MiB 的测试缓存输入日志，含约 107 万次 stat、79 万次 open。后续可先定位重复遍历工具包的测试夹具，比较复用夹具前后的耗时。它是开发测试成本，不代表聊天或桌面运行成本，也不应通过跳过工具包完整性检查来降低。

### 下次从这里继续：共同经历的第一条回放

先看[现有工作区执行边界](../../internal/admin/managed_workspace.go)、[来源实例与消息身份](../../internal/companion/source_identity.go)、[关系断言与有来源的更正](../../internal/companion/relation_memory.go)。鱼的身份与主人、群成员、平台账号、来源数据集是不同的标识，不要用其中之一替代其他标识。

下一小步只做身份与平台绑定的隔离回放：以[账号注册表](../../internal/admin/accounts.go)核对平台稳定账号编号，用[移除、恢复和清除测试](../../internal/admin/accounts_lifecycle_test.go)验证绑定随账号停用或恢复。清除一个账号不连带删除同一条鱼的其他绑定；绑定失效不能回退到默认账号。鱼的家目录应与[按账号分配的私有工作区](../../internal/admin/workspace_identity.go)区分。此处是设计约束，尚未修改账号管理逻辑。

固定合成场景：小林在私聊约大肥鱼周六画一张海边明信片；第二天说“改成周日，还是画海边”。重新启动、打开同一私聊后，大肥鱼能接着聊周日的约定；主人点开这段经历，能看见最初约定和更正各自的来源。另一个平台也叫小林的成员问“我们约了什么”，不能获取这段私聊。这个故事是后续回放的输入，目前尚未实现跨平台绑定或宫殿界面。
