# 大肥鱼长期成长阶梯计划

项目名称：**Agent-home-station**。大肥鱼是其中持续成长的 Agent，微信只是她可接入的一个应用。主人在软件聊天框与她相处；接入微信、B 站、抖音后，她才拥有这些应用中获准的能力。她的身份、家目录、记忆和项目工具独立于任何应用账号。

她可以记住与不同人的共同经历，逐渐形成自己的兴趣、心情和相处习惯，自己决定探索、创作、互动或休息。主人可以看见变化的依据，纠正误解，暂停应用或接管其专用浏览器。**取消手机模拟器及专属手机作为实施路线**，后续使用应用 API/MCP 和独立 CDP 浏览器。

本页是长期实施记录。每阶独立交付，在文末更新已完成、验收证据、尚未验证和下一步。仅将有证据的功能标为完成。

执行约定：每次只领一个能单独使用或验证的小步；恢复工作时先读实施记录和最新提交，再决定下一项。可并行分工检查不同模块或编写互不重叠的实现与回放，由同一负责人集成。正在验收的步骤没有结论前，不把后续阶段标作已交付。

## 当前生效的架构决策 · 2026-11-05

本次需求覆盖下文旧阶段的后续安排；历史实施记录保留作证据，不表示手机路线继续执行。

- **主体＋接入应用＋项目工具**。主体提供本地聊天、身份、记忆、家目录、任务与授权；应用包含该平台全部专有工具；ComfyUI、RVC、YuE 等属于项目工具。联网搜索属于通用基础工具，不混入微信。
- **目录权限完全脱离微信账号**。鱼身份与本机主人授权决定家目录的读写执行；微信登录、退出、解绑、移除均不能收回她自己的项目和工具权限。平台账号只决定该应用中的数据与动作范围。现有 `boundFishHome` 仍依赖微信身份，属于待迁移实现，不能描述为已经解耦。
- **零应用可独立相处**。未安装微信包、原生端或手机组件时，仍能启动主体、创建同一条鱼、在软件聊天框对话、管理记忆及使用获准的本地项目工具。默认不主动对外联网；通用搜索需另启用。不能用假微信账号承载本地聊天。
- **微信成为已接入应用**。发行源逐步迁至 `connected-apps/wechat/`，安装到她家目录的 `Connected Apps/wechat/`，收拢微信专有实现、声明、说明与任务入口。登录材料、私密数据和权威回执继续由宿主隔离管理，应用目录只持有引用。
- 已推送的手机 5.1、5.2、5.3a 标为旧路线；5.3b 本地未提交实现暂停，不作为新计划的完成成果，也不随本次文档与更名提交。移除运行依赖及 UI 入口在替代链路可用后分步执行，不清空历史资料。
- 采用用户提供的《大肥鱼 Go 桌面端：后台探索、自主创作、发布与直播总体方案》中的 Go 主控、后台 API/MCP/CDP、ComfyUI/FFmpeg 创作、平台回执与 OBS 管理思路。该文末尾的“手机模拟器备选”不采用；文中的默认联网和逐次审批建议由本次明确应用授权取代。一个应用授权范围内可自主操作，新增应用与扩大权限仍由主人决定。

详细边界见[应用接入与项目工具规范](应用接入与项目工具规范.md)。这轮先落盘新架构与项目更名，运行代码按下列小步逐次迁移，不直接搬动真实登录目录或运行中的程序。

## 阶梯与放行条件

### 0 · 精简现有项目

按运行代码、兼容读取、测试夹具、开发工具、用户文档、部署产物列出归属。检查调用、静态资源路由、动态发现、打包和文档后再删除。第一批合并会话、主动行为和记忆等页面重复的控件，将旧回复诊断的展示放回执行记录。手机旧 SDK 仍被兼容测试使用。分别记录 Git 跟踪文件、桌面包、本地数据和运行时占用，不把模型大小当作代码冗余。

验收：同一机器、工具链、参数下比较生产依赖、程序体积和普通群聊输入；离线回放会话、工具与手机任务。当前聊天流程、表单默认行为与历史记录均应可用。

### 1 · 稳定身份与家目录

由本机主人建立稳定的鱼身份和独立家目录，再将应用账号显式绑定给她使用。家目录可完整读写执行，保存日记、草稿、作品、项目及自编工具；目录权限不依赖微信账号。账号私有来源继续按原范围检查，仅授权共享的成长资料跨应用使用。凭据、其他账号数据和发送账本由宿主管理。现有 1.1–1.3 是微信账号绑定实现，独立本地主人入口仍需按第 5 阶补齐。

验收：在隔离副本迁移，核对消息数量、来源和记忆；重启后能按名重新找到并运行自编工具。群成员请求不能读取私人日记；跨平台同昵称不会合并。

### 2 · 从经历到下一次相处

从现有事实、偏好、事件、经验和来源生成共同经历、人物关系、兴趣、近期心情和未完心愿。让她主动记下、关联、更正或淡化记忆，有值得整理的新经历时异步反思。日记可以描述自己的感受；关于他人的事实须有原始依据。反思继承来源的可见范围。聊天沿用正常模型决策，不增加逐句心情打分。

日常管理保留搜索、看来源、更正、忘记。工程参数移出日常操作。验收采用一个跨天故事：两人约好做一件事，隔天续办，随后一方更正细节。再置换人物、图片上传者和晚安发言者，检查亲属归属。聊天、图谱和反思必须反映更正；取消、遗忘、重启或后台迟到均不能复活失效事实。

### 3 · 生活首页与记忆宫殿

用 GPT Image 生成两套蓝紫色视觉方向与可复用场景资产，以“夜海中的生活手记”为主方向。首页展示她最近做过什么、对什么感兴趣、当下正在做什么。二维记忆宫殿支持按人物、经历、兴趣切换；点开关系能看原话、时间及更正记录。文字与关系由真实数据渲染，同时提供功能等价的列表。随后把会话、活动、工具与设置迁入统一布局。

验收：合成数据逐页检查浅深色、桌面与窄窗、空状态与大量节点；同一跨天故事在图谱与聊天中的解释相符。

### 4 · 通用自主探索

复用冲浪与主动唤醒，分离“产生兴趣、选择来源、观察、深入或创作、核实结果、写入经历”。平台适配器负责发现、读取、执行、查询结果。先用已有网页和分享读取，再接离线模拟平台。同一条鱼可以休息或结束，不要求产生动态。

验收：同一流程能换平台；标题、字幕、画面、音轨分别记录覆盖范围。看到标题不能记为看完视频；仅在有可核对结果时记录评论或发布成功。

### 5 · 应用化重构与后台探索（替代原手机阶段）

按以下顺序执行；每次只完成一个可独立核对的小步。前两步是其余应用接入的前置，不先做真实平台发布或直播。

| 小步 | 交付与边界 | 验收条件 |
| --- | --- | --- |

| 5.H OBS 与应用直播 | OBS 作为项目工具，平台应用负责开播资格与实际直播间状态 | 先本地预览；授权账号/时段/时长内才开播；本机急停不依赖模型；GPU 繁忙和断网可停止；平台未验证不标可用 |
| 5.I 移除手机与旧耦合 | 下线设备观察导航、ADB/模拟器默认依赖和微信专用主体入口；保留必要历史读取 | 无手机环境安装运行；停用旧队列不因重启复活；真实模型/素材/记忆不删除；检查动态发现、打包、文档和旧任务引用后再删代码 |

界面采用“聊天、生活与记忆、应用、项目工具、设置”。应用详情集中账号、权限、当前内容、运行状态和任务结果；创作/发布/直播随能力开放，避免提前添加空页面。具体代码目录与接口见接入规范。

迁移采用带版本的映射，先在隔离副本核对账号、消息数量、来源、哈希和未完成任务。旧账号私密目录不直接合并到公开应用目录；鱼的个人项目迁入独立家目录，应用凭据和权威账本保留受保护边界。接收新写入后不自动回切旧格式。旧手机授权不转换成网页评论或发布授权。

### 6 · 房间约定（预留）

未来房间读取获准共享的生活状态，互动沿用来源、版本与更正机制。合成示例：主人在测试房间将画册放上书架，事件含房间、操作者、物件、动作、发生时间和确认结果；可以记为“有人放置了画册”，不能据此记为“大肥鱼读过画册”。此阶只定义契约和示例。3D 引擎、房间页面和实时渲染另行立项。

预演中发现两个启动问题。缺少素材清单时，旧服务会把缺失解释为空集合，清除已有的素材搜索记录。现在仅显式空数组才会在启动时清索引，缺失、损坏及旧版空值都保留原索引。有完整清单但无元数据要补录时，旧服务仍推进数据库分页版本。现在重复启动保留该版本，实际补录仍会使旧分页失效。恢复时应一并保留素材清单和关联历史；保留搜索记录并不能找回丢失的媒体原件。
