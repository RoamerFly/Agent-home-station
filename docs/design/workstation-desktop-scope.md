# 工作站桌面界面范围

Station 是桌面端产品，布局和验收以 Windows 桌面窗口为准。采用左侧工作站导航、应用目录与详情分栏、记忆宫殿与资料分栏，以及独立打开的近全屏应用详细配置窗口。详细配置保留左侧分区导航与右侧独立滚动。

不再维护手机视角的单列工作台、顶部移动导航、手机全屏弹窗切换，以及 375/390 像素验收矩阵。旧截图是当时的阶段证据，后续不要求重新生成。相关 UI 脚本使用桌面视口和桌面截图命名，业务授权与回执断言继续保留。

桌面界面内容最小宽度为 960 像素。检查 1024×600、1280×800 和 1440×900 等桌面窗口，保留普通窗口缩放与桌面分栏调整、内容滚动、键盘焦点、系统减少动效与高对比度支持。不会为缩小到手机宽度另起布局。

这一范围只约束工作站界面和布局验证。手机扫码确认、手机收到微信消息、设备接入或其他独立业务能力不受影响；这些能力仍按各自的授权和实际证据验收。
