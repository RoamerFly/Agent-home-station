# 管理端排版与遮挡修复

版本：`0.31.1-layout-local`，2026-10-27。

保留已确认的鲸鱼主题、明暗配色和节点大弹窗，集中修复实际排版问题。

## 修复

- 登录表单使用独立的网格间距。错误提示为空时隐藏，但不会再把输入框与提交按钮的间距一起消除。品牌分行，窄屏可容纳；错误与密码字段关联，支持错误后重新聚焦。
- 画布“更多”菜单靠右排列，并限制菜单的可视尺寸，避免工具栏换行后向窗口左边越界。支持Esc关闭及点击外部关闭。
- 工作台消息提示和未保存提示放回正常布局，画布随提示区域高度变化调整，避免盖住工具栏。
- 其他页面的浮动保存条可以换行，桌面宽度避开左导航，并为页面底部和聚焦滚动保留空间。
- 长操作名称和后台进程编号可以换行。节点弹窗里的长反馈保留全文滚动，避免挤掉配置表单。
- 通用弹窗长标题和简介在受限的标题区域内滚动，关闭按钮及正文仍可访问；表单滚动区域为焦点留有内边距。

## 使用的辅助指南

项目本地安装目录为 `.agents/skills/`，不打包进程序、不提交第三方Skill副本。

- [Impeccable](https://github.com/pbakaus/impeccable)：使用独立的 `adapt`、`polish` 和基础 `impeccable` 指南，固定在 `f957fcad206b6534c9bf89064d015ae941c4b6cf`。采用其响应式、空间与长内容检查方法，保留本项目已确认的视觉选择。
- [UI Skills fixing-accessibility](https://github.com/ibelick/ui-skills/tree/main/skills/fixing-accessibility)：表单错误关联、焦点和原生对话框检查。
- 既有UI UX Pro Max、Frontend Design及Vercel Web Interface Guidelines继续作为项目设计和复核依据。

根目录 `.impeccable.md` 记录来自用户已确认需求的设计上下文，避免后续修复反复改变页面身份。

## 验证

`scripts/test_admin_layout.cjs` 是可选的本机Edge/Playwright验收，需要通过环境变量提供本机地址、管理密码和Playwright模块路径，不在源码保存凭证。

- 18个管理页面，320、375、768、844、1280、1440像素宽度，包含460像素高的横屏窗口。
- 登录页两种主题及4种宽度，检查输入框与按钮间距及错误状态。
- 展开设置后检查页面顶部、中部、底部；使用浏览器命中测试检查可见控件是否被其他元素覆盖。
- 排除关闭的原生details、屏外抽屉及滚动区域中本应不可见的内容，避免把隐藏内容误报成遮挡。
- 合成长进程编号、操作名称、群名、URL和反馈文本；验证弹窗、菜单边界、Esc、表单聚焦及未保存提示。
- 操作和进程测试记录为合成内容，所有页面写请求被阻止，不发送真实微信消息。

浏览器窗口仿真用于验证本次布局；不代表已在所有真实手机和浏览器上验收。
