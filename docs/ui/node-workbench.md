# 可编辑流程工作台

版本：`0.31.0-editable-flow-local`。

## 范围

按本轮确认的范围交付“流程设计＋真实配置编辑”。图中的节点和连线描述流程；自定义节点用于备注、条件或行动规划。新增、移除和重连图形不会改写执行引擎、停用后台能力或授予权限。现有能力节点通过关联面板编辑原有运行配置，各设置沿用自己的保存接口。

默认图覆盖24个环节、34条关系：微信接收、持久接收与去重、会话授权、引用正文、消息聚合、媒体理解、上下文记忆、角色、模型、Agent决策、工具执行、结果反馈、异步续办、回复计划、动态排队、回执、恢复补发、投递记忆、中断变更、安静、自主复评、网上冲浪、权限与状态费用。工具节点包含现有插件、联网/MCP、语音、音乐、手机和已授权主机能力，不复制第二套运行逻辑。

## 编辑操作

- 节点库可搜索现有能力，或添加便签、条件规划、行动规划。支持点击添加及从节点库拖入画布。
- 节点可自由拖动；属性中可改名称、说明、颜色和坐标。方向键或移动菜单提供不依赖拖动的替代方式。
- 支持复制、移除节点，移除时同时删除设计中关联的连线；撤销和重做保留完整图快照。
- 从输出端拖到输入端可连线，也可以通过属性中的目标选择器添加。连线支持编辑标签、端点及移除，允许反馈环路。
- 空白处拖动平移，滚轮平移，Ctrl/Command＋滚轮缩放；提供适应画布、缩略图定位和节点定位。
- 清单视图保持可读，窄屏默认使用清单，也能切回画布。可选择流程图、树形或自由布局；自动排版可撤销，不改变节点说明和连接关系。支持导入导出JSON、恢复默认流程草稿。

## 完整节点弹窗

点击节点或连线，打开居中的大弹窗。现有节点有“节点／配置／回合证据”分组，自定义节点显示说明与规划；弹窗顶部可以切换节点。实际配置表单被临时移入弹窗，关闭后回到原位置，因此切换节点仍保留同一表单的未保存内容，不增加重复ID或第二份配置。

桌面弹窗最大1120px，较窄屏幕自适应，内容完整滚动；节点说明和连线分列，窄屏改为单列。原配置面板在宽屏恢复相应的多列布局。支持Esc关闭、点击遮罩关闭及焦点返回，关闭时不改变画布缩放或位置。查看完整执行回合可以叠加独立回合弹窗。

“保存画布”仅保存图形设计。关联的服务商、人设、权限等运行配置在对应面板保存，反馈会显示在节点弹窗内。画布操作及周期状态刷新不会把正在阅读的位置滚回顶部。

## 保存与冲突

画布通过受管理密码和CSRF保护的 `GET/POST /api/canvas` 保存至私有管理目录的 `flow-canvas.json`。它独立于 `config.json`、原生微信登录、聊天记忆和媒体资产。服务重启和不同浏览器均可读取已保存设计。

保存请求带 `base_revision`，服务端在同一互斥锁下检查当前版本并原子写入。旧标签页写入返回409，保留当前草稿，提供导出草稿或载入服务器版本；不盲目覆盖。保存请求发出后继续编辑，后续编辑仍保持“未保存”。载入服务器版本期间又有新编辑，也保留它而非静默丢弃。

未保存图稿缓存在当前标签页的sessionStorage，刷新前同步保留，退出登录时清除；浏览器localStorage只记录视角及画布/清单模式。旧版12节点布局记录保留但不直接套用到新图，以免新增环节重叠。

输入只允许图稿字段，拒绝未知配置字段、无效类型、重复ID、悬空连线和非有限坐标。节点标签始终作为文字呈现。单画布资源边界为200节点、600连线和120KiB，坐标允许负值；达到边界时明确提示，不静默截断。损坏文件保留，不自动重置。

## 视觉与交互依据

使用UI UX Pro Max与Frontend Design。两次设计系统检索的页面模式仍偏营销页，未采纳hero/CTA结构；采用匹配的功能型后台方向、拖动替代操作、键盘焦点与对比度建议，并结合项目自身的鲸鱼身份制定以下规范。

- 海盐白背景 `#F6F8FA`、画布 `#EFF5F8`、纸面 `#FFFFFF`、文字 `#172B3A`、强调 `#146D88`、边界 `#DCE5EA`。
- 深色采用深海蓝画布与独立语义色，节点色只辅助区分环节，不取代标题和状态文字。
- 系统中文字体与Segoe UI，无外部字体或图编辑器运行时。流程图只突出节点名称，说明、状态与配置集中于完整弹窗和节点提示中。
- 主操作为添加节点和保存画布；整理、导入导出等低频操作收进“更多”，编辑操作集中于完整弹窗。
- 默认流程图按接收理解、工具行动、回复交付和安静后续分区；树形布局自上而下展开。节点采用矩形、判断菱形和起止圆角。所有连接带方向箭头，自动折线避让其他节点；反馈回路及配置依赖用不同虚线区分。选中后突出关联连线并显示标签，避免全图堆叠文字。超大自由图采用曲线路由以保持编辑响应。
