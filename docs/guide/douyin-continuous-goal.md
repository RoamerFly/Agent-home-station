# 抖音工作台持续目标（2026-11-26）

仅在 `douyin` 工作树与分支推进。正式工作站的发行包、数据、登录资料和媒体不作为开发测试材料；微信工作树独立集成。每批代码通过定向验证后以中文提交并推送，核对远端 SHA。

## 1. 通知驱动的评论执行回合

1. 由已绑定账号的互动通知发现新请求，按作品编号分别列出通知及状态；作品编号缺失单列，原生编号本身不证明作品归属。分页不能把同一作品的通知误并到另一作品，也不能因新通知插入而漏页。
2. 在同一受限网页登录资料中取得可比较的通知账号与创作者账号摘要，逐条确认作品来自当前账号。仅保留派生摘要，不保存平台原始 UID、Cookie 或签名。
3. 针对通知编号定向核对本次评论的 `cid`、一级评论编号、直接父评论编号和作者。只有本人作品的主评论、或直接回复本账号子评论的子评论可进入回复；其他子评论排除。文案和候选字段路径不能代替关系证据。无法核实的回合保持待核对，不创建回复任务。
4. 每个作品建立独立上下文：创作者中心简介与状态、原视频完整音轨的转写进度、覆盖整段时长的分批画面分析及每段时间戳。记录媒体哈希、覆盖范围和缺口。画面采样不宣称逐帧观看；缺少所需上下文时暂停自动回复，避免用评论区文字冒充视频内容。
5. 回复沿用精确评论目标、原文版本、授权、节奏控制与原任务回执链；未知结果只核对原任务，不重复发送。

## 2. 作品制作与发布

复用工作站项目媒体工具、不可变成品登记、`app_publish` 草稿与提交回执链。抖音工作台提供创作请求入口、已有成品及发布任务的可见状态，创作请求可编辑且不自动发送。发布前展示视频、标题、简介和可见范围的可审阅结果。任何正式账号投稿都须遵守本聊天先前的“不要自行投稿”约束；授权前只用合成平台完成提交与回执验证。

## 3. Agent 工具验证

- 源码和合成回放：核对工具发现、授权、创作成品、草稿、提交、回执及取消/未知结果的原编号语义。
- 真实模型加合成抖音传输：只读使用工作站现有 DeepSeek 配置，测试主机、合成媒体和发布账本均落在本工作树忽略的独立临时目录；不使用正式账号或正式媒体。
- 真实平台只读验收：核对工作台独立 Edge 资料的登录、通知与创作者账号一致性、通知到评论树的逐条映射及视频上下文覆盖。普通 Edge 已登录标签页的 DOM 观察不能代替这一步。
- 真实外部动作：仅在具体账号、作品、文案、可见范围和接收效果可审阅后，按用户最终授权执行；记录平台回执，不以合成测试代替。

## 本轮进展与后续验收

在通知编号、目标评论与直接父评论仍未逐条核实期间，通用 `app_action` 对抖音评论回复暂停创建、提交和续办；原任务保留状态查询与取消，抖音点赞和其他应用交互不受影响。此门禁在宿主任务校验处重复执行，防止升级前的待提交回复继续发送；待真实响应样本校准后再接服务端通知绑定的原任务路径。

`douyin_rounds(locate)` 现在可针对指定日期已保存通知中的一个作品编号，逐页读取当前创作者管理页的作品列表，仅返回精确匹配且已核实归属的临时作品入口与可观察字段。`pages` 和 `page_size` 可指定单次扫描范围，未完成时用相同 `page_size` 和 `resume=true` 续办；各通知作品拥有独立私有游标，超出本轮时间预算返回已扫描页数。此动作会访问创作者作品列表并可能更新已授权的本人作品文字记忆，但不读取评论、音轨或画面，不调用视觉模型，也不发送回复。入口是有效期约 20 分钟的内存引用，过期或重启后需要重新定位；可见性和媒体读取仍按现有 `app_observe` 授权与平台条件核对。

目标评论只读函数已加请求栅栏：只放行固定作品页、所需静态资源、同作品的视频详情和每次一条精确匹配的评论列表 GET；无关接口、写请求、子框和认证挑战均拒绝。用户已提供评论列表与回复列表的真实请求和响应样本；工作台独立受限浏览器能否自然发出并捕获目标响应仍待实测；Agent 仅能通过已保存通知的 `douyin_rounds(relation)` 定向调用，结果一律不能授权回复。通知列表的 DOM 暂不能将可点击行与通知编号可靠绑定，因此不会为获取详情按文字或顺序点击。

执行回合已按作品分组，组内通知独立分页；通知入账另存同域创作者账号摘要。当前账号、通知组、创作者作品快照和记忆授权同时吻合时，可以读取该作品简介和已留存的音轨/采样画面证据。`context` 的后续页使用绑定日期、作品和证据版本的 `next_cursor`；页间证据变化时返回 `restart_required`，工作台丢弃旧页并从头读取。旧 `offset` 仅作未锁定快照的兼容输入。音轨与画面的完成标记分别依其实际分页连续性与媒体哈希，画面完成仅表示采样计划覆盖，不表示逐帧观看。内容浏览中显式读取的证据才会入账，打开回合页面不会自动抓视频。

Agent 的 `context` 现在另报 `agent_pages_read` 与 `agent_context_read_complete`，逐作品、逐回合核对实际交给 Agent 的页序；账本中 `audio_complete`、`visual_complete` 为真仍需本回合从首页读到末页。中途更新、断页、沿用另一回合游标或兼容 `offset` 均不能宣称已读完。该标记表示工具响应时的已存证据阅读状态，不表示之后平台原视频仍相同；评论发送仍按独立关系证据门禁暂停。

普通本机聊天的合成模型回放已交错调用 `douyin_rounds(context)` 读取两件作品的标题简介与各自音画页，分别从 1/2 读到 2/2，并确认下一聊天沿用旧游标不能取得“本回合读完”标记；本次未访问抖音浏览器或调用 DeepSeek。此验证证明工具在 Agent 回合中可调用、页序与作品隔离有效，不代表真实模型一定会自主选择这些步骤。

针对主评论与直接回复本人子评论已建立严格的纯合成判定门禁；同一受控通知会话中自然发出的 `/notice/detail/` 响应现按已保存通知编号归一化，并将只读候选证据及缺失、无效、冲突状态保存在原账号作用域执行回合中。详情被动请求现在识别已有列表编号对应的 `notice_id_str` 单条形式及原批量形式，并已收到点赞、空结果与一条 31 类评论通知的真实单条响应。`douyin_rounds(relation)` 已将只读目标评论函数接入执行回合：只接受同一通知详情的明确候选编号和可选根评论编号，先核对目标评论，再在自然加载的结构化页面中各定向核对主评论及直接父评论；根评论或父评论缺页时返回待核对，不翻页发现通知。其他人的子评论会标为不匹配本人子评论，仍不授权回复。31 类通知的 `comment.comment.cid` 已作为目标候选进入只读探测，其他评论提醒类型和逐条实际关联仍未验收，判定门禁尚未接发送；所有执行回合 `reply_eligible=false`。已按样本补齐只读字段解析；连接既有 `app_action` 原任务链仍需真实平台逐条关系与发送语义验收。

用户提供的真实 `/comment/list/`、`/notice/detail/`、`/notice/` 与 `/comment/list/reply/` 响应只用于本机只读结构核对，未存入仓库；仓库测试只使用合成编号和文案。31 类通知的列表与详情按通知编号、作品编号和嵌套 `comment.comment.cid` 对应，作品编号同时出现在顶层及嵌套字段时必须一致。其子评论 `comment_type=11` 的 `comment.parent_id` 在这份配对样本中等于目标回复列表的 `reply_id`，因此只保存为未分类候选；精确读取目标 CID 后必须用该行 `reply_id` 再核对。`reply_to_reply_id` 单独指向直接父评论，不能由 `parent_id` 或文本预览推定。通知没有主楼候选时，仅在自然主列表命中目标 CID 后从该评论结构读取主楼；有候选但精确回复列表缺页时保持待核对。`root_comment_id` 在不同回复响应中含义不一致，解析器不依赖它。评论主列表的内嵌回复预览也能供精确 CID 核对，缺失时才尝试候选主楼自然返回的回复列表。真实工作台通知到评论的逐条捕获及回复门禁仍未验收，回复门禁保持关闭。

作品发布页已增加可编辑创作请求、项目工具入口与原任务只读审阅：标题、正文、可见范围、不可变素材编号和哈希可供主人核对，原任务视频现可在审阅中手动播放或下载；只读预览逐次核对当前账号和成品来源，合成测试通过完整视频与 Range 字节读取。通用 Agent 状态查询仍只返回元数据。执行回合对有有效编号的作品组始终提供资料与音画核对请求入口；请求先复用已存完整证据，缺失时才定位作品并补读音轨或画面采样，带入主聊天时只预填、不自动发送。`douyin_video_check` 已在普通聊天中接入不可变视频成品的只读容器、元数据及指定帧和音频片段解码检查，并以合成视频验证。创作请求区分项目工具已返回的 `artifact_id` 与家目录文件：前者直接检查，后者先用 `artifact_publish` 登记。`project_comfy_register` 的普通聊天分派已补齐并以合成后端定向验证。既有不可变成品登记、`app_publish` 草稿/提交/回执链具合成端到端验证。用户授权只读使用工作站现有 DeepSeek 模型配置后，本工作树真实模型加合成 Creator 的定向测试通过：Agent 自主调用一次受管 Windows FFmpeg 进程制作带音轨 MP4，登记为不可变成品，再创建草稿、提交一次并按原任务查询到回执；测试主机、媒体、进程暂存和账本均在本工作树忽略目录，正式运行时与模型配置只读使用，抖音浏览器操作为零。本轮依用户费用限制没有再次调用 DeepSeek，`douyin_video_check` 还未纳入真实模型完整链路。工作台独立浏览器登录、真实平台逐条评论定位及正式投稿亦未验收。原 Edge 标签曾返回 `Debugger unattached`；随后通过扩展新开 Edge 标签，只读查看一条通知及打开后的评论弹层，能看到子评论卡片编号，但 DOM 没有可靠的直接父评论编号，当时没有取得原始通知详情/评论响应。新标签已关闭，原标签未改动；这不等于工作台独立登录资料验收。
