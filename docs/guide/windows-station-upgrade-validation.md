# Windows 工作站旧资料升级预演记录

日期：2026-11-11。候选源码为开发分支 `codex/windows-portable-directory` 的 `b87edec604f385c1ba15b470d527a1d7c31e4fb1`。本次是已有 Station 资料的本机升级预演，与 [旧 WSL 管理数据迁移](windows-migration.md) 分开。

## 实际核对结果

- 从已停止的旧工作站资料根复制到独立私有目录，共 1,924 个源文件、413,690,862 字节。逐文件核对复制摘要，原路径和原件保留。Windows 长路径按原路径完整读取，没有跳过较深的发布暂存目录。
- 副本保留原鱼身份、主人身份及家目录授权。仅在副本中暂停模型配置，不启动微信原生登录、不调用模型、不发送、发布或开播。
- 用候选服务端和副本启动独立随机回环端口，验证原主人管理会话、家目录状态、聊天历史接口及默认本机会话的记忆宫殿接口。服务正常退出，原资料在预演前后的文件集合和 SHA-256 一致。
- 旧本机聊天记忆库的 SQLite 完整性检查通过，包含 10 条事件、0 条提炼记忆。另有 4 份微信封存会话档案，包含 56 条来源事件及 1 条提炼记忆。这些数字属于不同来源，不能合并声称所有微信历史已接回。

## 本轮未放行的事项

本次没有将原登录复制到正在试用的新实例，也没有用副本启动第二个原生微信登录。微信原生聊天库和封存档案存在，不等于新运行版已经按原账号、会话和权限读通全部原文。历史其他部署的更大记忆库仍需核对其真实位置及来源摘要；不能用同名目录或不同摘要的快照替代。

本次没有替换正式运行版，没有合并新旧实例的消息和身份，没有验证所有旧任务的外部资源路径，也没有发布正式发行包。已有真实账号、模型、生成物、回执和资料必须继续保留。

后续先生成原账号及资料接续预览，确认来源和目标身份及当前授权。新实例已有资料时不得覆盖；开始接收新写入后，不允许把旧数据库或 JSON 直接覆盖回去。正式切换须先排空并保留可核对的备份，之后只验证本次切换影响的路径，沿用未改动功能的通过记录。

私有原件、账号、正文、凭据、浏览器资料、逐文件清单和原始日志均留在本机，不进入仓库。本文件只记录聚合结果和验收边界。

后续已找到旧微信完整库并完成来源核对及独立接续入口，具体步骤、可接续数量与未补证范围见[微信旧记忆库的独立接续](wechat-memory-archive.md)。这项新预览没有重复上述已通过的整库升级预演。
