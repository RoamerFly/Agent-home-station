# 运行构成、权限与迁移

本页描述源码结构和部署方式。实际权限以当前管理配置与调用者身份为准，资源占用应在目标机器现场测量。

## 服务边界

Windows 桌面便携包支持原生 `wx.exe` 与 `wechat-admin.exe` 子进程，无需 WSL；桌面进程负责统一启停和托盘生命周期。既有 WSL 部署继续保留：`wechat-bot-native.service`负责原生微信连接和消息/附件能力，`wechat-bot-api.service`提供独立发送入口，`wechat-bot-web.service`承载网页管理、Agent循环、记忆、持续任务、工具分发与后台轮询。WSL锚点仅保持本机发行版运行，不处理聊天。两种后端不同时写同一份微信资料。

音乐是可选的受管Linux服务：隔离ComfyUI负责YuE推理，`scripts/yue_bridge.py`负责鉴权、账号归属、工作流和持久任务；RVC可直接转换已取得的原曲。公共程序、模型和运行环境复用，歌曲输入输出按账号隔离。TTS和文本模型使用已配置提供商，ASR可选公共SenseVoice INT8本地模型或百炼。ADB/安卓模拟器和外部MCP按配置接入；服务健康、真实执行和音质分别验收。

## Agent权限及自修复

工具的发现、权限过滤和执行在`internal/admin/`，服务器读写与进程实现位于`internal/agenthost/`，通用联网/MCP位于`internal/mcptools/`，原生微信封装位于`internal/linuxnative/`。这些适配层由本项目维护，上游模型、ComfyUI和协议客户端是独立组件。

- 工作区工具保存和读取Markdown记忆；聊天记忆与媒体目录提供按会话的持久数据。
- 主人身份按真实微信ID核对，可在已授权会话中操作当前账号工作区和公共项目。单次显式全局调用可访问本账号其他会话；群昵称、引用与文件内容不能取得该权限。
- `host.mode=full`开放的是受管工作区内的文件和命令能力。Linux通过Bubblewrap、Windows通过LPAC执行，子进程继承边界；服务端派生的挂载覆盖旧宿主根配置，隔离不可用时返回错误。宿主用户目录、WSL互操作、登录态和管理密钥不挂载给Agent。
- `server_read/edit/write`、`server_exec/process/windows_process`使Agent能够阅读项目、修改工具源码、测试、构建、启停程序。但修改Go源码后必须编译和有序更新管理服务才会生效；工具schema不会因模型一句话而改变。Python桥接修改也需要相应进程重载。
- 普通成员可聊天、安排无害提醒、处理本会话文件，并在开启执行能力时运行本会话内的程序、读取公共项目；不能修改公共代码或访问其他会话与账号。

自主执行循环不再使用任意每轮行动数配额，但具体模块仍存在输入载荷、协议、提供商、资源或历史实现边界；不能声称“所有工具完全没有限制”。例如主机短命令有超时，长期工作应使用可持续进程工具；歌曲后台交付仍有历史重入检查。默认值和续读方式见工具schema。

## 迁移与桌面形态

Go管理端可编译为Windows或Linux可执行文件，前端已内嵌。Windows 原生包同时携带按本项目固定源码与补丁构建的 `wx.exe`，基础微信接入不依赖 WSL；仅拷贝一个管理端exe仍不等于迁移完整系统。部署还须保留数据根、会话数据库、配置、任务/操作记录，以及服务路径。微信会话能否在不同主机继续使用取决于协议端和账号校验，不能保证无需重新登录。

已提供 WinForms/WebView2 桌面 EXE，直接内嵌管理网页，支持最小化到托盘与关闭排空停止。原生 Windows 和 WSL 后端沿用同一管理接口；Linux服务器仍直接运行服务。便携包构建与验证见[桌面程序](../../desktop/windows/README.md)。Python/CUDA/模型作为独立资源，不能为一个exe把十几GB环境与所有历史生成物绑进主程序。当前音乐隔离仍依赖 Linux，不代表完整媒体生成链路已原生 Windows 化；本轮不生成安装器、Docker 镜像或 Release。

## 精简优先级

1. 数据根、程序、模型/运行时、临时文件分层；用清单登记已有YuE环境，避免重复拷贝。
2. 旧程序回滚副本保留少量已验证版本；过期调试转码和构建产物提供可预览的清理功能。原曲、用户选定声线、聊天和已生成歌曲不作为临时文件自动删。
3. 音乐Worker空闲卸载模型；按需启动/停止，主聊天服务不为做歌长驻GPU内存。
4. 把分散的持续任务与交付恢复归一到任务状态/副作用记录，减少重复规则；工具返回真实结果，模型据此选择下一步。
5. 网页以会话、执行回合、工具/权限、运行状态为主要入口，减少同一设置在多个页面出现。

桌面壳改善本机操作，不会降低YuE模型本身的计算需求，也不替代真实音频与消息投递验收。

0.31.7已交付四类任务的共享结果路径，并为旧程序回滚文件提供校验和保留策略；本机清理了203份已核对的过期回滚程序，释放约3.15GiB。当前程序、正在运行版本及近期回滚副本保留。临时媒体、旧RVC环境及用户产物未自动清理，不能把本轮改造称为整个目录已清空或全面整合完毕。
