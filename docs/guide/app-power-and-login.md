# 应用开关、抖音登录与日志入口

本页记录 2026-11-13 收敛后的三类交互，避免把内部实现当成用户操作。

## 应用开关

- 微信在「详细配置 → 账号与授权」顶部提供「微信应用」开关：关闭后工作站不再为该应用领取消息或执行任务，账号、登录与记忆继续保留，**不重启工作站**。
- 开关只影响主人已经启用过的微信连接；从未启用的连接不会被这个开关打开。
- 抖音与哔哩哔哩继续使用各自分区内的开关，语义相同：关闭只停止该应用的活动，不删除资料。
- 「高级：微信原生服务」是启动级设置，切换会重启工作站，只用于调整微信原生进程是否随包启动。日常开合请使用「微信应用」开关。

## 抖音网页登录

1. 在「详细配置 → 账号与授权」点击「接入抖音账号」，工作站用项目专属资料目录打开 Microsoft Edge。
2. 主人在窗口内完成扫码/登录。
3. 工作站只探测会话 cookie **是否存在**（`sessionid`、`sessionid_ss`、`sid_tt`），不读取、不记录、不外传 cookie 值。
4. 探测到登录后，页面自动确认并关闭浏览器，保存登录资料，无需再点一次「确认」。

探测只是让窗口自动收尾，不构成新的授权：读取、发布、互动仍各自按分区授权。

## 日志

设置页新增「排查与日志 → 打开日志文件夹」。桌面版直接打开本机数据目录下的 `logs`，浏览器访问时显示该路径。日志内容仍留在本机，界面不展示技术字段。
