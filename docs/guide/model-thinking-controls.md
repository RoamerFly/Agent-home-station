# 模型与思考设置

管理页的“模型与语音”支持获取模型列表并下拉选择。获取列表使用已保存的接口地址和密钥，只查询模型目录，不生成文本。获取失败时保留当前选择。

“思考与回复”提供思考开关与 low、high、max 三档。聊天、工具执行和回复复核共用选中的模型、开关、强度及输出预算；不自动换用另一个复核模型。默认关闭思考，强度预选 low。输出预算包含思考及最终正文，开启思考时应预留足够额度。

工具续办需要回传模型的思考内容。程序只在当前执行的内存中暂存，通过独立引用与实际回复绑定；执行结束即清除，不把思考正文写入聊天、记忆或诊断快照。重启后的旧执行不能借用其他回合的思考内容。

## 当前回合临时思考

工作站模型设置和微信控制台的“思考与回复”新增任务思考策略，默认“Agent 自行决定”。Agent 可调用 `task_reasoning`，从下一次模型请求临时切换到 `low`、`high`、`max`、关闭思考或沿用日常设置。它不修改保存的模型配置；回合结束、失败或取消后自然恢复，并发会话各自独立。

人工可以指定策略；指定后，该回合不向 Agent 提供切换工具。设置对之后的新回合生效。`inherit` 沿用日常配置；`off` 关闭当前回合思考；其余档位开启对应强度。临时思考默认预留至少 8192 Token，Agent 可用 `max_tokens` 显式调整预算，包含思考和最终输出。提供商实际支持范围仍以接口返回为准。

当前实现适用于已声明该能力的 DeepSeek 接口；普通兼容接口不会被假定支持专用思考参数。记忆压缩与专用复核配置不随这一临时选项改变。控制工具只记录模式、预算和简短调整原因，不保存内部思考正文。

## 查看上一次回复

对话记录把已发文字、媒体附件及后续配文分别呈现给模型。语音的合成稿说明提交给合成器的内容；微信回执记录实际接受的部分。遇到“还有一个呢”这样的追问，模型可以在同一正常回合对照原话与记录，复用成品或调用工具补做。结果未确定时先查原投递，用户已取消的任务不能续发。普通闲聊无需另做一轮模型复核。

本次仅使用 Flash 对三个固定错误草稿做非思考／low 对照，共六次复核：非思考两条正常拒绝、一条协议格式无效；low 三条正常拒绝。估算费用分别为 0.0075 元和 0.0267 元，平均耗时分别为 1.30 秒和 10.97 秒。协议无效也会停止发送，不能记为错误稿被放行。这不是完整生成或总体准确率验收，没有评估正常回复误拒，也不能据此保证思考模式总是更准确。计费按提供商实际用量及当时空闲时段价格估算。
