# 模型与思考设置

管理页的“模型与语音”支持获取模型列表并下拉选择。获取列表使用已保存的接口地址和密钥，只查询模型目录，不生成文本。获取失败时保留当前选择。

“思考与回复”提供思考开关与 low、high、max 三档。聊天、工具执行和回复复核共用选中的模型、开关、强度及输出预算；不自动换用另一个复核模型。默认关闭思考，强度预选 low。输出预算包含思考及最终正文，开启思考时应预留足够额度。

工具续办需要回传模型的思考内容。程序只在当前执行的内存中暂存，通过独立引用与实际回复绑定；执行结束即清除，不把思考正文写入聊天、记忆或诊断快照。重启后的旧执行不能借用其他回合的思考内容。

本次仅使用 Flash 对三个固定错误草稿做非思考／low 对照，共六次复核：非思考两条正常拒绝、一条协议格式无效；low 三条正常拒绝。估算费用分别为 0.0075 元和 0.0267 元，平均耗时分别为 1.30 秒和 10.97 秒。协议无效也会停止发送，不能记为错误稿被放行。这不是完整生成或总体准确率验收，没有评估正常回复误拒，也不能据此保证思考模式总是更准确。计费按提供商实际用量及当时空闲时段价格估算。
