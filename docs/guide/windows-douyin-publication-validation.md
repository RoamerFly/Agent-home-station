# Windows 抖音视频制作与发布隔离验收

普通账号作品沿工作站的成品登记和发布任务流转：制作视频后，通过 `artifact_publish` 登记不可变成品，再用 `app_publish` 绑定抖音连接、成品、文案及可见范围。抖音发布授权独立于作品读取，草稿保存不会提交。明确提交时，宿主核对当前连接、权限、原请求及成品摘要，将同一份字节暂存到任务的私有目录。平台动作前保存提交检查点；之后若结果未知，只核对原任务。可见范围必须明确指定。

迟到回执只允许在短时本地记账阶段保存。浏览器返回已核对的作品编号或明确拒绝后，即使原聊天请求已取消，原任务仍可记录该结果。记账不会重新打开浏览器、上传或提交。没有可信回执时保留待核对状态，不能把本地提交检查点当作平台接受。

缺少作品编号时，核对以提交前持久写入的时间为起点，按创作者浏览器的提交时限限定窗口，同时核对同账号作品的文案、可见范围和唯一匹配。草稿时间仅用于验证提交时间的先后关系。旧任务缺少提交时间且没有作品编号时保持待核对。按文案匹配前和接受结果前重新检查原请求及应用资料授权。已核验的作品编号可继续按同账号查询，不需要读取原文案或暂存文件。

验证分为三层：

- **本机制作。** `TestLiveDouyinPublicationFromWindowsVideoProcessThroughChat` 使用合成模型脚本驱动正常聊天入口，在真实 Windows LPAC 隔离进程中运行受管 FFmpeg，制作三秒 MP4，验证可解码画面和音轨。登记后的成品与实际生成字节一致。该用例通过环境变量 `AHS_WINDOWS_RUNTIME_CONFIG` 指定已有的 Windows 运行器配置，受管媒体运行时包含 FFmpeg，本机测试路径提供 FFmpeg 与 ffprobe。
- **宿主任务。** `TestDouyinPublicationVideo*` 使用普通账号的正式 Station 发布适配器与私有账本，把外部创作者浏览器传输替换为合成夹具。检查视频字节、摘要、仅自己可见、持久提交边界、撤权、请求复用、回执丢失及服务重启后的只读恢复。恢复不需要原暂存上传，且不会重新生成暂存。`TestLocalDouyinPublicationLateReceiptPersistsAfterRequestCancellation` 分别检查迟到的作品编号及明确拒绝可入账。
- **浏览器。** `TestLocalCreator*` 使用真实 Windows Edge 和合成回环创作者页面，分别核验上传文件、页面切换、文案及可见范围、检查点、提交与原作品状态查询。

专项另外核对了窗口前后的同文案作品、原请求在结果返回前被遗忘、旧记录缺少提交时间，以及重启后保留原提交时间。隔离检查保留待核对状态时没有重新上传或提交。

这三层通过仍不代表正式抖音账号的实时界面、发布资格、审核结果或实际外部可见性已验收。真实账号及发布按明确授权单独核对；隔离回放不接触账号资料或正式作品。
