# 公开分享读取与安装版本更新

分享读取按实际来源解析短链跳转、平台作品、HTML video/source、Open Graph 视频和 JSON-LD VideoObject.contentUrl。快手支持轮换的 m.chenzhongtech.com 落地域名，B站及视频号继续使用各自解析器。普通网页读取正文，纯文本链接保留短正文；封面、播放器页面地址和卡片描述不冒充视频原件。

视频地址交给宿主下载后，沿用原消息的音轨转写与采样帧理解，观察覆盖范围写入同一条消息记忆。每次公开页读取记录起止、耗时、返回字节及安全错误码，不记录 Cookie、带查询参数的下载地址或网页原文。

一次成功解析可恢复既有检查点。工具包版本/摘要、配置或来源变化会生成新的只读解析任务，避免新版解析器与旧失败任务的请求键冲突。临时网络失败进入现有持久重试机制；重读失败任务会真正调用解析器，保留旧失败记录，不重发微信消息。需要登录、验证码或浏览器执行的页面仍返回明确状态；当前不能保证任意网站都能读取。

## 部署必须核对已安装快照

`publictools` 保存当前工具发行源，微信旧宿主另有小型、按摘要固定的已安装执行快照。只替换发行源不会升级已安装快照。部署、重启后执行：

```powershell
python -B scripts/update_installed_public_tool.py --release <运行包绝对路径> --tool share-reader
```

脚本通过本机管理接口导入已声明代码文件，停用空闲旧执行器、安装新包、恢复原启用意图，最后核对实际安装摘要及配置不变。不会复制模型/环境，不请求聊天重放或发送接口。相同摘要重复执行不修改安装；权限声明发生变化或配置迁移失败会报告失败，原配置和凭据由安装事务保留。标准构建完成不等于安装快照已经升级，此命令与健康检查应一起作为部署验收。

## 验收边界

合成回归覆盖轮换域名、作品身份、JSON-LD相对媒体地址、短文本、非媒体嵌入页、版本变化重读和成功检查点恢复。真实验收应使用用户授权的既有分享，通过 observe-share 只观察不回复；分别核对实际画面、ASR覆盖时长、素材缓存及 wechat_sends=0。真实视频、聊天记录、下载地址和报告只保存在本机。
