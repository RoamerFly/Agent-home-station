# 能力和验收边界

界面版本 `0.35.0-managed-workspaces-local`。本清单概括当前能力，具体实现与验证按[主题文档](../README.md)查看，避免把早期版本记录当成当前配置。

| 能力 | 范围及边界 |
|---|---|
| 微信接入 | Linux原生后台，本机WSL真实登录和收发已验证；云端重新授权及长期运行需另验收 |
| 多账号 | 同时运行独立Worker、各自配置/记忆/任务/收件进度；昵称优先展示，支持新增及重新扫码；双账号并发通过合成原生服务测试，真实第二号需扫码验收 |
| 聊天Agent | 群聊/私信、人设、工具决策、主动复评和网上冲浪；可选择安静，依赖上下文与授权 |
| 媒体理解 | 图片、表情包、语音转写、引用和分享；实际内容读取依赖来源可用及所需授权 |
| 投递 | 文本、图片、音视频、文件，动态延迟、持久任务、来源追踪与核对恢复；接受不等于手机阅读/播放 |
| 扩展 | HTTP声明式工具、MCP和异步任务；不是有审核和签名的托管工具市场 |
| 主机行动 | [受管工作区](../agent/managed-workspaces.md)内文件/文档、隔离程序执行/控制和提醒；普通成员仅本会话，管理员临时访问当前账号全局；隔离失败拒绝宿主回退 |
| 跨会话媒体 | 管理员从明确来源获取原件，投递至明确目标并持久续传；完整语音顺序、目标绑定与重启恢复已通过模拟，真实跨群投递待验收 |
| 语音/音乐 | 百炼说话/识别；原曲翻唱默认RVC换声，原创/相似歌曲使用YuE，尊重明确指定；不保证音质或角色歌声相似度 |
| 手机探索 | ADB设备、真实截图和任务执行；完整目标App登录、连续刷视频及跨设备兼容待实际验收 |
| 记忆 | 会话记录、媒体来源、摘要压缩和历史查看；压缩不等于删除原文 |
| 工作台 | 明暗主题、箭头流程图/树形布局、图稿编辑、节点弹窗和真实配置；自定义节点用于规划，不重写引擎 |
| UI验证 | 本机浏览器多窗口、长内容、焦点和回合/会话交互，不代表所有真实手机浏览器已验收 |

源码检查、合成测试、模型调用、工具执行、微信回执与用户手机确认分别记录。未经本轮明确授权，不向微信群或好友发送验收消息。

当前不生成Docker镜像或Release。`deploy/docker/`是历史容器草稿，旧标签不代表当前可部署交付。
