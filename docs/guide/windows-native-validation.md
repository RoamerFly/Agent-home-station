# Windows 原生后端验证记录

日期：2026-10-30。环境：Windows x64、.NET Framework WinForms/WebView2、Go 1.25.3、Rust 1.93.1 MSVC、Visual Studio 2022 C++。以下区分真实微信回执、合成隔离测试和待验收能力。原始私人证据保存在本机忽略目录，仓库只记录结果。

## 实际微信与迁移

- Windows 原生扫码认证、在线心跳、保存凭据后重启恢复通过。手机显示“Linux 电脑”来自所用协议设备身份；程序本身为 Windows PE，不通过 WSL，也不伪装官方 Windows 客户端身份。
- 修复空资料目录发布错误 183、数据库相对路径分隔符、保存登录绑定路径，以及 Windows 附件缓存读取分隔符问题。群同步成功；联系人目录同步返回完整覆盖，26 条记录、0 项失败。
- 用户授权的私聊、测试群1和测试群2，文字、图片、语音、视频、普通文件各一次，共 15 次发送取得微信服务器接收回执。测试群1的实际名称由用户确认是“机器人测试群”。每次发送使用稳定幂等编号并保留回执；不把排队成功当成送达。
- 完成旧 WSL 管理资料的离线备份：733 个文件、526197396 字节，逐文件 SHA-256 校验，原数据保留。迁移 5 个记忆范围、813 个已有原始事件、35 项派生记忆；事件原文与哈希、来源、修订和遗忘标记保留，账号范围重映射为当前 Windows 原生账号。
- 迁移私人工作区 4112 个文件、9615720510 字节，素材、声线、模型和已有产物原件保留。跳过 scratch 临时目录和 Linux 运行链接，不将 Linux 环境登记为可执行的 Windows 环境。鉴权管理 API 逐条确认 35 项长期记忆可读、62 项来源关联可读，声线目录有 32 项，26 项任务保持原状态（16 项需复核、10 项失败）。新接收记录可能继续增长。
- 保留 Windows 原生登录、密钥、事件游标和本轮发送回执；没有用旧 WSL 原生任务编号或游标覆盖新后台。1 项旧媒体恢复种子移入私有迁移归档待人工复核，没有自动重发。通过鉴权记忆校验与激活接口验收。
- 普通桌面入口指向 Windows 原生 EXE；旧 WSL 桌面程序、入口及配置保存到独立留存目录。原 WSL 数据和模型仍保留；项目 Web/native/API 服务取消自启动，项目 Web/native/API/music 均为 inactive，没有终止共享 WSL 实例。

## 合成与源码检查

- 固定上游提交与累计补丁构建，锁定依赖；新补丁在独立干净工作树完成正向应用与反向校验。许可证和协议、媒体、SILK 声明随包保留。原生程序依赖 Microsoft Visual C++ x64 Runtime；Go 管理端无 CGO。
- Windows profile 集成测试 73 项通过：初始化 5、保存登录 9、媒体写入与缓存 17、MMKV 6、资料读取 29、消息投影 7；中断初始化恢复测试 1 项通过。测试资料使用合成数据，写入测试使用平台规范路径，安全校验未放宽。
- 桌面控制器 55 项断言通过，包括私有目录所有者、原 WSL 启停兼容、排空失败/取消保护、Windows 原生配置、分离运行目录、哈希拒绝、Job Object 进程归属及关闭偏好。显式设置新目录所有者，解决提升权限的 Windows CI 默认将所有者设为 Administrators 所致的启动拒绝；不接管其他用户的已有目录。
- 独立中文/空格路径、独立回环端口的真实空实例完成两轮启动、管理鉴权、排空、有序停止及冷重启，并完成两轮管理进程失败恢复和端口冲突拒绝。退出后端口释放，测试凭据保留；不扫码、不调用模型、不发送微信。
- 4 项真实 LPAC 执行器测试和 1 项生产 Agent 工具集成测试通过，验证 Unicode、非零退出码、目录读写边界、取消及幂等续读。Windows 隐藏执行代理随便携包提供；便携包提供项目内 Pythonw，既有显式执行器保留。
- 完整 `go test ./...`、`go vet ./...`、仓库凭据检查、3 项结构检查和 28 个静态 JS 语法检查通过。新增离线账号迁移 3 项合成测试，验证只读预演、原文/来源/遗忘保留、账号拒绝以及未提交数据库日志拒绝，纳入双平台 CI。
- EXE 默认最大化，内嵌管理页；关闭默认提供取消、托盘运行、退出，可记住并重置选择。依用户要求不使用电脑操作工具，本轮没有把弹窗视觉交互算为实际验收通过。

- 补充真实 Windows 固定参数 Python 隔离测试：中文、引号、空参数、反斜杠、独立 stderr、只读挂载与外部读写拒绝通过。无界面 Python/推理库避开 SxS 清单启动失败，未增加网络或注册表能力。
- 项目内 Windows SenseVoice Small INT8（Sherpa ONNX 2.0.1、NumPy 2.2.6、Python 3.13.13）实际处理合成语音，返回非空 38 字符识别结果；未上传音频、未发送微信。模型已登记与实际运行分别验证；同一源码安装器在独立目录从原模型归档重建环境，通过语音与启用 VAD 后的静音无词用例。

## 尚未通过的能力

手机播放与主观听感未确认；不以服务器回执替代播放验收。音乐服务受管启动仍依赖 Linux systemd，原 Python/CUDA 唱歌与训练环境尚未在 Windows 重建验收，暂不使用旧 WSL 服务。Linux 沙箱/运行库不能直接作为 Windows 可运行资源。真实 Embeddings 服务未配置，本轮只验证已有词法记忆和数据完整性，不宣称语义召回通过。

原生同步中不支持的协议控制条目继续保留待投影状态，不能把它们记作完整历史同步。普通微信文字和媒体发送回执已验证；破坏性账号操作、其他成员授权和所有模型决策未逐项在真实账号执行。不能宣称全部 WSL 功能已经原生化。
