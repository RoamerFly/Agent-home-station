## Windows 音乐与 GPU 补充验收

用户已明确授权音乐/GPU 后端使用 `registryRead`、`privateNetworkClientServer`。仅固定的受管音乐策略和已登记的命名声线执行器使用这些能力；普通 Agent 保持原隔离。该网络能力允许访问局域网，不将其描述为离线网络隔离。

- Windows 管理端通过受管 Python 启动 Comfy/YuE，账号专用 AppContainer 命名管道连接推理服务；认证桥和令牌保存在推理挂载之外。账号私有目录可写、公共模型可读，其他账号的文件/管道访问被拒绝。重复启动不收养占用端口的外来服务；在途音乐任务参与桌面排空，退出通过私有控制管道停止拥有的进程树。
- 实际使用 RTX 3060 Laptop GPU 6 GiB、驱动 591.59、Torch 2.12.0+cu130。YuE 合成歌词生成 10.0 秒音频，桥接任务完成、565461 字节，整文件解码通过。修复 aiohttp 在命名管道上调用 socket sendfile 导致音频读取断开的错误；旧中断任务保留，未自动重放。
- RVC 默认声线换声完成；另行明确选取账号私有 mom 模型的合成输入换声完成，9.77619 秒、1724564 字节，实际使用 `cuda:0`。校验模型与配置哈希，mom 索引实际命中 11575 个向量，整文件解码通过。修复 Faiss 的 Windows 窄字符文件 API 在中文路径下读写失败，选定索引未被使用时不再报告成功。保留原默认声线和已有声线身份。
- GPT-SoVITS 用指定的 mom GPT/SoVITS 权重和已有参考录音，针对合成测试文本生成 3.02 秒、32000 Hz WAV，实际设备 `cuda:0`。其 Transformers 4.52.4 依赖与 YuE 分目录；修复 Python 3.13 临时目录 ACL、可选 TorchCodec 不存在时的本地规范化音频解码。仅验证此次中文推理，不泛化为全部语言/模型版本通过。
- RVC 合成数据在全新的账号私有影子工程完成准备、GPU 训练和索引：3 个完整样本，最终 epoch 6，生成器优化器 19 步、判别器 24 步，索引 441 个向量。检查优化器状态、导出 epoch 和模型 SHA-256。修复嵌入 Python 忽略 PYTHONPATH、Windows 无权限创建符号链接、multiprocessing 全局管道，以及仅有模型导出便将训练标记完成的问题。短试训被混合精度保护全部跳过更新时明确失败。
- 5 项音乐策略/真实 LPAC 集成测试、4 项普通执行器集成测试通过；35 项 RVC 测试完成（33 项通过、2 项非 Windows 路径跳过）、26 项 YuE 测试和 6 项 GPT-SoVITS 适配测试通过。完整 Go 测试/vet、28 个静态 JS 文件语法、仓库检查及 Windows 原生构建分别记录。保留并移出活跃发现范围的旧登记备份共 81 份，登记器后续备份保存在独立 `.backups` 子目录，避免重复或过时配置进入能力上下文。真实模型原始日志、输出和回执仅留本机忽略目录。本轮新增微信发送为 0。
