## 接入顺序与验收

1. 回合卡片及弹窗、任务与文件结果、便捷日志入口。
2. 会话与联系人选择、账号操作和授权、旧资料及记忆接续。
3. 旧持续任务与生成资料、网上冲浪与互动、流程画布。
4. 工作站公共模型、工具、声线和用量入口的关联。

每项使用当前管理员会话和应用级接口，验证账号切换、撤权、迟到响应、重启后的状态及结果。旧任务先作为历史资料核对，恢复执行时沿用现行授权和幂等机制。已有验证按代码影响复用，真实账号、真实外发与正式发行分别记录。

用户已授权大幅取消此前微信重复实现。原生微信业务模块尽量直接复用上述基线源代码；视频/图片理解、生成、模型、语音、工具与 MCP 接到工作站公共能力。不能将挂载旧全局管理服务、另起机器人或复制旧凭据当成迁入。账号切换、修订号、幂等和当前会话授权在适配层保留。完整功能迁入仍在进行，本表不是已完成声明。
