# 使用大肥鱼

## 启动和进入后台

Windows本机双击根目录 `启动大肥鱼.vbs`（无命令窗口），后台就绪后打开 http://127.0.0.1:8081/ 。管理密码使用已有配置；只有默认密码尚未修改时才是 `admin`。修改入口为“系统 → 后台设置”。

启动器恢复已有WSL服务，不新建账号、不清除登录、不重复启动原生会话。退出浏览器不会暂停机器人。Windows关机或关闭WSL会中断运行，重新启动后续接持久任务。

错误提示会给出 `temp/launcher/` 日志路径。运行 `启动大肥鱼.bat Status` 可查看管理页和音乐端口。启动器不创建Windows开机任务。

## 页面导航

| 页面 | 常用操作 |
|---|---|
| 工作台 | 查看箭头流程图/树形图、运行状态与费用；点击节点打开完整设置 |
| 会话 | 群聊/私信记忆、压缩摘要、目录同步和回复规则 |
| 执行回合 | 一次请求的接收、判断、工具与投递过程，按来源或异常筛选 |
| 角色 | 人设与表达、任务和文档、自主活动及网上冲浪 |
| 能力 | 模型/语音、插件、联网/MCP、权限和手机探索 |
| 系统 | 微信连接、账号操作、管理密码和运行设置 |

## 聊天、群规则与媒体

私信、群聊及主动行动遵循网页中的会话授权和权限。普通聊天是否回复由模型判断，群里可针对真正@设置必须回复。判断没有统一冷却禁令，发送经过动态延迟和队列。

新群未显示时刷新群聊目录；小号实际入群后，收到新消息也可补充群标识。群成员名单缺失时在该群单独刷新成员，群目录与群成员同步是不同操作。

图片、表情包、语音、引用和分享卡片按权限进入对应理解工具。无法取得内容时日志保留原因；卡片标题不代表已观看视频。来源及环境要求见[分享观察](../media/share-observation.md)与[视频号说明](../media/channels-content-understanding.md)。

## 记忆和执行回合

记忆保存文本、媒体来源和投递信息。上下文压缩生成摘要，已覆盖历史默认不再整段进入模型请求，原文仍可展开查看，各会话可以独立压缩。

执行回合显示模型选择、工具结果与投递状态。`accepted`表示微信接受，不代表已读或已播放；结果不确定时按恢复机制核对记录、退避并继续处理。不能仅凭模型记得一句话就判定送达。见[投递恢复](../delivery/delivery-retry.md)。

## 联网、插件和高权限

服务商Key在网页配置，留空保留已有值。模型通过工具发现和function calling使用联网/MCP、下载、媒体或主机工具，实际操作及结果记录在回合中。

扩展接口见[插件配置](PLUGINS.md)。接口可独立更新；外部命令依赖须安装在实际执行环境，Windows路径不能直接作为Linux命令。

普通会话与可信所有者身份使用不同权限。群内也可识别可信发送者；跨群读取、项目写入和程序控制等以服务端验证的身份与授权为准。不要把管理密码发给群成员。

## 说话与歌曲

说话使用已配置的百炼模型与角色音色；微信语音先转写再理解。模型、音色和识别参数在“能力 → 模型与语音”调整。

本地音乐服务按需运行 `启动大肥鱼.bat Music`。创作和参考翻唱经过YuE，默认女声；只有明确要求角色声线时才使用后续换声。翻唱需要真实参考音频、歌词与风格依据，不保证原伴奏和逐字演唱。见[参考翻唱](../media/yue-reference-cover.md)。

歌曲默认拆成微信允许时长内的语音逐段发送；用户要文件时复用完整原音频，明确要求两种格式则分别交付。生成任务保存真实编号，完成后回原会话续办，重启不应重复生成。

“服务就绪”“生成成功”“微信接受”“手机可播放”是不同状态。模型和运行环境不在Git仓库，后续云部署需另行准备相应资源。

## 数据和维护

本机原生登录、聊天库和网页配置位于WSL私有运行目录；Windows `secrets/` 也有私有凭据。不要删除这些目录来解决登录问题。`temp/`含歌曲、参考文件和任务产物，不能整体当垃圾清空。

更多主题见[文档导航](../README.md)，环境和脚本参数见[部署说明](../../deploy/README.md)。

YuE底层采样可由Agent调用`music_sampling_options`获取实时参数说明、范围、枚举和工作流默认值，再通过`music_local_start.sampling`覆盖。参数按semantic（音乐token采样）、render（音频扩散）和score（原创ABC规划）分组，原创规划模式用`planning_mode`。参考翻唱仍用`reference_mode`。实际配方保存在任务/素材中；改变参数不代表旋律或音色质量自动通过。示例见[采样与后台启动说明](../media/yue-sampling-and-hidden-launch.md)。
