# DeepSeek 原件理解与文档回看

微信“思考与回复”和工作站模型设置提供“DeepSeek 直接理解图片与文档”开关。启用时使用当前 DeepSeek Flash 配置；关闭后恢复原视觉描述及本地文档读取路径。现有插件、配置、语音、下载、生成和转换功能均保留，不新增云端语音调用。

## 实际执行

- 微信原生图片仍先获取并校验原件，随后 `artifact_view_image` 将实际图片字节交给主模型，禁止把“已载入”当作观察结论。
- `document_inspect` 和本机 `project_document_inspect` 将已授权素材原件交给 Files API，下一次模型请求引用 `file_id`。图片使用原字节；没有在本机先提取文字。
- `include_layout=true` 选择图文解析；纯文档读取使用文字解析；表格、文本和电子书使用 `user_data`。原文件接口不裁页，`pages` 是关注页而非实际截取范围；返回实际覆盖范围。文件引用本身不保证精确视觉排版，需查看渲染页。
- Files API 上传按当前回合内的内容摘要及解析方式去重。原件仅随下一次成功模型请求载入；后续工具步骤不自动重复带入。模型可按需重新调用查看工具。每次重新引用仍可能产生输入 Token 费用，文件 ID 不代表免费上下文。
- 上传设置一小时有效期，回合结束尝试删除云端副本；本地原件不删除。失败请求保留待载入内容以便重试。密钥、文件 ID、原件字节不进入 Git。
- 本机文档工坊保留生成、编辑、结构校验、转换与成品登记。管理员可调用 `artifact_render_document(asset_id,page)`，通过本机 WPS 将同一 DOCX 导出 PDF，再用便携 PyMuPDF 渲染指定页；主模型直接查看该页。返回总页数供继续检查，没有静默只检查首页。
- WPS 渲染是可选 Windows 主机能力，需要已安装 WPS。运行固定转换代码、只读打开、禁用宏并拒绝外部关系/嵌入对象；不授予模型任意 COM 执行接口。产物仍经过任务目录及哈希核对。

## 验证边界

自动测试验证真实字节请求、同回合上传去重、单次载入、模型不支持时明确报错、回合隔离、授权来源及退出清理。

`TestLiveNativeDocumentInput` 需显式设置私有管理目录后运行，仅生成合成 TXT/DOCX，验证实际 Files API 及主模型读取，无微信发送。

`TestLiveImageOnlyDocumentTrial` 使用私有原图和原请求、隔离记忆及任务空间，不提供参考 PDF，不执行微信投递。实际生成 DOCX、成功回看和导出只证明链路可用；文字、字体、行结构和签署位置仍需独立验收。未通过的试验产物不能自动发送。

2026-11-17 实测：合成 TXT 与 DOCX 图文解析通过；原图试跑成功直接看图、生成 DOCX、WPS 页面回看与修改并导出 PDF。独立验收仍有字号、标题粗细与签署区位置偏差，未向测试群发送。保留原参考 PDF 仅供人工验收。

## 文档处理档案

微信提供 `artifact_document_memory`，工作站提供 `project_document_memory`，支持 search/read/save。档案直接附在现有素材记录中（微信 `media-assets.json`，Station 素材 `record.json`），不复制原件、不新增档案目录；删除素材记录时一起移除。

素材登记自动保留来源和摘要标识，文档工坊自动关联原件。Agent 可保存简短的处理总结、约束及原件/前版编号；该摘要明确标为模型所写，不推断用户已验收。读取时同时返回实际素材身份、哈希和来源。旧素材也可补记档案，不自动编造旧处理摘要。

后续修改先 search/read 相关档案，必要时再调用原件读取工具；摘要不会全量自动注入每次聊天。search 默认每页10条，可指定limit/offset，返回next_offset；新摘要优先。save要求revision，避免并发或过期回合覆盖修改；更新时省略requirements/parent_artifact_ids保留原值。每份摘要和要求合计最多8KiB，超过明确报错，不能把整份文件塞入档案。

已用合成样本验证微信跨回合读取、重复登记保留摘要、跨会话拒绝、过期更新拒绝，以及Station重启恢复、文件ID/哈希不变。未执行新的真实微信投递。
