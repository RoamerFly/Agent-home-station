# 插件选择、安装与开发

先判断目标是**发送已有文件**，还是**生成或加工文件**。前者使用内置微信接口，后者通常需要安装对应插件。比如手机里已有一个 PDF 要转发时，检查微信文件权限即可；把图片中的表格重建为 PDF 才需要文档工坊。

| 目标 | 检查的插件 | 需要额外准备 |
| --- | --- | --- |
| 图片、Word、PDF 加工 | 文档工坊 | 文档运行包、中文字体、适用的 OCR 语言数据 |
| 合成朗读、建立私人说话声线 | 语音生成 | 已配置的服务商或已注册本地模型与参考音频 |
| 音乐生成、翻唱和唱歌换声 | 音乐 | 原素材、唱歌模型及后端所需运行环境 |
| 读取分享并理解其中的视频 | 分享内容读取、媒体理解 | 可读取的原分享、画面或语音理解后端 |
| 搜索网页、调用外部 API/MCP | 联网检索、外部工具连接 | 相应的网络授权和服务配置 |
| 操作工作区或设备 | 项目开发、手机控制 | 登记过的项目或设备，以及对应操作权限 |

## 安装一个能力

1. 切换到要使用该能力的账号，在设置的插件中心查找对应条目。确认选的是可选插件；“微信文件收发（内置）”显示的是主体权限。
2. 从官方目录选择，或导入准备好的插件目录。核对名称、版本、声明的权限和用途后，由管理员安装。
3. 打开插件详情填写配置。远程服务需要有效的地址和所需凭据，本地后端需要在服务所在的系统上具备运行文件、模型或设备。插件声明、安装登记和实际后端可用是三个不同环节。
4. 启用插件，在授权会话发一个小任务。例如文档工坊先处理一页含标题与简单表格的样本。检查工具调用结果和实际成品，然后再交给较大的任务。
5. 要停用或升级时，先查看是否有正在生成、待核对或投递中的任务。插件任务完成只说明成品已生成，最终的微信回执由内置接口记录。

## 在界面中创建连接插件

打开插件中心，选择“通过 UI 新建插件”。选择 HTTP 或远程 MCP，填写名称和唯一标识，再填入服务地址和用途。HTTP 向导可指定接口接收的文本字段，例如把字段设为 `query`，工具调用会向该地址 POST 含 `query` 的 JSON。MCP 向导使用所填的远程服务地址。

最后一步核对目标并创建。插件初始未启用，可从“管理连接插件”编辑声明、鉴权和启用状态。请同时核对“外部工具连接”的安装与授权。本地程序和多文件插件仍可选择“导入本机插件”。

## 编写第一个插件

从仓库的 `templates/plugins/` 选一个能运行的模板：本地 Python 选 `python-stdio`，本地 Go 选 `go-stdio`，远程接口选 `http-mcp`。复制到自己的开发目录，给插件设置唯一 ID。

| 文件 | 首次修改的重点 |
| --- | --- |
| `plugin.json` | 版本、平台、运行入口、依赖、权限、包内文件摘要 |
| `capabilities.json` | 工具名、参数、返回值、是否异步、有何副作用 |
| `config.schema.json`、`ui.schema.json` | 配置字段与宿主展示方式；凭据作为密钥字段处理 |
| `runtime/`、`tests/` | 最小运行实现和不依赖真实账号的合成测试 |

从一个只读操作开始，用模板 README 的命令验证协议及错误响应，再通过管理页导入。如果修改过包内文件，更新声明中的摘要后重新准备安装。加工插件接收宿主授权的素材并返回成品，由宿主校验、登记并投递。测试取消或重启时，检查同一个任务编号，避免重新提交有副作用的任务。[可运行模板](https://github.com/RoamerFly/wechat-agent/tree/89b0bfa/templates/plugins) · [宿主协议](https://github.com/RoamerFly/wechat-agent/blob/89b0bfa/docs/plugins/PROTOCOL.md)
