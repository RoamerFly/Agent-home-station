# 语音生成

范围：默认云端 TTS；声线、克隆与训练仍在主体旧实现中，尚未迁入本插件。

当前状态：`speech.synthesize` 是唯一已安装、可发现的能力：它通过独立 stdio
协议调用宿主绑定的云端接口，宿主核验音频、登记素材并负责微信投递。它只合成
配置中的默认云端说话声线。命名 GPT-SoVITS、声线克隆与训练仍由主体旧实现承担，
不属于本次迁移，不能回退成默认云端声线，也不能因本插件 ready 而视作已迁移。

当前包只声明云端 TTS 所需的 `model.invoke`。未迁移的声线和训练占位能力不申请
GPU、网络、素材或工作区权限，也不能被发现或调用。

宿主协议见 ../../docs/plugins/PROTOCOL.md。不得绕过宿主直接发送微信；生成结果与投递回执分别记录。

默认云端调用不再回退主体旧配置。旧账号先在插件迁移中核验配置、包摘要及权限，迁入后由管理员启用。管理页合成测试使用独立登录身份，生成和音频验证不发送微信；下载、转换期间退出登录或撤权会阻止后续步骤。
