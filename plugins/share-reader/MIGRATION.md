# 迁移

平台配置与凭据独立迁移，读取失败不生成虚假摘要。

当前迁移增量：`runtime/public_share.py` 已实现原 `internal/mcptools/shared_page.go` 的公开正文/显式媒体解析，以及 `kuaishou_video.go` 的精确作品状态解析。正文和播放地址只做读取/解析，不承担微信发送。`runtime/main.py` 通过 MCP stdio 运行；旧生产 Go 调用暂保留，尚未切换，不能称为已删除主体依赖。

后续顺序：接通原 `internal/channels` 的短链、对象桥接及凭据范围 → 迁入其他已有公开平台适配 → 通过宿主取得并校验媒体素材 → 调用媒体理解 → 将群偏好下的总结交回核心决策和发送。每一步必须保留作品编号与观察范围，取得播放地址不能直接返回“已观看”的总结。

当前没有执行真实迁移。实施先在隔离副本预演并核对，成功提交后再切换唯一存储；任务状态未知时先查询，禁止重复提交。启用前可恢复旧备份，接受新写入后保留新数据由兼容版本修复。

0.1.3 增量：迁入 `video_page.go` 的 B 站公开 BV/分 P 与渐进地址解析；包仅解析位置，下载体积和观察范围仍由实际媒体代理控制，不继承旧解析器的 100 分 P / 10 分钟偏好上限。旧生产调用尚保留，需在来源验证及媒体交接完成后切换。
