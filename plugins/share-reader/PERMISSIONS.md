# 权限

- network
- artifact.write

仅取得管理员批准的权限交集。请求上下文由宿主绑定；插件参数不能改变账号、接收者或访问范围。

公开解析增量只使用 network 的宿主管道代理，不直接联网。`wechat/channels_bridge` 是宿主绑定的本地对象桥接回调：插件只能传递已绑定的对象编号、可选 nonce 和当前请求的超时，不能传 URL、Cookie、请求头或目标地址；宿主只在安装配置的 `object_bridge_url` 通过环回地址验证后响应。artifact.write 为完整分享读取的后续声明，当前解析不写素材。没有视频号凭据的读取授权，不会尝试使用宿主浏览器或登录资料。

`http_routes` 是管理员确认的包摘要的一部分。`yuanbao_cookie` 仅用于元宝解析接口；`assistant_cookie` 仅用于视频号助手短链接口；预览接口不注入两者。密钥配置标记 x-host-only，不进入子进程初始化。`object_bridge_url` 是非凭据安装配置，宿主校验后才允许作为固定桥接目标；它不会赋予插件任意网络目标能力。重定向不跟随、请求失败不自动重放；来源参数仍须由业务宿主按原请求核验，网络授权不代表可以读任意对象。
