# 分享内容读取

范围：视频号、快手与已有分享适配。

当前状态：`migration-pending`。公开分享与快手精确作品解析已有独立 Python stdio 实现，完整业务尚未接入。不得作为可安装成品或对 Agent 可用的能力宣传。

已实现 `share.resolve_public`：通过宿主管道读取实际网页正文、提取显式视频地址、解析快手当前作品及备选地址；跨作品跳转拒绝、正文与候选分页、内容哈希续读。视频地址是供宿主继续读取的私有交接数据，不代表视频已下载或观看，不得直接注入模型。只有标题、应用落地页或要求视频却未取得视频时，返回真实缺失状态。

已实现 `share.resolve_channels` 的短链和 export 对象协议：通过固定宿主接口解析作品、检查对象编号，保持 uint64 标识与解码键精度。元宝/视频号助手凭据分开保存在宿主，预览接口不接收 Cookie。返回的媒体位置和解码键仅供后续受控交接，不代表内容已观察。

仍需接入视频号本地对象桥接、B 站等现有适配、受控媒体下载/解码、素材登记及媒体理解协作，以及生产来源绑定策略；随后完成旧配置迁移、原入口切换和旧代码删除。现有生产路径未被替换。

离线解析测试：`python -B plugins/share-reader/tests/test_public_share.py`。均使用合成 HTML/JSON，不请求真实网站或模型。

视频号协议测试：`python -B plugins/share-reader/tests/test_channels.py`。真实接口可用性未在本轮验证，不能用合成响应通过宣称登录凭据已验证。
