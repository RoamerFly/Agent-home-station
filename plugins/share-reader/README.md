# 分享内容读取

范围：视频号、快手与已有分享适配。

当前状态：`ready`（仅 `share.resolve_public` 与 `share.resolve_channels`）。公开分享、快手、B 站和视频号的来源绑定解析可由宿主发现；综合 `share.read` 仍是无权限、不可发现的迁移占位。解析结果不等于媒体理解、观看、下载或投递。

已实现 `share.resolve_public`：通过宿主管道读取实际网页正文、提取显式视频地址、解析快手当前作品及备选地址；跨作品跳转拒绝、正文与候选分页、内容哈希续读。视频地址是供宿主继续读取的私有交接数据，不代表视频已下载或观看，不得直接注入模型。只有标题、应用落地页或要求视频却未取得视频时，返回真实缺失状态。

已实现 `share.resolve_channels` 的短链和 export 对象协议：通过固定宿主接口解析作品、检查对象编号，保持 uint64 标识与解码键精度。元宝/视频号助手凭据分开保存在宿主，预览接口不接收 Cookie。可选的 `object_bridge_url` 是安装配置中的本机环回服务地址；宿主验证端点并优先调用固定环回桥接，只把原始 `/api/channels/feed/profile` 响应交给工具校验。工具不使用该地址直接请求，也不接触 Cookie 或请求头。桥接调用透传请求的超时（默认 25 秒），不把显式值悄悄改回默认值。桥接失败后的旧 Cookie 路径必须在迁移时明确选择，不能静默变更提供方。返回的媒体位置和解码键仅供后续受控交接，不代表内容已观察。

宿主已接入视频号本地来源桥接，以及公开分享的来源绑定、实际读取地址核对、私有结果保存和受控下载；仅已安装且启用的副本进入新路径。停用不会回退旧路径。分享读取只解析和交接受控媒体；后续理解、总结和发送由核心及相应能力独立执行，不构成对媒体理解工具的安装依赖。旧绑定保持只读兼容，尚未完成全部配置迁移或旧代码删除。

离线解析测试：`python -B plugins/share-reader/tests/test_public_share.py`。均使用合成 HTML/JSON，不请求真实网站或模型。

视频号协议测试：`python -B plugins/share-reader/tests/test_channels.py`。真实接口可用性未在本轮验证，不能用合成响应通过宣称登录凭据已验证。

宿主协议见 ../../docs/plugins/PROTOCOL.md。不得绕过宿主直接发送微信；生成结果与投递回执分别记录。

B 站解析支持匿名普通 BV 页面及 b23 短链，按实际分 P 的 CID 取得单段渐进视频地址。拒绝其他作品/分 P 跳转、试看、非支持流格式和非平台媒体域；不使用 Cookie，不执行网页脚本。播放地址和元数据仍不是已观看证据；分享原文地址保留分 P，去除跟踪参数。

全部解析回归：`python -B -m unittest discover -s plugins/share-reader/tests`。旧 Go 解析路径尚未移除；旧绑定保持只读兼容，不能以此宣称旧路径已迁移或删除。
