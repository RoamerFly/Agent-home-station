# 迁移

云端配置继续单向映射：旧百炼根地址加固定音乐生成路径形成 music_endpoint，旧密钥进入宿主私密 music_key，MusicModel 映射为 music_model。管理员核验后才可启用，不因安装包 ready 自动开启。

本地服务配置独立映射为 local_endpoint 和宿主私密 local_token。宿主需要核验原服务根地址、账号与管理员权限。迁移不导入私人歌词、RVC 声线文件、训练样本、GPU 环境、音频或未知远端提交；原任务和来源留在原持久存储，不移动模型或用户素材。

本地服务协议、路由校验和 HTTP/服务错误分类由 runtime/local_music.py 实现；宿主代理只执行已绑定的一次请求，保存实际响应字节和私有验证凭据。错误模板位于同包已索引的 runtime/error_templates.json，宿主只按不透明分类 code 查模板、绑定实际 provider_code 并核验文案，不能自由信任插件文本。core 不应继续保留另一套相同提供商错误分类，也不得在插件失败后调用旧直连实现。

旧任务须使用原 job_id 查询、取消或恢复。未确认后端状态时不得自动新建任务；恢复缺失或失败的计算需要原有显式操作，保留原配方、种子及来源约束。插件不会根据 HTTP 错误自行重试或转换为其他引擎。

启用前核验包摘要、配置和权限。只读状态、实际计算、音频下载、素材登记和微信接受分别记录，不能将协议测试称为真实模型或手机播放验证。

0.4.0 将固定本地服务生命周期接入 music.service_control。Windows 兼容的 owner-approved windows-music.json 暂由宿主只读解析，通用注册表保存实际所有权；安装包、配置或来源变化后原回调失效。未将旧 speech 设置作为服务授权。
