# 变更

0.3.0：迁入本地 YuE/RVC 服务的固定路由与 HTTP/错误码解释，新增宿主内部 music.bridge_request；正文、音频、令牌和授权留在宿主。云端与本地配置独立，同上下文单次请求，无自动重试或新建恢复任务。错误文案集中在哈希索引模板中，宿主按实际错误码核验；兼容旧桥 text/plain 的真实 JSON 错误响应。未迁移的训练及通用 GPU 能力仍不可调用。

0.2.0：开放受宿主 `model.invoke` 路由约束的 `music.generate` 云端歌曲提交；仅返回提供商 URL，未迁移的翻唱、RVC、训练与 GPU 能力继续不可发现。

0.1.0：建立迁移契约，尚未迁出旧实现。

## 0.4.0

- 新增已安装 music.service_control 固定服务能力；宿主通用注册表持有进程、停止和繁忙状态，输入只允许 action。
- 生命周期复用当前来源和管理员会话校验，不回退旧 speech 配置；离线检查不代表真实模型启动。
