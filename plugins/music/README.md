# 音乐与换声

music 0.5.4 保留本地音乐桥；旧云端 `music.generate` 已退役，作曲由工作站 YuE 处理。

- `music.bridge_request`：宿主内部使用的本地 YuE/RVC 服务协议。工具核验固定路由、解释实际 HTTP 状态和服务错误码；宿主持有完整请求正文、歌词、参考音频、响应音频和任务授权。需要 local_endpoint 和宿主私密 local_token。

- `music.service_control`：宿主内部的固定注册服务生命周期，输入仅为 action=start/status/stop。必须由当前所有者或有效的本地管理会话授权；每次回调重新校验来源、包、配置、取消和权限。工具不接收命令、环境、路径、凭据或 PID；状态只证明宿主拥有的监督进程，不证明模型就绪。

本地配置由工作站维护；空配置不会自动启用。旧云端配置不再提供生成能力。

内部桥能力由宿主从已核准声明调用，并且不直接向 Agent 开放任意 HTTP。它只接收 method/path、正文引用和幂等键，不接收用户选择的 endpoint、headers、凭据、文件路径或内联音频。工具不打开 socket、不启动进程或 GPU；实际连接由固定地址、账号和令牌绑定的宿主代理完成。

本次迁移的是本地服务的客户端协议及错误分类。现有 YuE/RVC 计算仍由独立受管服务承担；服务生命周期通过已安装能力调用通用宿主服务注册表，模型、声线资料、来源校验、任务保存、取消、素材登记和微信投递保留原授权边界。Windows 停止只作用于本宿主启动的监督进程，存在排队或运行任务时拒绝主动停止；Linux 启动仅适用于已预授权的固定 systemd 单元和当前工具配置，不操作 WSL。music.cover 与 music.train 仍不可发现、不可调用；本包不构成训练或任意 GPU 执行能力。

本地恢复始终针对同一个原 job_id，未确认结果不能自动重新提交。返回服务任务或音频引用不表示已试听、验证人声音色、登记素材或微信接受。离线测试仅证明协议和宿主回调契约，没有执行真实模型或发送微信。
