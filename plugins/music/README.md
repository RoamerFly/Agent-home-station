# 音乐与换声

music 0.3.0 提供两项相互独立的已安装能力：

- `music.generate`：默认云端歌曲生成，通过宿主固定的 `generate` 路由提交提示词、可选歌词和超时，只返回提供商音频 URL。需要 music_endpoint、宿主私密 music_key 和 music_model。
- `music.bridge_request`：宿主内部使用的本地 YuE/RVC 服务协议。插件核验固定路由、解释实际 HTTP 状态和服务错误码；宿主持有完整请求正文、歌词、参考音频、响应音频和任务授权。需要 local_endpoint 和宿主私密 local_token。

云端与本地分别检查配置和权限；空配置不会自动启用任一能力。本地配置不依赖云端密钥，云端配置也不会自动启用本地服务。不回退旧配置或其他提供商。

内部桥能力不会出现在 stdio tools/list；宿主仅从已核准声明调用，并且不直接向 Agent 开放任意 HTTP。它只接收 method/path、正文引用和幂等键，不接收用户选择的 endpoint、headers、凭据、文件路径或内联音频。插件不打开 socket、不启动进程或 GPU；实际连接由固定地址、账号和令牌绑定的宿主代理完成。

本次迁移的是本地服务的客户端协议及错误分类。现有 YuE/RVC 计算仍由独立受管服务承担；服务启动、模型、声线资料、来源校验、任务保存、取消、素材登记和微信投递留在原授权边界。music.cover 与 music.train 仍不可发现、不可调用；本包不构成训练或任意 GPU 执行能力。

云端请求保持 gender=female、format=mp3，不能替代命名唱歌声线。本地恢复始终针对同一个原 job_id，未确认结果不能自动重新提交。返回服务任务或音频引用不表示已试听、验证人声音色、登记素材或微信接受。离线测试仅证明协议和宿主回调契约，没有执行真实模型或发送微信。
