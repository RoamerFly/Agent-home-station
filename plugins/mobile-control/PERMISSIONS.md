# 权限

- `model.invoke`：仅 `device.plan` 请求宿主当前聊天模型，账号、用途、思考设置和用量由宿主绑定、计量和审计。
- `device`：原生五项能力通过 `wechat/device_io` 请求来源绑定的固定 IO。宿主复核原请求、授权、包与设备范围、物理锁、原账本和实际结果。

插件不持有凭据，不取得真实 serial、ADB 路径、宿主私有素材路径或二进制截图/录屏内容。包只在隔离 cwd 写自己的观察元数据缓存；宿主原账本不挂载到插件。没有网络、注册表、ADB 挂载、子进程、微信投递或可由请求扩张的权限。

主机 IO 接口拒绝命令、argv、任意路径、其他设备，以及与原请求不同的 text/URL。所有二进制结果经过私有文件引用、长度与 SHA-256 证明；取消和未知结果不触发重复动作。
