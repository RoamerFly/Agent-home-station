# 权限

- `model.invoke`：仅 `device.plan` 通过 `wechat/model_request` 请求宿主当前聊天模型进行屏幕描述和下一步规划。
- `device`：用于来源绑定的宿主设备代理；宿主独立核验授权、来源版本、请求键和回执，插件不能自行获得、扩大或升级该权限。

插件不持有或配置模型密钥，不直接联网、不启动子进程、不读取本地文件，也没有设备、素材写入或微信投递权限。模型调用的账号、会话、请求者、用途、思考设置和用量由宿主绑定、计量和审计。

设备观察、操作、录屏和受限素材读取只通过宿主设备代理完成；不能借规划能力扩大权限。门面不会处理截图、录屏或片段 bytes，只返回宿主核对过的受限回执元数据。
