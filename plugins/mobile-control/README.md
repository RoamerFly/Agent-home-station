# 手机控制

范围：现有设备桥接与任务。

当前状态：`migration-pending`。ADB 桥接实现已经放入 `runtime/bridge.py`，旧脚本为固定路径兼容入口；动作规划在 `backend/` 中。规划层当前仍静态编译进主体，设备队列、旧配置、路由和录屏分析尚未迁入插件进程。不得作为可安装成品或可调用能力宣传。

主体通过惰性设备服务加载旧配置和任务。未配置的安装不会因为读取默认设备设置而创建服务目录；损坏的设备配置单独报错，不阻止聊天、记忆和账号管理启动。旧任务重启后继续保留原编号，执行中和排队中的任务改为待核对，不重放动作。

后续独立运行须使用宿主受控设备代理：插件不得自行选择 ADB 路径、设备序列号、私有文件或任意命令。当前宿主仍拒绝未实现的 `device` 隔离权限，不因源码迁入而放宽。

宿主协议见 ../../docs/plugins/PROTOCOL.md。不得绕过宿主直接发送微信；生成结果与投递回执分别记录。
