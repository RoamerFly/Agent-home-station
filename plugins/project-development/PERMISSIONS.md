# 权限

- workspace.read：仅授权本次已绑定的目录、文件、搜索、执行器状态或公共登记快照。
- workspace.write：仅授权本次已绑定的新建文件、CAS 编辑或受管目录创建。
- process.execute：仅授权本次已绑定的隔离命令及当前 scope 的后台进程管理。

这些权限只允许调用宿主代理，不会给工具进程增加文件挂载、网络、GPU 或直接启动进程的权限。GPU 请求仍由宿主执行器根据原始 gpu 参数和部署策略处理。

工具不能更改原始路径、命令、request_key、账号、会话、真实发送者或 global 请求。宿主在调用、代理、结果核验与私有检查点读取时重新核验来源和授权。工具返回的文件/进程结果必须与实际宿主 I/O 观察相同。

当前安装契约要求批准整包声明权限；只读会话由宿主权限级别筛选实际可发现和可执行的工具。安装权限不会覆盖普通成员的会话边界或赋予其共享源码写权限。
