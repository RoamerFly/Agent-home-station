# 运行时

`main.py` 是 Python 标准库 MCP stdio 入口，`observation.py` 负责视觉请求和结果解析。运行时不读取宿主文件、不直接联网、不接收模型密钥；通过获准调用内的 `wechat/model_request` 使用宿主模型代理。图片引用必须由具体生产策略校验后替换字节；本轮只有合成策略验收。

`local_asr.py` 已迁入本目录，作为 SenseVoice CPU 推理的唯一源码；兼容安装器会将它部署到既有已登记模型的固定入口。模型、解释器、SDK、VAD 和来源绑定仍由宿主验证并只读挂载，当前插件没有自行选择路径、下载资源或启动本地推理的权限。

视频抽帧、ASR 宿主适配和本地识别运行环境挂载仍未完成。正式包保持 migration-pending。
