# 权限

- artifact.read
- artifact.write
- model.invoke

仅取得管理员批准的权限交集。请求上下文由宿主绑定；插件参数不能改变账号、接收者或访问范围。

0.1.1 的图片观察使用 `artifact.read` 与 `model.invoke`。`model.invoke` 只允许当前调用通过宿主请求声明的模型路由，不授予直接联网、任意 HTTP、文件系统或微信发送权限。接口地址由管理员配置，Authorization 由宿主添加；插件参数不能更换地址或认证头。素材引用必须由宿主绑定到当前来源及修订，不能把任意路径或 URL 当图片输入。

`artifact.write` 为尚未迁入的媒体处理契约保留，不代表当前观察实现会生成素材。撤销权限、停用、配置变更或来源失效时，宿主必须阻止后续调用及结果接受；未完成这条生产适配前保持包不可安装。
