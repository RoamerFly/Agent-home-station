# 媒体理解

0.1.2 提供独立 Python MCP stdio 的两项就绪能力：**入站图片/贴纸观察**与**入站语音转写**。插件负责请求构造和结果解析；宿主负责账号、会话、来源版本、素材字节和发送边界，并通过 `wechat/model_request` 或受控本地 ASR 代理执行。密钥不进入插件进程。

支持 OpenAI 兼容视觉接口及现有 DeepSeek 思考协议。默认输出额度可配置，调用可显式设置输出额度、时间和思考选项；不支持的思考协议明确报错。输出区分完整与截断，保留来源、仅所提供图片的覆盖范围、提供商实际 Token 与未知用量；隐藏推理和工具调用不作为观察返回。

语音识别已声明独立的可选接口、密钥与模型。未填写这些字段时，视觉观察配置和调用不受影响；选择“远程接口”后，`media.transcribe` 只能通过宿主的 `transcription` 模型路由使用该密钥。选择“本地识别”后，宿主必须签发已登记本地 ASR 的 profile 与资源版本；插件只发送来源绑定的 WAV 引用给 `wechat/local_transcription`，不读取或接收路径、字节、模型、解释器或命令参数。宿主在隔离环境中以本包固定 `local_asr.py` 和已登记运行环境执行。缺少签发 profile 时明确不可用，绝不回退到其他声线、模型或远程接口。

视觉、远程 ASR 与本地 ASR 的配置互不依赖：只配视觉可以保存并使用视觉能力；只配远程 ASR 或登记本地 ASR 可以保存并使用转写能力。未配的能力在宿主发现阶段显示为不可用，而不是要求补齐无关的密钥或地址。

当前就绪范围严格限定为宿主已核验的入站图片、贴纸和语音。视频号/视频分享的自动处理，以及视频音轨的分页读取，仍沿用主体的自动处理与 `video_inspect` 续读路径；本包不直接解码视频，也不把视频帧或音轨当作新的通用输入能力。模型质量、服务可用性和手机端投递仍需分别验证。

离线协议测试：`python -B -m unittest discover -s plugins/media-understanding/tests`。不得使用生产配置运行付费测试。

范围：入站图片/贴纸观察与入站语音转写。它不发送微信，不读取其他账号，不直接联网或执行任意命令。

宿主协议见 ../../docs/plugins/PROTOCOL.md。不得绕过宿主直接发送微信；生成结果与投递回执分别记录。
