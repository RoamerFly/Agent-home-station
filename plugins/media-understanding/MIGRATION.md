# 迁移

0.2.0 新增 `media.listen` 的独立音频内容观察配置：`audio_review_endpoint`、宿主持有的 `audio_review_key` 和 `audio_review_model`。它与视觉和 ASR 独立；预演或保存缺失该配置时不得将音频内容观察标为可用。该能力只接受宿主来源绑定的 WAV 引用，结果是模型观察，不得迁移或宣称旧声纹、人工试听或发送能力。

0.1.3 将旧 `ASRLocalModel` 仅在迁移预演时映射为本包的 `local_asr_profile_id`；运行时不再读取旧 speech 配置。选择本地识别时，该字段必须与当前账号宿主签发的 profile 完全一致，否则转写保持不可用且不会回退。0.1.2 已将经过宿主来源与权限核验的入站图片/贴纸观察、入站语音转写接入插件宿主，并允许按独立配置发现相应能力。视频号/视频分享的自动处理和视频音轨分页仍在主体自动处理与 `video_inspect` 路径中；本包没有新增通用视频解码或任意媒体读取能力。后续迁移必须保留这一边界，不能仅凭素材类型扩大插件输入范围。

0.1.1 增量迁移 `internal/deepseek/vision.go` 的观察提示与 OpenAI 请求结构、思考协议和响应处理到独立进程。宿主增加独立的模型权限代理、配置地址与宿主持有的密钥；不把原配置双写到插件库。本轮未迁移真实视觉配置，生产仍使用旧路径。

语音识别配置采用可选的 `asr_backend`、`asr_endpoint`、宿主持有的 `asr_key` 和 `asr_model`。`remote` 只使用独立远程接口；`local` 只使用宿主为当前账号、来源版本与任务签发的本地 ASR profile/资源版本。它们不从旧视觉配置推断或双写；迁移预演必须逐账号核对原 ASR 后端、模型和密钥归属。未配置 ASR 或尚未登记本地 profile 时可迁移视觉配置，但不得把语音任务标为已迁移。

视觉路由同样是可选的：配置与能力发现按视觉、远程 ASR、本地 ASR 分别核验。安装或保存某一个能力的配置，不得要求另一个能力的地址、模型或密钥；实际调用前仍由宿主重新核对该能力的完整路由、密钥或本地 profile。

后续需评估视频解码及更广媒体入口是否值得迁移；若迁移，必须先完成来源、素材、费用和续读边界设计，不能用当前两项能力的就绪状态替代该验收。

观察来源、版本和覆盖范围保留。

当前没有执行真实迁移。实施先在隔离副本预演并核对，成功提交后再切换唯一存储；任务状态未知时先查询，禁止重复提交。启用前可恢复旧备份，接受新写入后保留新数据由兼容版本修复。
