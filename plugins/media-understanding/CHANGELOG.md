# 变更

0.1.3：本地识别新增必填选择 `local_asr_profile_id`。插件仅在该配置与宿主当前账号签发的已登记 profile 完全一致时调用本地 ASR；运行时不再读取旧 `ASRLocalModel`，且缺失或不一致不会回退。

0.1.2：图片/贴纸观察与入站语音转写经宿主来源、权限与配置适配后标记为可用。视频自动处理、视频解码和音轨分页仍由主体与 `video_inspect` 负责，未被宣称为本包能力。

0.1.1：新增独立视觉协议实现、受控图片引用和模型代理；支持明确的用量、缓存与截断状态。音频转写可明确选择远程模型路由或宿主签发的受控本地 ASR profile，二者均不接收路径或任意命令。生产来源绑定、费用入账、视频处理和 ASR 宿主适配待迁移，包仍未就绪。

0.1.0：建立迁移契约，尚未迁出旧实现。
