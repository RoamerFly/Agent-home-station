# 迁移

0.3.0 完成公共搜索/读取入口切换，并将公开内容发现解析迁入 `web.discover`。先预演并明确安装、授权 network、配置后端及启用；已有安装须审核新版本摘要并升级后再启用。旧公共实现不再作为回退。冲浪订阅仍由宿主选择并校验，候选仍经过原历史去重与分享核验；仅有标题和媒体网址不算观看或播放。没有显式授权会话的私人浏览因缺独立来源授权暂明确阻断，不伪造聊天来源、不消费预算。

0.2.1 增加显式 `public` / `deepseek` 搜索后端选择。DeepSeek 通过宿主固定官方路由和宿主持有的 `search_key` 执行，保留 `need_content=false` 请求结构且默认 `count=6`；显式 count 原样发送，没有配置该后端或调用失败时不会自动切换公共索引。现有账号的内置联网开关继续作为调用授权；本轮没有修改真实账号配置。

0.2.0 已实现独立搜索和网页读取服务。

迁移预演保留旧搜索/读取开关作来源审查，实际配置只写本包声明的后端与宿主私密密钥；安装后保持停用，启用须单独操作。核心的公共媒体下载与 DNS/IP/TLS 安全运输层继续保留，本次不变更真实账号配置或旧媒体。

新宿主任务按原幂等键查询，不重提；旧任务不转换成新调用。停用后保留已登记任务和配置，恢复时先检查来源和状态。此插件不保存账号密钥、不修改记忆库、不发送微信。
