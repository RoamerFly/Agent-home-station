# 迁移

0.2.1 增加显式 `public` / `deepseek` 搜索后端选择。DeepSeek 通过宿主固定官方路由和宿主持有的 `search_key` 执行，保留 `need_content=false` 请求结构且默认 `count=6`；显式 count 原样发送，没有配置该后端或调用失败时不会自动切换公共索引。现有账号的内置联网开关继续作为调用授权；本轮没有修改真实账号配置。

0.2.0 已实现独立搜索和网页读取服务。

先在隔离副本导入本目录并确认 network 权限、启用并跑合成调用，再迁移账号工具发现。旧内置搜索、分享页特例和付费服务商搜索路径尚未删除，待引用关系与回归核对后切换；不能据此宣称轻主体已经完成。

新宿主任务按原幂等键查询，不重提；旧任务不转换成新调用。停用后保留已登记任务和配置，恢复时先检查来源和状态。此插件不保存账号密钥、不修改记忆库、不发送微信。
