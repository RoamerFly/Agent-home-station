# 变更

0.3.4：`web.read` 成功结果新增经宿主校验的 `read_coverage`，明确正文已读字符范围、完成度和有界正文摘录。发现候选、标题和摘要继续只表示元数据；读取失败保持 `ok=false`，不会被写成“已阅读”的经历。

0.3.2：B站音源搜索在站内公开搜索临时拒绝、空结果或两个既有公共索引均无匹配时，继续查询第三个独立公开索引。所有允许来源均失败时返回可重试的 `search_sources_unavailable`，有来源成功但未命中时保留 `search_no_relevant_results`，不把传输故障伪装成无结果。

0.3.1：增加 B 站作品站内搜索，支持歌手、曲名和分页，通过宿主读取公开搜索结果。

0.3.0：公共搜索、网页读取与冲浪发现统一经安装包执行；增加 RSS/Atom、B站列表/关联、图片及器乐目录的 `web.discover` 解析和分页。宿主按当前来源绑定代理请求，停用或未迁移不会恢复内置联网路径，缺少授权目标不会消耗冲浪预算。

0.2.1：增加显式公共索引 / DeepSeek 官方检索后端选择、受宿主保护的 `search_key` 和默认 count=6 的旧版请求结构；显式 count 原样转交服务商，未配置或失败时不自动切换后端。

0.2.0：独立 MCP stdio 搜索/正文解析、Bing/360 回退、分页/哈希核验、宿主网络代理及合成验收。旧内置路径保留至账号迁移完成。

0.1.0：建立迁移契约，尚未迁出旧实现。
