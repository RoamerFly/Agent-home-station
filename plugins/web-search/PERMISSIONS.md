# 权限

- `network`：允许在当前宿主调用内请求公共 HTTP(S) 页面，或调用摘要中声明的固定 DeepSeek 检索路由。通过管道代理读取，工具进程仍无直接网络能力。DeepSeek 密钥为宿主持有的 `search_key`，工具不能读取、替换或转发它。宿主拒绝私网地址、无效 TLS 以及范围外来源；不提供任意 HTTP 方法、认证头或账户 Cookie。

仅取得管理员批准的权限交集。请求上下文由宿主绑定；工具参数不能改变账号、接收者或访问范围。

公开索引 GET 必须匹配本次 query 及显式配置的 public 后端，正文 GET 必须匹配本次 url。`web.discover` 只读取当前已登记且启用的订阅/目录；关联探索还需匹配本次候选或已访问/收藏来源。解析在隔离工具内完成，宿主只提供受限公开读取与候选/授权核验。

撤销后不可继续调用或发现工具；查询旧结果也需验证当前授权与来源。已开始的读取在返回前再次校验，不把撤权前的输出交给新请求。无 GPU、设备、宿主工作区或微信发送权限。
