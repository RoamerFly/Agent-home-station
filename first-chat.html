首次配置与第一条回复

1. 确定当前账号

打开桌面管理页，在顶部账号选择器选中要配置的微信账号。进入设置中的微信账号页，点击 扫码登录此账号，在手机微信完成确认。回到管理页检查当前账号显示微信在线。若手机提示“登录 Linux 电脑”，这是当前协议的设备标识，Windows 原生版仍在本机 Windows 上运行。

多账号部署每次修改前都先看顶部账号名称。某个账号扫码成功，不能证明其他账号已连接。新安装也不会自动继承官方桌面微信的历史消息。

2. 连接模型

在 设置 → 模型与语音 选择服务商，填写接口地址和该账号使用的 API Key，保存并应用。获取模型列表后，从下拉框选服务端实际提供的模型；列表获取失败时检查地址和鉴权。不要把 Key 粘贴进微信群、群备注或问题报告。

若启用思考，选择服务商支持的强度，保存后回读模型名称与思考设置。获取列表只查询模型目录；“测试模型连接”会实际调用 API，费用按提供商计量。模型能连接后再开启自动回复，避免把鉴权失败误判成群聊保持安静。

3. 用一个会话验证

  1. 在会话页选一个有测试授权的私聊，配置允许回复的范围。若先用群聊，选择一个测试群，并让测试者真正 @ 机器人。
  2. 保存会话规则，在管理页启动 Agent。确认微信在线、模型已配置、Agent 运行中三项同时成立。
  3. 在刚授权的会话发送“请用一句话回复：测试收到”。在活动页按今天的日期和该会话查看执行回合。
  4. 查看接收、判断和投递结果。文字已生成但没有回执时，先按 排障与维护 核对原任务。看到微信已接受后再由接收方检查内容。

如果不再需要这个测试会话，回到会话页收回其授权。暂停 Agent 与退出微信登录是两个操作，短暂停止回复可使用暂停按钮。
