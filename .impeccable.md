# Design Context

## Audience and use cases

The owner manages a personal WeChat Agent from a Windows browser, with possible
future Linux hosting. The console supports reviewing conversations and execution
rounds, configuring models and permissions, and inspecting the editable reply
flow. Dense settings should remain available without crowding primary actions.

## Confirmed direction

The user selected the blue whale character identity and requested a simpler,
readable Chinese console with light/dark themes. Preserve the established ocean
palette, narrow navigation and system Chinese fonts. Brand words: friendly,
clear, calm. This is a working control panel; keep decoration restrained.

## Layout requirements

Keep labels and actions readable at narrow widths and short window heights.
Use intrinsic layout, explicit gaps and scrollable dialog bodies. Keep fixed
controls from covering content or keyboard focus. Preserve reading position.
Use full node dialogs and arrowed flowchart/tree layouts already accepted by
the user. Custom diagram nodes remain planning notes; existing nodes expose
their actual settings.
