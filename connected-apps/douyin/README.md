# 抖音接入版本

通过普通抖音账号登录，保存专属网页登录状态。登录过期时在应用详情重新登录。

主人可以分别允许首页和视频页面文字读取、静音播放观察、音轨转写及画面分析。实际内容定位和读取由抖音接入负责，解码、语音识别和视觉分析复用公共工具。模型按已取得的内容和来源继续任务。

评论读取使用独立许可，通过 `app_observe(field=comments)` 读取宿主已发现的视频。返回页面实际加载的评论、评论编号与作者；按原请求续读，`refresh=true` 从头更新。默认请求 20 条，可调整；达到本次读取资源边界时返回实际条数和继续位置。评论者观点与视频原话分开。本轮已通过离线页面和正常聊天入口回放，真实抖音评论页面仍待验证。

普通账号已支持通过创作者中心发布单个 MP4/WebM 成品。主人单独开启发布许可后，任务核对文案与可见范围、登记提交，再查询原作品回执。回执丢失时只读核对已提交的原任务，不自动重新投稿。实际账号已完成一次仅自己可见的 18 秒作品验收；公开发布、评论、点赞及直播伴侣接入仍待相应验证或实施。

历史 API 配置资料保留在宿主私有目录，正式站点取消开发者授权入口和对应工具连接。

Connected Apps/douyin 是本软件的接入版本工作目录，用于维护应用接入行为。账号登录资料、密钥和权威回执由宿主管理。目录内容与抖音客户端源码无关。

实现范围、授权和验证边界以项目的《大肥鱼长期成长阶梯计划》和《应用接入与项目工具规范》为准。
