# 授权边界

主人在站点私有目录登记的应用令牌只用于固定抖音官方搜索端点。模型只能从获准关键词中选择。应用从宿主传入关键词、分页和平台要求的设备编号。重定向、其他站点、账号会话和用户 OAuth 不属于该授权。

网页文字读取是另一条连接，必须由主人单独开启。默认只读取首页实际可见文字；主人另行扩大范围后，可信 Windows 宿主只能从首页实际发现的确切视频链接签发 `web-video-` 后续编号。浏览器资料、Cookie、资料来源、授权版本和分页完全由宿主保管；适配器只核对固定连接 `web-page-text`、合法内容编号和字段后转交宿主回调，编号不自行授予权限。首页仅允许 `page_text`；合法视频后续编号可请求 `page_text`，或在主人单独允许静音采样时请求 `playback`。旧文字读取许可不自动扩大为播放许可，实际许可与每次来源核验均由宿主掌握。它不是 OAuth，也不声明抖音平台账号已经认证。

普通网页登录采样与官方搜索播放器采样分别授权。普通网页路径复用专属资料锁和受控后台浏览器，须把确切视频、网页元数据及实际主媒体关联后，才能返回浏览器原生 `played` 区间。签名媒体地址、Cookie 和网络响应原件不返回适配器或模型。只有实际进度才算播放；无进度、来源不明或平台挑战不构成完成。该许可不包含音轨转写、画面理解、评论、点赞、发布或直播。撤销、改范围、重登及更换身份后，旧编号和缓存均重新核验。

设置变更、过期或停用后，旧进度和证据不能继续使用。凭据、设备编号和平台游标不进入观察结果、日志正文或家目录源码。

本人作品读取使用独立 OAuth 用户凭据，固定访问官方基础信息查询接口，仅提交本次允许的一个作品编号。原始账号编号和用户令牌留在宿主，接口返回脱敏账号引用。未公开状态仅提供作品编号、状态和核对时间。状态证据不持久缓存。

账号连接只由已登录的本机主人发起。临时授权绑定该主人、管理会话、登记回调和随机状态，一次性消费。Client Secret 和回跳不写入磁盘。已核验的访问令牌、续期令牌及过期时间存放在站点私有数据目录，由宿主使用。管理页只返回账号状态、访问到期时间和是否可续期。账号连接默认只核验资料。搜索、作品管理和外发操作有各自的授权。只有已登录的本机主人可发起续期。核对同一账号、授权范围和连接版本后保存新凭据，平台撤回的权限立即从工具能力中移除。

Windows 授权窗的网页资料与管理页和用户的 Edge 会话隔离。窗口拦截已登记的回跳导航，授权码经本机管理会话核对后兑换。关闭窗口会取消该次待授权，已有连接可以继续使用。

账号作品列表要求主人明确勾选，并且回跳和令牌同时包含作品列表权限。仅使用同一次授权中绑定的账号编号与用户令牌，固定访问抖音官方列表端点。游标由宿主保存，作品标题、封面、分享地址、原始加密标识和令牌均不返回。重新授权取消作品列表或解除账号连接后，旧游标和迟到结果失效。

开启跟进后，仅能用宿主为匹配的搜索结果签发的编号核对播放器。请求只提交该作品编号到固定官方匿名接口，不发送搜索令牌、关键词、设备编号或 Cookie。授权变化会使旧编号失效。

静音播放另需显式开启。播放使用临时独立的 Edge 资料和固定官方播放器。宿主限制必要的网络请求，不使用个人浏览器登录资料，也不返回媒体签名地址。

视频发布要求主人单独勾选并获得平台的上传创建与状态查询两项用户权限。工作流只通过宿主打开原任务登记的成品，在平台写入前重新核对账号、授权版本、来源及取消状态。上传会话编号、加密作品编号和令牌留在宿主，任务界面仅显示进度与可披露的回执编号。查询只读取原任务返回的同一作品。取消不调用平台删除接口。
