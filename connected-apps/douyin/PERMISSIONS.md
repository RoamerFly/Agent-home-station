# 抖音接入权限

正式接入使用主人专属的普通网页登录资料。登录资料由宿主保存，接入版本和模型均不能读取 Cookie、登录文件或其他应用资料。

首页文字、视频页文字、静音播放、音轨转写、画面分析和评论读取分别按主人保存的范围执行。具体视频须来自宿主记录的真实页面链接，读取前后都核对身份、来源和许可版本。评论读取不授予点赞或回复权限。关闭读取、收窄为首页或重新登录均撤销评论读取；缓存和迟到结果同样核对当前许可。音视频处理调用公共媒体工具，画面仅交给媒体理解中已配置并获准的视觉服务。

0.14.0 的正式站点已移除开发者账号授权、开放平台搜索和 API 发布连接。旧 API 配置与任务记录保留在私有存储中，不能作为普通账号的新操作授权。

普通账号发布已经使用独立许可和持久任务账本。点赞、回复评论和直播的动作权限将在对应实现接入时登记。网页内容不具有修改授权、运行命令或扩大可见范围的权限。
