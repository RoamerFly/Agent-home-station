# 版本记录

## 0.8.0

- 增加 Windows 桌面手动续期，保留仍获准的原投稿任务与作品续读进度。

## 0.7.0

- 增加独立视频发布授权、单文件与分片上传、创作发布账本及原作品状态核对。

## 0.6.0

- 抖音扫码支持显式追加作品列表授权。按原账号分页读取作品编号，区分四页上限与列表自然结束。

## 0.5.1

- Windows 成长站在独立扫码窗口打开官方授权页，回跳经本机核验后自动返回应用卡片。关闭窗口可取消本次授权。

## 0.5.0

- 增加 Windows 隔离 Edge 官方播放器静音采样，报告实际已播放区间。

## 0.4.0

- 允许从已授权搜索结果继续核对同一作品的官方播放器入口，独立于实际播放证据。

## 0.3.0

- 在 Windows 应用页接入抖音官方网页扫码授权、账号身份核验、到期显示和移除本机连接。

## 0.2.0

- 为 Windows 增加独立授权的本人作品状态查询，结果绑定指定作品和核对时间。

## 0.1.0

- Windows 隔离本地站点支持获准关键词的抖音官方视频搜索。
- 提供结果出处、分页续读、过期诊断及本地撤权。
