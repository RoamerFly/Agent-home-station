# 微信应用

微信接入包含登录、收发消息、通讯录、引用、撤回和微信分享读取。此目录是应用发行源，桌面可将它安装到大肥鱼家目录的 Connected Apps/wechat。

当前版本迁出了应用及连接身份、11 个工具声明、消息与成员读取协议、来源元数据投影及语音分段参数声明。运行中的兼容接入仍由宿主装配，文字发送、账号动作、撤回、原附件取得、文件转发、媒体投递与回执查询编排已迁入应用适配器。授权、原素材、分段队列、取消和回执继续由宿主通过绑定原请求的接口管理。读取前后由宿主核对当前授权；只有成功返回的消息页才可登记为任务来源，成员列表不能当作聊天原文。独立本机聊天安装此发行源后，仍需后续连接和运行组件迁移才能启用微信。

宿主在安装时校验 app.json 及文件摘要。大肥鱼可以编辑安装目录内的代码、说明和任务文件。修改声明不改变账号授权。工作文件保存在 workspace，非密钥设置保存在 config。再次安装相同发行源会保留已有编辑。升级到不同发行源需先处理旧版本及在途任务。

## 安装

在桌面发行包选择包含微信应用目录。使用管理接口 GET /api/local/apps/catalog 核对摘要，再以 POST /api/local/apps/wechat/install 提交 digest 与当前家目录 revision。家目录必须已经准备且授权。

## 运行组件

adapter/entry.json 标识宿主兼容入口。runtime/components.json 记录仍待迁移的 Windows 组件及现有打包入口。原生客户端与管理程序本轮继续沿旧布局运行。登录材料、聊天数据库及回执存放在宿主私有目录。
