# 迁移

此版本迁移应用身份、工具声明、消息/成员目录协议、来源元数据投影，以及文字发送、账号动作、撤回、原附件取得、文件转发、媒体发送与回执查询编排。原幂等键与操作编号保持不变，未知结果继续查询原任务；提交前核对授权及来源，实际回执由宿主入账。存储读取、更正/遗忘屏障和账号授权由宿主提供窄接口；应用不取得聊天数据库、账号凭据或其他账号句柄。原账号、来源编号、群偏好、素材、记忆、任务和回执继续由现有宿主存储管理。

首次安装将经摘要核验的文件原子发布到 Connected Apps/wechat。相同描述符重试保留现有编辑。不同版本或已存在的无关目录返回冲突，保留原内容。安装中断后重试创建完整目录，临时目录不代表应用已启用。

卸下此发行源不会清除宿主资料。运行组件、实际账号连接及 UI 的迁移在后续阶梯实施。
