# 版本记录

## 0.5.0

- 增加可单独授权的公开单段音轨读取。实际解码窗口、转写、无音轨及未识别到词分别记录。

## 0.4.0

- 为获准 BV 增加可单独授权的匿名公开一级评论读取、来源编号、发布时间和断点续读。

## 0.3.0

- 增加获准公开视频的独立 Edge 静音采样和实际播放证据。
- 按媒体就绪、已播放区间、暂停和完整播放分别记录状态。

## 0.2.0

- 增加独立无头 Edge 的只读网页入口，由主人另行开启。
- 读取范围继续由 BV 清单控制，页面文字和接口资料各自保存。

## 0.1.0

- 为 Windows 本地成长站提供可选的匿名公开资料连接。
- 按主人授权的 BV 清单读取稿件标题和投稿者简介，记录实际覆盖范围。
