# Agent 自主行动与服务器权限升级

交付日期：2026-10-25。运行版本：`0.7.0-agent-local`。

管理入口：http://127.0.0.1:8081/#agent

## 已交付

| 要求 | 实现 |
|---|---|
| 增强自主行动 | 统一1–30步工具预算，默认12步；真实会话/成员读取；保留最初请求，必要时压缩早期工具输出 |
| 持续任务 | 目标、检查点、状态、下一次评估时间和执行次数持久保存；后台接入现有会话调度器；管理页支持恢复/取消待处理任务 |
| 微信账号能力 | 可信用户可获授权会话目录、跨会话文字发送、发送/账号动作回执查询，以及逐项选择的账号管理动作 |
| 服务器能力 | 关闭、只读、文件、完整四级；只读列目录和读文本，文件级别创建新文件，完整级别增加真实Shell命令 |
| 身份与权限 | 可信微信用户ID+允许的已授权会话双重校验；群聊历史读取沿用群观察权限；外部API/MCP插件可限制为可信用户调用 |
| 防重与中断 | 写操作先持久领取再执行；发送编号换内容会拒绝；状态查询不会重发；运行中的任务重启后待复核；命令支持有界输出、超时与取消 |
| 管理页整理 | 行动步数统一至行动页；发送、等待、恢复、安静时段与预算集中；重复毫秒等待和旧MCP预算不再显示；模型基础指令折叠，历史值保留 |
| 现有体验 | 明暗切换、手机布局、日志筛选与阅读位置继续保留；高权限编辑未保存时切页丢弃，无确认弹窗 |

## 当前实例

- 微信保持登录、机器人运行中，运行程序与本地dist、静态资源核对一致。
- 自主行动和任务工具已启用，默认每轮12步。
- 服务器权限初始关闭，未替用户配置高权限身份或给普通群友开放服务器。
- 默认准备一个私有`agent-workspace`。开放服务器前，在「工具与权限 → 权限与服务器」选择可信用户、会话和权限级别。
- 没有构建或导出Docker镜像；本轮只更新本地Web程序，保留原生微信登录。

## 实际边界

- **完整命令运行在管理服务的系统用户权限下；工作目录不是命令沙箱，不自动获得root。** 文件工具使用根目录边界；完整Shell可以访问该系统用户有权访问的其他资源。
- 文件级别只创建新文件，不覆盖已有文件；完整级别可根据授权指令通过命令操作已有文件。
- 后台任务沿用主动权限、主动目标、安静时段和每日预算。保存任务不等于承诺固定时间发送。
- 管理页只能直接取消尚未运行的任务；运行中任务可先暂停Agent，再检查/取消。已经产生的服务器影响和已被微信接受的消息不能靠取消回滚。
- 本轮没有向真实群发送高权限测试指令，也没有实际修改群名、邀请/移出成员或退群；这些动作仍受微信账号权限和服务端限制。
- 已接入账号工具与服务器工具，不代表微信所有客户端功能、QQ接入或任意第三方服务均已实现。
