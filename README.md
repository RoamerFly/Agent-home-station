# 大肥鱼 · 微信 Agent

大肥鱼把语言模型接入微信。它可以在授权的私聊或群聊中结合聊天记录回答问题，按需调用工具，并把结果发回对应会话。管理员通过桌面管理页配置账号、模型、群偏好和插件，查看每次执行及微信回执。

微信文件收发、会话记忆和任务调度由主体提供。文档加工、语音合成、音乐换声、媒体理解等能力按需安装。Windows 原生版可直接运行，基础收发无需 WSL。
