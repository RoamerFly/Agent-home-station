# 大肥鱼工作台：GPT Image 3 设计稿

这组设计稿用于重构 `internal/stationui/static/local-home.html` 与 `local-home.css` 的工作台视觉层。图片是高保真方向稿，最终实现仍以现有 DOM、可访问性和权限语义为准。

## 页面对应

| 设计稿 | 现有页面 | 重构重点 |
| --- | --- | --- |
| `01-login-initialize.png` | `#login-view` / `#home-view` | 登录、初始化、准备状态放在同一条清晰流程里 |
| `02-chat.png` | `#chat-view` | 对话列表、聊天流、输入区、最近记忆分成稳定三栏 |
| `03-memory.png` | `#memory-view` | 关系图/列表切换与筛选放在同一工具栏，详情固定在右侧 |
| `04-apps.png` | `#apps-view` / `#apps-list` | 应用卡片开关使用真实轨道和圆形滑块，状态文字与颜色同时表达 |
| `05-app-permissions.png` | `#app-dialog` / `#app-configuration` | 默认开启安全只读能力；播放、自动回复、点赞、发布等自主功能单独分组并保持未授权 |
| `06-tools-settings.png` | `#project-tools-view` / `#settings-view` | 项目工具进度和设置分组用同一套管理组件表达 |

## 视觉规则

- 深海蓝只用于导航、遮罩和系统级背景；内容区域保持暖纸白，避免整页大面积渐变。
- 珊瑚色只承担选中态和主操作；海玻璃青承担已开启、已准备和进度状态。
- 开关必须同时有轨道、滑块、文本状态和焦点态；不能只靠一块色块表示开关。
- 应用权限分成“安全只读能力”和“自主操作能力”两组。前者默认可用，后者必须由用户在详细配置中明确授权。
- 设计稿中的文字是方向示例，落地时保留现有真实状态、错误信息、取消和回退路径。

生成方式：内置 GPT Image 设计生成工具；图片仅作为产品视觉方向资产，未替代代码实现。
