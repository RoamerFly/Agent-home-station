# 鲸鱼娘管理后台设计规范

本次方向：明亮海盐蓝控制台，搭配深海暗色。角色立绘是唯一主要视觉焦点，工作页面保持克制，表格/表单优先于装饰。保留两行 deepseek / 蓝色大肥鱼 品牌和按内容收窄的侧栏。

## 依据与取舍

已读取项目级 UI UX Pro Max、Frontend Design、Web Design Guidelines、Playwright CLI Skills。检索结果中的营销页布局与本产品不符，未作为后台架构；只采用匹配的蓝色语义色和可访问性建议。shadcn 官方 Skill 已核实，现有项目无 components.json 或 React，故保留原生 HTML/CSS/JS。

## 色彩与排版

- 浅色底 #F4F7FC，工作面 #FFFFFF，正文 #18283F，次要文本 #52647C，主色 #245FD6，边框 #D9E2EF。
- 暗色底 #091423，工作面 #111F32，正文 #EDF4FF，次要文本 #A7BAD2，主色 #3975E8，操作按钮另用深蓝保持白字对比。
- 中文字体采用本机 PingFang SC / Microsoft YaHei，正文 15px，表单 15px，标题 24–28px，辅助文本 13px，代码 13px。不加载外部字体。
- 间距使用 4/8/12/16/24/32px，面板圆角 16px，输入 9px，图标统一 18px 线形 SVG。按钮移动端点击区至少 44px。

## 信息架构

七个主要入口：总览；账号管理（登录、群规则、操作审批）；会话中心（目录、消息附件）；Agent 控制（人设、服务商）；工具与权限（插件、联网 MCP、权限）；记忆管理；系统日志。

页内保留原功能和 DOM ID。状态与暂停按钮全局可见。主导航与页内导航分层，支持 URL 片段、前进/后退。权限和记忆拥有独立页面。插件按模板、已安装和编辑器三块组织，常用地址/类型/Key 优先，完整 JSON 渐进展示。

## 验收范围

浏览器操作、375/768/1024/1440 响应式、明暗主题、键盘焦点、菜单 Escape、减少动态效果、配置未保存反馈、插件模板/导入/编辑。使用真实服务做只读检查；不发送消息、不执行群变更、不改现有权限和 Key。
