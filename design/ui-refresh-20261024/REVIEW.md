# UI 与交互审核

使用项目级 UI UX Pro Max、Frontend Design、Vercel Web Design Guidelines 和 Playwright CLI Skills。设计检索中营销页/不适合中文的字体建议未采用，保留原生 HTML/CSS/JS 与鲸鱼娘视觉。

## 已完成修复

- index.html：七个主导航与页内导航；记忆和权限独立；跳到主要内容；图标 aria-hidden；图片固定尺寸；插件导入改为键盘可触发按钮。
- app.css：语义主题、减少动态效果、44px 移动点击区；群规则控制网格及 min-width 约束；日志改横向流程，控制区压缩。
- app.js / ui.js：history 导航；不在同页刷新时回到顶部；移动菜单背景层、焦点约束与 Escape 返回；未保存反馈、输入错误关联与首错焦点。
- plugins.js：常用配置字段与高级声明分层，独立 Key 输入只写，完整配置序列化与清空输入验证；移除/切换时保留未保存提示。
- logs.js：北京时间格式、分类/来源/关键词筛选；同一消息按关联 ID 合并；刷新只提示新记录，默认不跟随、不抢阅读位置。

## 证据

research/evidence/ui-refresh-delivery.json 汇总完整测试。13 个视图、375/768/1024/1440 宽度、明暗主题、键盘菜单、表单 mock 提交、群卡片边界与日志滚动/筛选全部通过。日志截图使用明确的“界面回归”模拟数据，不代表真实群发送验收。真实配置未因浏览器回归改写；Go 服务更新保留配置文件哈希，微信会话未重启。

## 实测边界

未做第三方在线插件市场，不引入 React/shadcn 组件；没有生成 Docker 镜像。修复了普通模型文本被 JSON 解析器丢弃与误报静默，真实模型+隔离原群记忆已返回 reply；修复后的新手机收件还需用户测试。旧日志缺失的正文或关联标识不伪造补齐。
