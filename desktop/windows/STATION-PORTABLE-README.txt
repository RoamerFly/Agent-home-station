Agent-home-station Windows 便携包

解压并整体保留程序目录。双击 AgentHomeStation.exe 打开本机工作台。
首次使用，准备大肥鱼的家并配置聊天模型。可以先聊天，再按需接入应用。
系统需有 Microsoft Edge WebView2 Runtime。安装应用前，工作站不要求微信账号、ADB 或手机模拟器。

默认本机资料在 data\station，家目录在 data\station\managed-workspaces。
更新时保留这些目录以及已登记的模型、素材和应用运行资源。
不要把旧版 WechatAgent.exe 或旧管理后台直接放进此目录。

最小化保留任务栏按钮；关闭时可收起到托盘或退出并停止服务。
如有端口或资料目录权限提示，先查阅项目的工作站使用说明。
